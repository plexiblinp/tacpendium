==================================================
 Tacpendium (SF6 Tactics Workbench) — 配布版 README
==================================================

※ 本ファイルは Tacpendium を使う方へ向けた説明です。開発者向けの情報(ビルド・
  CI・リポジトリ構成)は README.md にあります。画面ごとの詳しい使い方は、
  本ファイルと同じ場所の manual/ フォルダにある操作説明書
  (manual/tacpendium-readme.html)に全 21 章あります。はじめての方は、
  その冒頭にある「クイックスタート」のリンクから読みはじめてください。

Tacpendium は、ストリートファイター6(SF6)の戦術ワークベンチです。コンボ・
セットプレイ・確定反撃を記録し、整理・比較・共有できます。フロントエンドを
同梱した単一の実行ファイルとして配布され、別途ソフトウェアをインストール
する必要はありません。


■ 起動方法
--------------------------------------------------
1. 実行ファイルをダブルクリック(または端末から実行)します。
     - Windows : tacpendium-windows-amd64.exe   (公式サポート)
     - macOS   : tacpendium-darwin-arm64        (非公式対応)
     - Linux   : tacpendium-linux-amd64         (非公式対応)
2. 起動すると自動でブラウザが開き、アプリ画面が表示されます。
3. ブラウザが自動で開かない場合は、logs/ 配下のログに記録される
   URL(例: http://localhost:47318)を手動でブラウザに入力してください。

※公式サポートは Windows(amd64)のみです。macOS・Linux 版もビルドして配布して
  いますが、動作検証と問い合わせ対応は行っておらず、動作保証はありません。
  お使いいただけますが、自己責任でお願いします。

※設定ファイル(config.toml)とログ(logs/)は、アプリを起動したフォルダ
  (カレントディレクトリ)に作成されます。書き込み可能なフォルダに実行ファイル
  を置き、そこから起動してください。データベースの保存場所は後述します。


■ ダウンロードしたファイルの破損確認(SHA-256)
--------------------------------------------------
配布アーカイブの隣には、同じ名前に .sha256 を付けたチェックサムファイルが置いて
あります。ダウンロードが途中で壊れていないかは、次のコマンドで確認できます。

  - Windows(PowerShell):
      Get-FileHash tacpendium-windows-amd64.zip -Algorithm SHA256
    表示された Hash の値が、tacpendium-windows-amd64.zip.sha256 に書かれている
    値と一致すれば問題ありません。

  - macOS:
      shasum -a 256 -c tacpendium-darwin-arm64.tar.gz.sha256

  - Linux:
      sha256sum -c tacpendium-linux-amd64.tar.gz.sha256

※これは「ファイルが壊れていないこと」の確認です。「配布元が正しいこと」の証明で
  はありません。


■ 常駐と終了 (Windows)
--------------------------------------------------
Windows 版は、起動しても黒い窓(コンソール)は出ません。代わりに画面右下の
通知領域(タスクトレイ)に Tacpendium のアイコンが常駐します。ブラウザの
タブを閉じてもアプリは動き続けます。

アイコンを右クリックすると、次の 6 つが選べます。

      ブラウザで開く
      設定画面をブラウザで開く
      設定ファイルのフォルダを開く
      ログフォルダを開く
      DB のフォルダを開く
      終了

★ 終了はこのメニューの「終了」だけです。アプリ画面の中に終了ボタンはありま
  せん(同じ LAN にいる人が勝手に止められる口を作らないためです)。

※簡易パスワードを忘れたときは、「設定ファイルのフォルダを開く」から
  config.toml を開いて直します。アプリの中から戻す方法はありません
  (詳しくは操作説明書の「設定」の章にあります)。

※macOS・Linux 版(非公式対応)には通知領域のアイコンがありません。端末から
  起動し、その端末で停止してください。


■ 操作タイプについて
--------------------------------------------------
本アプリは「クラシック操作」を前提としています。技の入力表記とコンボのレシピ
は、すべてクラシック操作のコマンドで記録・表示されます。モダン操作の入力表記
には対応していません。

モダン操作で遊んでいる方も、キャラクター・技・フレームのデータはそのまま参照
できます。ただし、レシピに並ぶコマンドはクラシックの表記であり、そのまま入力
しても同じ技が出るとは限りません。

※モダン操作の表記と使用可否への対応は、今後の課題として残しています。


■ ポートについて
--------------------------------------------------
既定では 47318 番ポートを使用します。このポートが他のアプリで使用中の場合、
自動的に次の空きポート(47319, 47320, ...)へフォールバックします。
実際に使用されたポートは起動ログおよび config.toml に記録され、ブラウザ
自動起動・URL 案内もその実ポートを使用します。利用者がポート番号を意識する
必要はありません。


■ スマートフォン/タブレットからの利用(同一 LAN)
--------------------------------------------------
同じ Wi-Fi(LAN)内のスマホ・タブレットからアクセスするには、LAN 共有モードに
切り替えます。

■方法 A(推奨): 設定画面から切り替える
  1. アプリを起動し、画面の「設定」→「ネットワーク」を開きます。
  2.「LAN 共有モード」のスイッチをオンにします。確認ダイアログが出るので、
     内容(公開されるポート番号・外部公開の注意)を確認して「有効にする」を
     押します。
  3. アプリを再起動します(モード変更は再起動後に反映されます)。

■方法 B: 設定ファイルを直接編集する
  1. 一度起動して終了し、生成された config.toml を開きます。
  2. [server] セクションの mode を "local" から "lan" に変更します。
       [server]
         mode = "lan"

再起動すると、起動時に logs/ 配下のログへ、スマホからの
アクセス先 URL(例: http://192.168.x.x:47318/、検出した IP 候補を複数列挙)が
表示されます。スマホ側のブラウザでその URL を開いてください。設定画面の
「ネットワーク」からも URL・QR コードを確認できます。

※LAN モードでは同一ネットワーク内の他端末からアクセス可能になります。
  信頼できるネットワークでのみ使用してください。

★ スマホから接続できないときは、まず次の「うまく接続できないとき」を
  確認してください(最も多い原因はファイアウォール/ウイルス対策ソフトです)。


■ スマホから接続できないとき(トラブルシューティング)
--------------------------------------------------
LAN モードにしてもスマホから開けない場合、次の順に確認してください。

【1】ファイアウォール / ウイルス対策ソフトの許可(最頻出の原因)
  Windows は既定で、外部からの着信接続(inbound)をブロックします。本アプリの
  着信を許可してください。
    ・Windows Defender ファイアウォールの場合:
        コントロールパネル
          →「Windows Defender ファイアウォールを介したアプリまたは機能を許可」
          →「設定の変更」→「別のアプリの許可」で Tacpendium の実行ファイルを追加
          →「プライベート」にチェックを入れて OK。
      または、管理者として開いたコマンドプロンプトで次を実行:
        netsh advfirewall firewall add rule name="Tacpendium" dir=in ^
          action=allow program="(tacpendium-windows-amd64.exe のフルパス)" ^
          enable=yes profile=private

  ※重要: サードパーティ製のウイルス対策/セキュリティソフト(例: Norton、
    McAfee、ESET 等)を入れている場合、Windows 標準のファイアウォールが
    無効化され、そのソフトが代わりに着信を制御していることがあります。
    その場合、Windows 側の設定を変えても効果がなく、お使いのセキュリティ
    ソフト側で本アプリ(またはポート 47318)の着信許可を行う必要があります。
    設定方法は製品ごとに異なるため、各ソフトのヘルプをご確認ください
    (本アプリ側ではサードパーティ製品の挙動までは保証できません)。

  切り分けのため、一時的にファイアウォール/セキュリティソフトを無効にして
  接続できるか試す方法もあります(確認後は必ず元に戻してください)。

【2】PC 自身で LAN IP を開けるか確認
  PC のブラウザで、localhost ではなく LAN IP(例: http://192.168.x.x:47318/)を
  開いてみてください。
    ・開ける  → サーバーは正常。原因はファイアウォール【1】かネットワーク【3】。
    ・開けない → 上記【1】のブロック、または表示 IP が PC の実 IP と不一致。
                Windows で「ipconfig」を実行し、実際の IPv4 アドレスが
                アプリ表示の IP と一致するか確認してください(有線と無線で
                複数 IP がある場合は、スマホと同じネットワーク側の IP を使用)。

【3】同じネットワークに繋がっているか確認
  ・スマホと PC が同じ Wi-Fi/ルーターに接続されているか
    (ゲスト Wi-Fi は別ネットワーク扱いのことが多い)。
  ・ルーターの「AP アイソレーション/プライバシーセパレーター」が有効だと、
    同じ Wi-Fi でも端末間の通信が遮断されます。無効化を検討してください。
  ・PC が有線・スマホが無線でも、同一サブネットなら通常は接続できます。


■ データの保存場所と注意事項
--------------------------------------------------
- コンボ・タグ・セットプレイ等のデータは SQLite データベース
  (tacpendium.db)に保存されます。既定の保存場所は OS ごとに以下のとおりです。
      - Windows : %APPDATA%\tacpendium\tacpendium.db
      - macOS   : ~/Library/Application Support/tacpendium/tacpendium.db
      - Linux   : ~/.local/share/tacpendium/tacpendium.db
                  (XDG_DATA_HOME を設定している場合はその配下)
  バックアップは、上記の tacpendium.db ファイルをコピーしてください。
- アプリを更新する際は、実行ファイルのみ差し替えてください(データベースは
  上記の場所に、config.toml は起動フォルダに残るため、そのまま引き継げます)。
- 不具合に遭遇した場合は、起動フォルダの logs/ 配下のログを確認してください。
