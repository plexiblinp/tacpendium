## 2. 修正概要

### DES-003 §3.4（combos・消費 2 列・型差）
- **`sa_gauge_consumed`（INTEGER・NULL 可・0〜6）** ＋ **`drive_gauge_consumed`（REAL・NULL 可・0〜20・0.5 刻み）** を追加。CHECK 不使用。
- **型差を明記**: SA 消費＝整数（全層 `int`／CSV 正準整数／FE `.int()`）・drive 消費＝0.5 小数。将来 SA を 0.5 本単位で消費する要望が出た場合は SA も再構築型変更（M16-01 相当）が要る旨を注記。
- SA の範囲差（始動 0〜3・消費 0〜6）＝コンボ中に SA が溜まり始動より多く使えるため。

### DES-005 §5.6（詳細）・§5.7（登録/編集）・§5.8（比較）・§5.4（一覧）
- §5.7: 消費入力欄 2 つ（SA＝整数ステッパー・drive＝0.5 小数）。**始動と消費をラベルで判別可能に**（※上限クランプは F-1(a) 実装後に追記＝§5）。
- §5.6: 詳細に消費を表示（始動と区別）。
- §5.8: 比較に **ゲージ 4 行（drive 始動残量 / SA 始動残量 / drive 消費 / SA 消費）を連続ブロック**で掲載（追補・A-1 非対称解消）。比較行ラベルは「始動残量」（開発者指定・暫定＝M16-06 で正典化）。
- §5.4: **一覧の表示列カスタマイズには始動/消費を追加しない**（過密回避・現状維持）を明記。

### DES-002 §7.6（CSV 後方互換・任意列の正典化）
- 消費 2 列を **CSV「任意列」として列末尾追加**（`requiredImportColumns`＝全列−消費 2 列で必須列判定。旧 CSV〔消費列なし〕の import を VAL-I04 で落とさない）。
- **CSV 列契約を「必須列（欠けたら VAL-I04）」と「任意列（往復するが欠けても可＝後方互換の新列）」の 2 種に正典化**。**以後 combos に列を足す際は「任意列として列末尾追加」を標準**とする。消費列が JSON blob 列（tags/recipe）より後ろに並ぶのは後方互換のための意図的順序。

## 4. M16-06 送り事項の記録（開発者指示「記録しっかり」・A-1/A-3）

> M16-06（表記 rollout）で回収する。**放置すると表記ゆれ・非対称が恒久化**するため、overview §4.6 と本レポートに明記し取りこぼしを防ぐ。

1. **A-3 始動/消費ラベルの横断正典化**: 比較「始動残量」／詳細「開始残量」の**同一概念 2 表記の並立**（意図的暫定）を統一。en の始動 `(start)`／消費 `consumed` の**語法非対称**を解消。**詳細・比較・入力欄・エクスポートを横断**して始動/消費ラベルを一括正典化（ja/en 両ロケール parity）。FB⑨⑬ と同時。
2. **A-1 エクスポートカードへの消費項目追加**: 詳細・比較に消費が出るのに**画像/クリップボード・エクスポート（`combo-io`・`ExportItemKey` opt-in）には未掲載**＝「始動はエクスポートできるが消費はできない」非対称。新 `ExportItemKey`（例 `saConsumed`/`driveConsumed`）＋ UI トグル＋ export-model 行を M16-06 で新設（DES-005 エクスポート項目定義に反映）。
3. **F-1(a) UI クランプ**: 消費入力欄の上限クランプ（暫定・① 維持）は M16-02 追補として実装 → 実装後に DES-005 §5.7・DES-006 §2.4 を反映（M16-06 の表記正典化とは別系統）。
