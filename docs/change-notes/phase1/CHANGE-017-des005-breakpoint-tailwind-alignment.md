## 1. 改訂の背景

### 1.1 発見の経緯

M7-RESEARCH-02(M1〜M4 レスポンシブばらつき調査、2026-05-27 完了、Opus 4.6 実施)の §4.5 (a) で、設計書本体記述と実装の乖離が 9 件発見された。そのうち #3 #4 は **DES-005 §4.4 規定値と `tailwind.config.js`(デフォルト設定のまま)の乖離** に該当する。

### 1.2 乖離の事実

DES-005 §4.4 原文(現状 v2.9.0):

> TailwindCSSの標準ブレークポイントを使用。
>
> - スマホ:〜640px(sm未満)
> - タブレット:641px〜1024px(md、lg)
> - PC:1025px〜(xl以上)

実装の事実(M7-RESEARCH-02 §4.1 (c) 確認結果):

- `web/tailwind.config.js` はデフォルト設定のまま(`theme.extend` 内に `screens` 拡張なし)
- Tailwind デフォルト値: `sm` = 640px / `md` = 768px / `lg` = 1024px / `xl` = 1280px / `2xl` = 1536px

乖離の内訳(M7-RESEARCH-02 §4.2 (b) より):

| 範囲 | DES-005 規定 | Tailwind デフォルト | 整合状況 |
|------|-------------|-------------------|----------|
| スマホ | 〜640px(sm 未満) | sm = 640px(640px 未満が sm 未満) | **一致** |
| タブレット | 641px〜1024px(md、lg) | md = 768px, lg = 1024px | **差異あり**:641px〜767px は Tailwind では `sm`(640px〜767px)に該当 |
| PC | 1025px〜(xl 以上) | xl = 1280px | **差異あり**:1025px〜1279px は Tailwind の `lg`(1024px〜1279px)に該当 |

### 1.3 改訂の必要性

DES-005 §4.4 冒頭で「TailwindCSSの標準ブレークポイントを使用」と明記している一方で、後続の境界値記述が Tailwind 標準と齟齬を生じている。この乖離は M7-03(系統 C: レスポンシブ仕上げ)の着手前に解消する必要がある。理由:

1. **製造担当が DES-005 §4.4 を参照して Tailwind 設定をカスタマイズする可能性**: 規定通りに実装しようとすると `tailwind.config.js` の `theme.screens` カスタマイズが必要となり、Tailwind 慣例(640/768/1024/1280)から外れる
2. **shadcn/ui 統一導入(M7-01)との整合性**: shadcn/ui のデフォルト前提は Tailwind 標準ブレークポイント値。`theme.screens` のカスタマイズは shadcn/ui の動作前提と齟齬を生じる可能性
3. **M7-RESEARCH-01 報告書特記事項 7 で発見された architecture-patterns §1 分離パターン逸脱対応(M7-02 統合)** との作業順序整合: M7-03 着手前に DES-005 規定が確定していると、M7-03 指示書の Plan Mode 判断が容易になる

## 2. 改訂内容

### 2.1 改訂方針

**案 P-α 採用**(M7-RESEARCH-02 結果評価時に開発者承認 2026-05-27):DES-005 §4.4 規定を **Tailwind 標準に合わせて改訂** する。`tailwind.config.js` のカスタマイズは行わない。

採用しない案(参考):

- **案 P-β**(`tailwind.config.js` を DES-005 規定値に合わせてカスタマイズ):Tailwind 慣例から外れて将来的に shadcn/ui 等との整合性問題を引き起こす可能性、不採用

### 2.2 改訂対象節

`docs/design/05-screen-design.md` §4.4「レスポンシブブレークポイント」

### 2.3 改訂前(v2.9.0)

```markdown
### 4.4 レスポンシブブレークポイント

TailwindCSSの標準ブレークポイントを使用。

- スマホ:〜640px(sm未満)
- タブレット:641px〜1024px(md、lg)
- PC:1025px〜(xl以上)
```

### 2.4 改訂後(v2.10.0)

```markdown
### 4.4 レスポンシブブレークポイント

TailwindCSSの標準ブレークポイントを使用(`tailwind.config.js` はデフォルト設定のまま運用、`theme.screens` 拡張なし)。

- スマホ:〜639px(sm 未満)
- タブレット:640px〜1279px(sm、md、lg)
- PC:1280px〜(xl 以上)

注:本規定は CHANGE-017(2026-05-27)で Tailwind 標準値に整合化したもの。それ以前は規定値と実装の境界値に齟齬があった(タブレット範囲 641px〜1024px / PC 範囲 1025px〜と記載)。M7 期間で改訂、`tailwind.config.js` 側のカスタマイズは行わない方針を採用した(CHANGE-017 §2.1 参照、playbook §17.2 個人開発の規模感 + shadcn/ui 統一導入との整合性確保)。
```

### 2.5 改訂の影響範囲

**設計書本体改訂のみ**。実装(`tailwind.config.js`)への影響なし、製造担当が参照する規定値が変わるが、現状実装はすでに Tailwind 標準に従っているため、改訂後の規定と実装が **一致** する状態になる。

他の設計書本体(REQ-001 / DES-001 / DES-002 / DES-003 / DES-004 / DES-006)への影響なし。補足資料(SUPP-001 / playbook / handover / retrospective-log / architecture-patterns / change-number-registry)への影響は change-number-registry の §1 / §3 への追記のみ(後述 §5 派生作業)。

- **SUPP-001 §4.6**(レスポンシブ対応タイミング): 境界値は明示なし、影響なし

| 範囲 | DES-005 改訂後 | Tailwind デフォルト | 整合状況 |

| スマホ | 〜639px(sm 未満) | sm = 640px(640px 未満が sm 未満) | **一致** |
