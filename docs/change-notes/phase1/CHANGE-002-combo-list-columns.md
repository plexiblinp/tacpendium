# CHANGE-002: コンボ一覧・マイコンボの表示項目再構成

- 対象: DES-005 §5.4（コンボ一覧）、§5.5（マイコンボ）
- 発見経緯: M0-01 開発者目視レビュー

## 変更内容

### 列構成の変更

1. **「ステップ数」列を削除** — ユーザーにとって有用性が低い。§5.4, §5.5, §5.8（比較画面）の3箇所から削除
2. **「相手スタンス」を一覧表示から削除** — 不要なキャラも多く、一覧では冗長
3. **列の先頭に「始動状況」グループ列を追加** — 始動技 + カウンター種別 + ポジション をまとめて表示し、コンボの識別性を向上
4. **「備考（メモ）」列を追加** — 短いメモをテーブル上で確認可能に
5. **「登録状態」列を追加** — 仮登録バッジだけでなく、本登録・仮登録を明示的に表示

> ※「コンボ名」列はプロトタイプで試した結果、冗長であったため追加しないことに変更（M0-01 開発者目視レビュー確認済み）

### ソート関連の変更

7. **デフォルトソートを「始動状況」に変更** — 現行の未定義状態からデフォルトを明示
8. **ソートの昇降ラベルを項目に応じた自然な表現に変更** — 例: 日時→「最近/昔」、ダメージ→「大きい順/小さい順」

### その他

9. **コンボ一覧・マイコンボ画面にエクスポートボタンを追加** — ファイル種別を選べるエクスポート導線
