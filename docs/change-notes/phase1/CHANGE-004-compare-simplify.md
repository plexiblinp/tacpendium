# CHANGE-004: コンボ比較画面の簡素化

- 対象: DES-005 §5.8（コンボ比較）
- 発見経緯: M0-01 開発者目視レビュー

## 変更内容

1. **「表示項目選択チェックボックス」を削除** — §5.8 item 2 を除外。全項目を常時表示に変更
2. **「エクスポート」アクションを削除** — §5.8 のエクスポート機能を除外。比較画面からの直接エクスポートは不要
3. **ステップ数行を削除** — CHANGE-002 と連動
4. **起き攻め表示形式を変更** — 受け身種別ごとに分離し、ドライブラッシュ(DR)有無を明示:
   - 起き攻め（その場受け身）　DR無: ✓ / DR有: ✗
   - 起き攻め（後ろ受け身）　DR無: ✓ / DR有: ✓
5. **knockdown_advantage（有利フレーム）を起き攻めセクションから分離し独立行に**
6. **セットプレイ表示を件数→内容に変更** — 「N件」ではなく名称一覧（名前未設定時はレシピ先頭）を表示
