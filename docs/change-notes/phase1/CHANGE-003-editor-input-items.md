# CHANGE-003: エディタ画面の入力項目見直し

- 対象: DES-005 §5.7（コンボ編集）、§5.9（セットプレイ編集）、DES-003（データモデル）
- 発見経緯: M0-01 開発者目視レビュー

## 変更内容

### combo-editor（DES-005 §5.7）

1. **「キャラ固有状態」ラベルから内部識別子サフィックスを削除** — §5.7 item 5 のラベル表記を `キャラ固有状態（situation JSON）` → `キャラ固有状態` に変更。フィールド自体は残す
2. **「有利フレーム」ラベルから内部識別子サフィックスを削除** — §5.7 item 9 のラベル表記を `有利フレーム（knockdown_advantage）` → `有利フレーム` に変更。フィールド自体は残す。入力欄の幅を3桁相当（w-24）に縮小
3. **opponent_stance に「どちらでも可」を追加** — 一部のコンボはスタンスに依存しないため。DES-003 の opponent_stance 許容値にも反映が必要

### setup-editor（DES-005 §5.9）

4. **「紐づくコンボ（複数選択可）」を削除** — §5.9 item 5 に記載があるが、誤操作リスクが高いためUI上の入力欄を除外。設計担当への確認事項とする

### データモデル（DES-003）

5. **opponent_stance の許容値に「any」を追加** — コンボがスタンスに依存しないケースに対応
