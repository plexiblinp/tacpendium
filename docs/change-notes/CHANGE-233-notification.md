## 1. ★★★何が変わったか

**★`CHANGE-129`**（`M24-09a`・2026-08-20）**が定めた「★2 本立てとする」が失効した。⇒ リリース区分が 3 本目として立った。**

| 区分 | 契機 | 状態 |
|---|---|---|
| PR 検査 | PR と既定ブランチへの push | **不変** |
| nightly | 1 日 1 回の定時 | **不変**（**★1 バイトも触っていない**） |
| **★リリース** | **タグ `v*` の push**（＋ 公開しない `workflow_dispatch` の dry-run） | **新設** |

## 2. ★★★`CHANGE-129` §4 を明示的に撤回する

**★★旧決定の逐語＝「Releases への自動添付＝作らない。公開の手番は人が持つ」。**

**★★★本サブはこれを覆している。⇒ `gh release create` が CI から自動でリリースを作り、資産を添付する。**

**★★黙って上書きされた状態にしないため、本 CHANGE で*明示的に*撤回する。**

**★★指示書の命令である**（`M36-02` §2.6-1＝「リリース成果物を CI から出す。手元のマシンからアップロードしない」。出典は `license-strategy-outline` §10.6 の逐語であり **2026-09-12 の開発者判断**）**。⇒ 製造の独自判断ではない。**

---

## 3. ★★★安全性の根拠は*ゲート*ではなく*構造*である

**★★開発者の懸念の逐語**（2026-09-20）**＝「誤って CI が動いてしまい、公開するつもりのなかったバージョンが公開されること」。⇒ `CHANGE-129` が守りたかったものも、要するにこれである。**

| # | 塞ぎ方 | 出所 |
|---|---|---|
| **★★★1** | **リポジトリを分ける。⇒ 公開用 `tacpendium` と開発用 `combomgr`。★公開側は「ちゃんと動いた後で同期する」** | **開発者**（2026-09-20・確定事項） |
| **★★2** | **`release.yml` を public リポジトリ限定にする**（`if: github.event.repository.private == false`） | **開発者裁定**（2026-09-20） |

**★★★非公開の開発リポでは、タグを打っても `release` job がそもそも起動しない。⇒ 「気をつける」ではなく「起こりえない」形になった。**

**★★★したがって正確な言い方はこうである**——**「CI からの自動公開を許すが、それは*公開リポジトリでのみ*であり、公開リポへ内容が渡るのは開発者が同期を実行したときだけである」。⇒ 自動化されたのは「公開リポにタグが入った後」だけであり、*何を公開リポへ入れるか*は依然として人の判断である。**

**★★人の手番が消えたわけではない＝タグを打つのは人であり、署名するのも人である。**

## 4. ★★public 限定ガードの理由は 2 つある（**★どちらも書くこと**）

| # | 理由 |
|---|---|
| **★★1** | **attestation は private / internal リポジトリでは取れない**（GitHub Enterprise Cloud を除く） |
| **★★2** | **開発リポへのタグは公開スナップショット生成の正規の契機である**（`D-637`）**。⇒ ガードが無いと、生成のたびリリース区分が赤くなる** |

**★★1 つ目だけを書くと、ガードを外してよい条件を誤読する。⇒ 2 つ目は GHEC へ移っても消えない。**

## 5. ★★★契約 9 を足した

> **タグ署名の検証は、鍵が未登録なら*明示的に落ちる*こと。**

**★素通りさせると、署名していないものを署名済みとして配ることになる。**

**★★本契約は契約 1**〔結果キャッシュ〕**・契約 2**〔パイプの終了コード〕**・契約 6**〔`gofmt` の終了コード〕**・契約 8**〔ANSI エスケープ〕**と同じ型の 5 本目である。⇒ 「走ったが何も見ていない」「失敗したのに緑」を作る道。**

**★実装は `git verify-tag` ＋ `.github/allowed_signers`。⇒ 公開鍵が台帳に無ければ git は信頼度を `undefined` とし検証は失敗する**〔`git/git` の `Documentation/config/gpg.adoc`〕**。**
