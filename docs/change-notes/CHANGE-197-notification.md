## 1. なぜ要るか

### 1.1 ★★同じ画面の 2 つの表が食い違っていた

| 実体 | 着手前の並び |
|---|---|
| **コンボ** | **`starter_move_id` / `position` / `hit_type` / `opponent_stance` / `opponent_size` / `id` の昇順**＝通常一覧と同じ始動状況順 |
| セットプレイ | **`deleted_at DESC, id DESC`** |

**★原因＝ゴミ箱のフックが `sort` / `order` を送らず、whitelist に無い値が既定分岐へ落ちていた。**

**★★セットプレイ側のコードコメントは当初から意図を書いていた**〔逐語＝「並びは削除日時の新しい順（ゴミ箱は直近に消したものから探す）」〕**。⇒ コンボ側だけがその意図を満たしていなかった。**

### 1.2 ★★★`DES-005` §5.15 は並び順を一言も規定していなかった

**★同節は「削除日時」を*表示する*とだけ定めている。⇒ 本件は既存記述の訂正ではなく*追記*である。**

**★★★規定が無いところに実装の食い違いが生まれた。⇒ 「書いていない」は「どちらでもよい」ではなかった。**

## 2. 変更内容

### 2.1 `DES-005` §5.15 — 並び順を追記する

| 項目 | 内容 |
|---|---|
| **既定の並び** | **コンボ・セットプレイとも `deleted_at` の降順。⇒ 直近に消したものから探せるようにする** |
| **副次キー** | **`id` の降順** |
| **★★副次キーが要る理由** | **`deleted_at` は `datetime('now')` の秒精度である。⇒ 同じ秒に消した 2 行は日時だけでは順序が決まらず、`LIMIT` / `OFFSET` のページ境界で重複・欠落が起こりうる** |
| **並び替え UI** | **★足さない**（2026-09-13 開発者裁定）**。⇒ 既定を直すだけにする。★API 側は受け口を持つため、後から UI を足すときサーバ側の変更は要らない** |

### 2.2 `DES-002` §4.2 —`GET /api/combos` の `sort` が `deleted_at` を受理する

**受理する値の全数**＝`default` / `updated_at` / `damage` / `step_count` / `starter_move_id` / **`deleted_at`**〔新規〕**。**

**★whitelist に無い値は拒否されず既定へ落ちる**〔従来どおり。400 は返さない〕**。**

| 要求 | 並び |
|---|---|
| `only_deleted=true` ＋ `sort` 未指定 | **`deleted_at DESC, id DESC`**〔新〕 |
| `only_deleted=true` ＋ `sort=deleted_at`〔＋`order=asc`〕 | `deleted_at` の指定方向 ＋ `id` の同方向 |
| **`only_deleted=true` ＋ `sort=default`** | **始動状況順 ＋ `id ASC`**〔★下記〕 |
| `only_deleted` 無し〔通常一覧〕 | **★従来どおり不変。⇒ `sort` 未指定なら始動状況順 ＋ `id ASC`** |

### 2.3 ★★★持たせなかった分岐（**誤読を防ぐため明記する**）

| # | 持たせなかったもの | 帰結 |
|---|---|---|
| **1** | **`sort=deleted_at` を通常一覧で送っても拒否しない** | **★`deleted_at` が全行 NULL なので実質 `id` 順になるだけである** |
| **2** | **★★`sort=default` は「明示指定」として扱う** | **⇒ ゴミ箱で送ると始動状況順へ戻る。★これは意図どおりである**——**`default` は whitelist の 1 エントリであり「始動状況順で並べてくれ」という明示の要求だからである**〔一覧の並び替えで「始動状況順」を選ぶと同じ値が飛ぶ〕**。★★将来ゴミ箱へ並び替え UI を足すときの落とし穴＝「既定へ戻す」操作に `sort=default` を使うと削除日時降順にならない** |
| **3** | **セットプレイ側**（`GET /api/setups`）**は 1 行も変えていない** | **★既に正しいため。⇒ `sort` パラメータも持たせていない** |
