## 1. なぜ要るか

### 1.1 ★★★開発者の実機確認で、入力の作りが変わった

**★`D-730` は「入力方式は 3 つで*連動する*」と定めていた。⇒ 3 方式を同時に出し、どれを動かしても他の 2 つが追随する形である。**

**★★開発者が実機で確認したのち、2026-09-13 に指示が出た**（逐語）**＝「入力方式を選んだ後、1 項目だけ入力させる方法に変えてもらえますか？」。**

**⇒ 3 方式の同時表示をやめ、方式を選んでから 1 欄だけ描く形になった。**

### 1.2 ★★連動そのものは失われていない

**★保存される値はマス数 1 本のままである**（`D-731`）**。⇒ 方式を切り替えると*同じ値が別の単位で見える*。**

**★★★だから「連動」の語を消すのではなく、*何が連動するのか*を書き直す。⇒ 「3 つの欄が追随する」ではなく「1 本の値が 3 通りに見える」である。**

### 1.3 ★値域外の扱いも変わった

**★開発者の逐語**（2026-09-13）**＝「他の項目と同じように所定の範囲外は画面的に入力できないようにしてもらえますか？」。⇒ 画面の一貫性が優先された。**

**★★防衛線は外していない＝zod と `VAL-RANGE` はそのまま残る。⇒ CSV / API から入る経路は画面を通らない。**

## 2. 変更内容

### 2.1 `DES-005` §5.7 — 入力 UI の as-built

| 画面要素 | as-built |
|---|---|
| 「始動位置」の**入力方式**（新設） | **3 択のピル**——「1 通常入力」／「2 パーセンテージ」／「3 マス目」。**★既定は通常入力**（`D-731`）**。★頭の数字は表示であると同時に押せるキーである** |
| 同・値の入力 | **★選んだ方式の 1 欄だけを描く。** 通常入力＝既存の区分ボタン 8 個〔**★選ぶと代表値のマス数が入る**〕／ マス目＝`0〜160` ／ パーセンテージ＝`0〜100` |
| 「運び量」の**入力方式**（新設） | **★2 択**〔マス目 / パーセンテージ〕**。⇒ 「通常入力」を持たない**（`D-731` 不変条件 2）**。既定はマス目** |
| 方式ボタンの**見た目** | **丸ピル ／ 選択色 `slate-700`**〔値のボタンは従来どおり角丸長方形・`blue-600`〕**。★左に「入力方式」と言葉でも書く** |
| 方式の**並び** | 始動位置＝**通常入力 → パーセンテージ → マス目** ／ 運び量＝**パーセンテージ → マス目**。**★★番号は並び順から導出する。⇒ ラベル文字列へ焼き込まない** |
| ⓘ（新設） | 始動位置の方式ボタン群の hint。文面＝「トレーニングモードで、自分が画面端にいる状態を 0、相手が画面端にいる状態を 160（100%）とします。」 |
| **値域外** | **★★入力段でクランプする**〔`161 → 160` ／ `-1 → 0` ／ パーセントは `101 → 100`〕**。⇒ 拒否ではない** |
| **保持** | **★入力方式は画面のローカル状態である。⇒ 保存もブラウザストレージへの保持もしない**（**★保持すると `web/CLAUDE.md` §1 の台帳へのキー追加になる**＝`CLAUDE.md` §10.X） |

**★★★保存されるのはマス数だけである**（`D-731`）**。⇒ パーセントは表示・入力の変換であり、フォーム state にも持たせない。**

**★丸めの向きは 1 か所＝表示は小数第 1 位へ四捨五入 ／ 入力は四捨五入 ＋ 0〜160 クランプ。★★小数第 1 位が往復不変の下限である**〔整数 % だと `1% = 1.6 マス` で壊れる〕**。**

**★★帰結が 1 つある＝パーセント欄からは値域外を作れない**〔クランプするため〕**。⇒ `161` / `-1` の拒否はマス欄からしか到達しない。**

## 3. ★★★`D-730` の改訂

| 旧 | 新 |
|---|---|
| **入力方式は 3 つで*連動する***〔従来の区分選択・マス数・パーセントの 3 方式を連動させる〕 | **★★入力方式を選んで 1 項目だけ入力させる。⇒ 値はマス数 1 本であり、方式を切り替えると同じ値が別の単位で見える** |

**★不変条件は変わらない。⇒ 始動位置と運び量は別の値である ／ 運び量は区分へ丸めない ／ 運び量は「通常入力」を持たない。**

**★物差し**〔0〜160 マス ／ 7 区分 ／ 代表値〕**も変わらない。**
