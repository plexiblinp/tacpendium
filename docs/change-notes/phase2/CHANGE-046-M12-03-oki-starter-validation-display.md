## 1. 変更の概要(過去最大の横断 = 3 設計書)

M12-03 完了に伴い、6 関心 + E2E フィードバック 2 件の end-state を DES へ反映:

- **R-1**: 起き攻め 6 BOOLEAN ラベルを正典語彙へ統一(編集/詳細/比較)+ 表示方式統一(比較を 6 BOOLEAN 個別へ)+ 有利フレーム `+nF` 統一。
- **C-12**: 始動技プルダウン除去・自動推定一本化。VAL-C03 は BE 維持。
- **C-03**: セットプレイ名必須(VAL-S06)。
- **C-08**: 紐付け候補を knockdown_advantage 一致へ(編集 + 詳細「既存から紐付け」)。
- **C-10/C-11**: drive_damage 詳細表示 + INTEGER→REAL・-6〜6 小数(VAL-C13)。
- **6.5-2**: drive_damage 入力ラベル「(-6.0〜6.0)」。

## 2. 変更の内容

### 2.1 DES-003(v1.22.0)
- `drive_damage`: **INTEGER→REAL**、値域 **-6〜6・小数許容**(回復で負値、1 本未満の増減で小数)。L101 mermaid `int`→`real`、L361 型・説明更新。CHECK 不使用維持・範囲は VAL-C13+UI 担保。マイグレ 000016(テーブル再構築)を注記。

### 2.2 DES-005(v2.25.0)
- **§5.6 詳細**: item2 に drive_damage 表示追加(C-10)。item6 起き攻めに正典語彙統一(重ね/シミー・その場/後ろ受け身・ドライブラッシュ、誤訳「中段攻め」解消=R-1)+ 有利フレーム `+nF` 統一。item10 に詳細「既存から紐付け」モーダルの knockdown 一致絞り込み(6.5-1)+ 「転用候補」との重複に関する UI 統合の要判断を注記。
- **§5.7 編集**: #4 始動技を自動推定・読み取り専用化(C-12、VAL-C03 は BE 維持)。#9 drive_damage 小数・負値入力 + ラベル「(-6.0〜6.0)」(C-11/6.5-2)。既存紐付け候補を knockdown 一致へ(C-08)。
- **§5.8 比較**: spec は既に 6 BOOLEAN 表示(その場/後ろ受け身・ドライブラッシュ無/有・シミー)で正しく、**実装が 2 行集約から spec へ追従**。**DES テキスト変更なし**(漏れ検知=実装側の整合)。
- **§5.9 セットプレイ**: #2 名前を任意→必須(C-03、VAL-S06)。

### 2.3 DES-006(v1.13.0)
- **VAL-C13 新設**: drive_damage 範囲(-6〜6・小数許容、ERROR)。create/promote 時に実行。**PATCH 単純更新では非実行**=既存 VAL-C04/C05 と一貫、FE zod が第一防衛線(設計判断=現状維持、§4-1)。
- **VAL-S06 新設**: セットプレイ名必須(空不可、ERROR、create/update 空クリア禁止)。
- **VAL-C03 は不変=維持**: 始動技プルダウン除去後も starter≠レシピ先頭 WARNING を API 直叩き対策として BE 残置(§10-2 確定、VAL-S05 補足の「API 単体使用時の防御」と整合)。
