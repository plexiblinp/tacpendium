## 1. 変更の概要

M12-05(seed 整理 + B-7 move_code 統一)の実装過程で、製造担当が次の不整合を報告した(申し送り §5・研究報告 A-2):

- seed(`000004_seed_moves_ryu` / `000010_seed_moves_aki_jamie_guile`)に **`dash_forward` / `dash_back`(category = system)** が実在する。
- 一方、正典の DES-004 §2.1「移動・ジャンプ動作」表には **dash 系の行が無い**(`micro_*` / `jump_*` は列挙済み)。

正典表の欠落を補完するため、DES-004 §2.1 に dash 系 2 行を追記する。**挙動変更を伴わない正典文書の完全化**である(seed・実装は既に dash 系を保持しており、表の記載が追従していなかった)。

## 2. 変更の内容(DES-004 v1.6.3)

### 2.1 §2.1 移動・ジャンプ動作表への追記

「移動・ジャンプ動作」表(`category = "system"` の移動動作一覧)に、`micro_back` と `jump_neutral` の間へ 2 行を追記:

| code | 意味 |
|------|------|
| `dash_forward` | 前ダッシュ（前方向のダッシュ移動） |
| `dash_back` | 後ろダッシュ（後方向のダッシュ移動／バックダッシュ） |

配置は地上移動グループ(`forward`/`back` → `micro_*` → `dash_*` → `jump_*`)として `micro_back` の直後とした。

## 3. 確定した設計判断

| 項目 | 判断 |
|------|------|
| dash 系を正典に含める | **含める**。`dash_forward`/`dash_back` は seed・取込双方に存在しうる正当な SF6 移動動作で、§2.1 の「技を出さない移動動作も system として登録」方針に合致する。表からの欠落は記載漏れであり補完する |
| §2.3 modifier flag `dash` との関係 | **別系統で不変**。§2.3 の `dash`(ダッシュ（前後）)は modifiers.flags の修飾フラグ。本 CHANGE の `dash_forward`/`dash_back` は独立した system move(`combo_steps.move_id` 参照)。両者は別概念のため §2.3 は変更しない |
| 日本語名 | 「前ダッシュ」「後ろダッシュ／バックダッシュ」。表示細部の調整余地は開発者にあり(§2.1 の意味列は内部表現の説明であり、利用者向けラベルではない) |
| seed の dash 系 | ryu に温存(M12-05 の B-7 は通常技/投げが対象で dash 系は新形化対象外)。本 CHANGE は seed を変更しない |
