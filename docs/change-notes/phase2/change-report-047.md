- **§5 共通要素 L125**: N-29 統一完了のトレーサビリティ追補(全系統が共通プルダウン、コンボ一覧の絞り込みフィルタのみ native `<select>` 維持=コンテキスト選択とは別役割)。
- ヘッダ: バージョン 2.26.0、ステータスに第37版(CHANGE-047)を前置。

- N-29 統一が「技マスタ編集 1 画面の共通化 + 一覧フィルタ native 維持」で実装(製造 §2-1/§2-2)と整合。`CharacterSelector` の `placeholder`/`ariaLabel` 後方互換プロップ追加・`pickMode` の `placeholder` 有無集約も DES に規定不要の実装詳細として確認。
