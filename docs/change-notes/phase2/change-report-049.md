## 2. 修正概要

### DES-002(v1.24.0)
- L304 付近「DBファイル配置」の「配置先は設定で変更可能とする」を、**アプリ既定データディレクトリ／実行時カレントディレクトリ配下に限る**(`..` トラバーサル・管轄外絶対パスを拒否)へ狭める。設定経由(config.toml / PUT /api/config)の `database.path` / `logging.file` がアプリ管轄外の既存ファイルを上書き・破損させる隙を封止。ステータス欄に CHANGE-049 を前置。

### SUPP-001(v1.25.0・補足資料)
- §5.8 設定ファイル例のコメント + 「`database.path` / `logging.file` のパス検証ポリシー」段落を追記(正典は DES-002)。前提文書欄を M12 完了時点の現行版へ追従。
