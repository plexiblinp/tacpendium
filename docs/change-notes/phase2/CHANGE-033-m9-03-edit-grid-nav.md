## 1. 変更の概要

M9-03 実装レビューで、moves 編集グリッド（画面18）が共通ヘッダーナビに未追加で発見性が低い指摘（#5）があった。導線配置を DES-005 §4.1 に明記する。

- **画面18 は主要ナビ（コンボ一覧/マイコンボ/プリセット/設定）には並べず、「設定」配下（データ管理）に導線を置く**。データ整備系の管理機能のため、利用頻度の高い主要ナビとは分離する（設計担当推奨、開発者非上書き）。
- 取込 commit 後（画面17）からの遷移も併せて導線とする。

---

## 2. 変更の理由

- **発見性の確保**: 画面18 が URL 直叩き以外で到達不能だと機能が埋もれる（レビュー #5。retrospective-log M6-6＝ヘッダーナビ追加漏れと同系統の再発）。
- **主要ナビに置かない理由**: 編集グリッドは取込データの管理的補正（FR703）で、コンボ一覧/マイコンボ等の日常導線とは性質が異なる。主要ナビの肥大を避け「設定」配下に置く。

---

## 3. 変更の内容

DES-005 §4.1 ヘッダの「主要ナビゲーション」行に、画面18 の導線配置を補足する注記を追加する（主要ナビ項目自体は不変）。

> 注記（追加）: moves 編集グリッド（画面18、FR703）への導線は**主要ナビゲーションには含めず、「設定」（画面16）配下のデータ管理導線として配置**する。取込プレビュー（画面17）の commit 後遷移も導線とする（CHANGE-033）。
