## 1. 変更の概要

DES-003 §3.3 の `total`（全体硬直）算出式は、現行では「格闘ゲーム仕様前提＝開発者が定義する（製造工程の着手前確認事項）」というプレースホルダ（§3.3 末尾注記、L332）になっている。これを開発者が定義・承認済みの具体式（案B、2026-06-10）へ置き換える。

> **total = 発生 + 持続 − 1 + 硬直**（`startup + active − 1 + recovery_frames`）

本 CHANGE は §3.3 末尾注記の**文言具体化**であり、スキーマ（列・型・制約）・enum・API・画面仕様は変更しない。M9-02（FR704 取込時 total 算出）の着手前提を設計書本体へ確定させる。

---

## 2. 変更の理由

- M9-02（FR704）は取込時に CSV の発生・持続・硬直から `total` を算出して格納する（DES-003 §3.3 L269、DES-002 §7.5 L390/L401）。この算出の確定式が実装の必須前提となる。
- DES-003 §3.3 L332 は CHANGE-022 時点で「算出式は格ゲー仕様前提＝開発者が定義する（製造工程の着手前確認事項）」とプレースホルダ化されていた。開発者が 2026-06-10 に案B を定義・承認済み（m8-to-m9-handover §2）。M9-02 着手前に設計書本体へ正式記載し、製造担当が参照できる状態にする。
- `−1` の根拠: 発生（startup）の最終フレームと持続（active）の初フレームが同一フレーム上で重複するため、単純合算では全体硬直が1フレーム過大になる。これを補正する。

---

## 3. 変更の内容

### 3.1 DES-003 §3.3 末尾注記（L332）の改訂

**現行（DES-003 v1.18.0）**:

> **硬直（recovery）は `moves` に保持しない**。取込ツール出力CSVが公式の発生・持続・硬直を保持し、本体は取込時にこれらから `total`（全体硬直）を算出して格納する。`total` の内訳が必要な場合は取込元CSVを参照する。`total` の算出式は格闘ゲーム仕様前提＝開発者が定義する（製造工程の着手前確認事項）。

**訂正後**:

> **硬直（recovery）は `moves` に保持しない**。取込ツール出力CSVが公式の発生・持続・硬直を保持し、本体は取込時にこれらから `total`（全体硬直）を算出して格納する。`total` の内訳が必要な場合は取込元CSVを参照する。
>
> **`total` の算出式（案B、開発者定義 2026-06-10、CHANGE-028）**:
> ```
> total = 発生 + 持続 − 1 + 硬直
>       = startup + active − 1 + recovery_frames
> ```
> - `−1` は、発生の最終フレームと持続の初フレームが同一フレーム上で重複するための補正（単純合算は1フレーム過大になる）。
> - `硬直`（recovery_frames）は、CSV `recovery`（公式原文の文字列）を解釈して得た整数フレーム。recovery の取り得るパターン（整数 / `全体 N` / `着地後N` / `N+着地後M` / `N-着地まで` / `[※2] 1-12` / 空欄）は DES-002 §7.5 を正とし、文字列→整数フレームの解釈ロジックは M9-02（FR704）で設計する。
> - **算出に必要な値（発生・持続・硬直）のいずれかが空欄または解釈不能で算出できない場合は `total = NULL`**（CHANGE-025。実測で発生・硬直とも空欄の行が11件存在）。
> - 公式「備考」の「空振り時硬直 N フレーム増加」等は、取込側で式に算入しない。利用者が備考を読んで FR703 で手動微修正する（DES-003 §3.3 既定）。

### 3.2 DES-003 §3.3 `total` 列説明（L269）の参照文整合更新

**現行**:

> 全体硬直。本体が取込時にCSVの発生・持続・硬直から算出して格納する正準の利用値（算出式は格ゲー仕様前提＝開発者定義、§3.3末尾注記）。**算出に必要な値が空欄で算出不能の場合はNULL**（CHANGE-025）。硬直（recovery）単体はmovesに保持しない（CHANGE-022）

**訂正後**（参照文のみ更新、意味は不変）:

> 全体硬直。本体が取込時にCSVの発生・持続・硬直から算出して格納する正準の利用値（算出式 = `発生 + 持続 − 1 + 硬直`、§3.3末尾注記、CHANGE-028）。**算出に必要な値が空欄で算出不能の場合はNULL**（CHANGE-025）。硬直（recovery）単体はmovesに保持しない（CHANGE-022）

## 6. リスク

| リスク | 内容 | 緩和策 |
|--------|------|--------|
| 持続（active）NULL 行の total | active が NULL（弾系で公式持続が空欄、CHANGE-022）だと式が成立しない | 発生・持続・硬直のいずれか欠落なら `total = NULL`（§3.1）。NULL 伝播規則を M9-02 で明示し、取込プレビューで要確認強調 |
| recovery 文字列の解釈漏れ | `全体 N` / `着地後N` / `[※2] 1-12` 等から硬直フレームを抽出する際、列挙外パターンが将来キャラで出現 | 未知パターンは算出不能扱い（total=NULL）+ 要確認強調、FR703 で手動補正（CHANGE-026 と整合） |
| `−1` の一律適用 | 一部技で発生・持続の定義境界が異なり、`−1` 補正が実フレームと1F乖離する可能性 | 取込後に実測突合（開発者）+ FR703 手動微修正で吸収。式は開発者承認の既定とする |
| 空振り時増加Fの不算入 | 「空振り時硬直 N 増加」を式に含めないため、空振り時の total が実値と異なる | 仕様どおり（DES-003 §3.3）。利用者が備考を読み FR703 で手動補正。プレビューで該当語を要確認強調 |
