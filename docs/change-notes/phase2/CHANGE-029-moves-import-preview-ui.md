## 1. 変更の概要

M9-02（FR704 アプリ取込）で取込プレビュー UI と `/preview` エンドポイント（別経路方式）を新設するため、設計書本体を 2 点改訂する。

1. **DES-002 §4.2**: `POST /api/import/moves/preview`（dry-run・DB 書込なし）を追加し、既存 `POST /api/import/moves` を commit（行単位 upsert）と位置づける。
2. **DES-005**: moves 取込プレビュー画面を新設する（§2 画面一覧に画面17 + §5.17 詳細）。

スキーマ・データモデル・enum・CSV 契約は変更しない（M9-02 のそれらは CHANGE-022 / 025 / 026 / 027 / 028 で確定済み）。本 CHANGE は UI 画面とエンドポイント経路の追加のみ。

---

## 2. 変更の理由

- **DES-005 UI 未定義**: DES-005 §5.14「インポート」はコンボ CSV（FR405、画面14）専用で、moves 取込（FR704）の取込プレビュー UI が未定義（m9-overview §6 の判断）。M9-02 は取込プレビュー（行選択・要確認強調・行単位レポート）を実装するため画面定義が要る。
- **DES-002 §4.2 に preview 経路なし**: M9-02 は preview（dry-run・書込なし）+ commit の**別経路方式**に決定（指示書 §4.1、開発者一任 2026-06-14。拡張性・保守性・誤書込防止・2 段階検証思想への適合が根拠）。DES-002 §4.2 は commit 単一（`POST /api/import/moves`）しか定義しておらず、`/preview` の追加が要る。
- **M9-03 は対象外**: M9-03（グリッド編集・ラッシュ版生成等）の UI は本 CHANGE では扱わない（M9-03 設計時に別途起票）。本 CHANGE は M9-02 の取込プレビューに限定する。

---

## 3. 変更の内容

### 3.1 DES-002 §4.2: 取込 preview エンドポイントの追加

§4.2 のエンドポイント表に次の行を追加する（既存 `POST /api/import/moves` の直前または直後）。

| メソッド | パス | 説明 |
|---|---|---|
| POST | `/api/import/moves/preview` | moves 取込の dry-run プレビュー（FR704、フェーズ2）。取込ツール出力 CSV を解析し、`total` 算出・`properties` 正規化・category 写像・要確認判定を行い、**行ごとの確定値 + 要確認フラグ + 検出エラーを返す（DB 書込なし）**。CSV フォーマットは §7.5 参照 |

既存 `POST /api/import/moves` の説明を、preview と対になる commit として補足する。

> 訂正後（`POST /api/import/moves`）: moves・キャラクターデータの CSV 取込（FR704、フェーズ2）。**`/api/import/moves/preview` でプレビューした行のうち選択された行を、characters → moves → preset_aliases の依存順で行単位 upsert する（commit）。** 解析・算出・正規化は preview と共通のサービス層を用いる。CSV フォーマットは §7.5 参照

### 3.2 DES-005 §2 画面一覧: 画面17 の追加

§2 画面一覧の末尾に次を追加する（既存最大は画面16「設定」）。

| No | 画面 | 概要 | 備考 |
|---|---|---|---|
| 17 | moves 取込プレビュー | フレームデータ CSV（FR701 ツール出力）の取込プレビュー・行選択・実行 | コンボ CSV インポート（画面14）とは別系統 |

### 3.3 DES-005 §5.17: moves 取込プレビュー画面（新設）

§5 に次の節を新設する。

> ### 5.17 moves 取込プレビュー
>
> **表示項目**:
> 1. ファイル選択（moves CSV。FR701 取込ツールの出力 CSV）
> 2. プレビュー領域（取込内容の確認。`/api/import/moves/preview` の結果を表示。DB 未書込）
>    - 各行にチェックボックス（取込対象選択、既定は全行チェック済み）
>    - 行ごとに確定値を表示（算出後 `total`・正規化後 `properties`・写像後 `category`）
>    - **要確認強調**: recovery 要確認語（空振り/増加/減少/全体/変化）含む行 / `total` が NULL の行 / 未知の combo_scaling キーを含む行 / 未知 properties の行 / 通常投げ 3 件目以降 / 検出エラー行
> 3. 取込実行ボタン
> 4. 実行後の行単位レポート（成功 / スキップ / 失敗 + 理由）
>
> **アクション**: ファイル選択 → プレビュー（`/api/import/moves/preview`、DB 書込なし）→ 行選択 → 実行（`/api/import/moves`、commit）→ 行単位レポート。失敗行・要確認行は手動修正（FR703、M9-03）へ回す。
>
> **無害化**: セル値を式・コマンドとして解釈・実行せず、描画時にエスケープする（DES-002 §7.5）。
>
> **レスポンシブ**: PC/スマホとも縦並び（§5.14 と同方針）。
>
> 注: コンボ CSV インポート（§5.14、画面14、FR405）とは**別画面・別導線**。本画面はフレームデータ取込（FR704）専用。
