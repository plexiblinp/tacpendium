## 1. 変更の概要

M12-01(表記・文言 + ソート/フィルタ UX + 戻り時保持)の完了に伴い、DES-005 §5.4 コンボ一覧・§5.5 マイコンボの記述を実装に整合させる。対象は以下 4 点(M12-01 連絡レポート §1 + §2.4 確認済):

1. **C-02 既定ソートの変更**: 既定を「始動状況」→「更新日時(updated_at)降順」へ(コンボ一覧・マイコンボ両方)。「始動状況順(default)」は選択肢として存続。
2. **C-18 相手スタンスの一覧控えめ表示**: 一覧本体(始動状況セル内)に `opponent_stance` を控えめ表示(不問=any/未設定は非表示、淡色・小)。フィルタには温存(ソートには元から無し)。表示列カスタマイズ対象には含めない(始動状況列に内包)。
3. **C-01/N-30 戻り時のフィルタ/ソート保持**: コンボ一覧で、一覧以外(詳細/編集/登録)へ遷移して戻った時にフィルタ(キャラ含む)/ソート/仮登録トグルを保持。in-app セッション保持(`sessionStorage`)。**コンボ一覧のみ**(マイコンボは対象外)。
4. **C-07 情報バーの合計表示化**: マイコンボの情報バー(`CharacterInfoBar`)の内訳重複表示を合計件数へ置換し、内訳はステータスタブへ集約(役割分離)。

## 2. 変更の理由

- M12-01 実装(ブランチ `feature/m12-01`、レビュー・取込済み、Vitest 523 passed)と DES-005 の現記述が乖離するため、設計書本体を実装に追従させる。
- 先行リリースの妨げ(ソート既定の使いにくさ・相手スタンスの不可視・戻り時のフィルタ消失・件数表示の紛らわしさ)の解消(M12-overview §2)。

## 3. 変更の内容

### 3.1 DES-005 §5.4 コンボ一覧

- **ソート(L199/L201)**: 既定ソートを「更新日時(降順)」に変更。ソート項目に「更新日時」を既定として明記し、「始動状況順」は選択肢として存続(BE の sort ホワイトリストは既存・変更なし)。
- **表示項目(L202-215)**: 始動状況セル内に `opponent_stance`(相手スタンス)を控えめ表示する旨を追記(不問/未設定は非表示、淡色・小)。表示列カスタマイズ(L200)の対象外(始動状況列に内包)。
- **フィルタ/ソートの保持(新規追記)**: 一覧以外の画面へ遷移して戻った際、フィルタ(キャラクター/タグ/状況/仮登録トグル)とソートを **in-app セッション(`sessionStorage`)で保持**する旨を追記。列表示(L200=ブラウザストレージ)・展開状態(L224=セッション)と同系統。セッション跨ぎの恒久化は対象外(フェーズ3)。**コンボ一覧のみ**。

### 3.2 DES-005 §5.5 マイコンボ

- **ソート(L253)**: 既定ソートを「更新日時(降順)」に整合(コンボ一覧と共通の既定 `DEFAULT_SORT_FIELD/ORDER`)。
- **情報バー表示**: `CharacterInfoBar` の件数表示を合計件数とし、状態内訳(使用中/練習中/頻度低下)はステータスタブ側に集約する旨を反映(§5.5 に情報バーの内訳表示規定がある場合に改訂。無ければ SUPP/実装事実として扱い本項は除外)。
- 戻り時保持は **マイコンボ対象外**(C-01/N-30 はコンボ一覧のみ)。

### 3.3 ヘッダ

- バージョン 2.23.0、ステータスに CHANGE-044 反映を前置。
