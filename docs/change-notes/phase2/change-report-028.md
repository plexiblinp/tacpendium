## 確定方針

- 算出式は案B = `total = 発生 + 持続 − 1 + 硬直`。`−1` は発生の最終フレームと持続の初フレームの重複補正。
- recovery 文字列(整数 / `全体 N` / `着地後N` / `N+着地後M` / `N-着地まで` / `[※2] 1-12` / 空欄)→整数フレームの**解釈ロジックは設計書本体ではなく M9-02 製造指示書側**に置く(本体に無関係な実装詳細で CHANGE 番号を消費しない原則に整合)。
- 算出に必要な値(発生・持続・硬直)のいずれかが空欄/解釈不能なら `total = NULL`(CHANGE-025 と整合)。公式備考の「空振り時硬直 N 増加」は式に算入せず FR703 手動補正。
- スキーマ(列・型・制約)・enum・API・画面は変更なし = マイグレーション不要。
