- 取込は **別経路方式**(preview〔dry-run・書込なし〕+ commit)を設計書本体に確定。解析・算出・正規化は共通サービス層で単一化(指示書 §4.1、拡張性・保守性・誤書込防止・2段階検証思想への適合が根拠)。
- moves 取込プレビュー(画面17)はコンボCSVインポート(画面14)と**別画面・別導線・別系統**。
- M9-03(グリッド編集・ラッシュ版生成等)の UI は本 CHANGE 対象外。M9-03 設計時に別途起票する。
- スキーマ・データモデル・enum・CSV 契約は変更なし(CHANGE-022/025/026/027/028 で確定済み)。
