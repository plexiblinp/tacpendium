## 1. 変更の概要

REQ-001 §3.8 公式データ連携について、以下の 2 点を是正する。

1. **FR702 の文言修正**: 「更新作業は FR701 の別ツール経由で行う」という記述が、データ更新の実行主体を別ツール側と誤読させる。実態は「別ツールが最新の公式データを CSV 化し、**本体側の取り込み機能が反映する**」であるため、これに整合させる。
2. **FR704 の新設**: 取り込みツール(FR701)が出力した CSV を本体アプリに取り込む経路(技・キャラクターデータのインポート)を **正式な要件 FR704 として明文化** する。これは整理工程 Part A-4 で「抜け候補」とした箇所で、新フェーズ2(先行リリース準備)に必須となる(近しい関係者が使用するキャラクターのデータ投入経路)。

**機能・スキーマ・コードの実体は変更しない**(要件記述の是正・追加のみ。実装は新フェーズ2 着手時)。

---

## 2. 変更の理由

### 2.1 FR702 の記述不整合

現行 FR702(CHANGE-020 反映後)は「更新作業は FR701 の別ツール経由で行う」と述べる。しかし FR701 は本体とは独立した別ツールで、公式 HTML から技データを取り出して **CSV を生成する** までを担う(ユーザーには提供しない)。生成された CSV を本体アプリの DB に反映(登録・更新)する処理は **本体側** で行う。したがって「別ツール経由で更新」という記述は更新の実行主体を取り違えており、修正を要する(開発者指摘 2026-06-07)。

### 2.2 本体側取り込み経路の要件欠落

本体側の取り込みは、現状いずれの FR でも規定されていない。

- FR405 は **コンボ/セットプレイ** の CSV インポート(ユーザーデータ用)であり、技・キャラクターデータの取り込みではない。
- FR701 は **別ツール側** の責務(HTML → CSV 生成)であり、本体への取り込みは含まない。

新フェーズ2(先行リリース準備)では、取り込みツールが出力したキャラクターの技データを本体へ投入する経路が必須となる(全手動投入は非効率・不正確のため)。この経路を FR704 として明文化する。直接 SQLite を編集する方式は採らず、**CSV を本体側のインポート機能で取り込む** 方式とする(取り込みツールをユーザーに提供しないため、また将来キャラクターを追加する際も CSV 追加取り込みで対応できるため)。

### 2.3 FR701 / FR704 / FR702 の役割分担

本変更により、公式データ連携の役割が次のように一貫する。

- **FR701**(フェーズ2): 別ツールが公式 HTML から技データを取り出し CSV を生成
- **FR704**(フェーズ2、新設): 本体アプリが CSV を取り込み、技・キャラクターデータを登録・更新
- **FR702**(フェーズ4): ゲームアップデート追従は FR701 で最新 CSV を生成し FR704 で反映することで行う

## 3. 変更の内容

### 3.1 FR702 の文言修正(REQ-001 §3.8)

**現行(REQ-001 v2.14.0)**:

```markdown
| FR702 | ゲームアップデートに追従してデータを更新できる（キャラクター追加、ダメージ変更、計算式変更、新システム追加）。更新作業はFR701の別ツール経由で行う | 重要 | 4 |
```

**改訂後(REQ-001 v2.15.0)**:

```markdown
| FR702 | ゲームアップデートに追従してデータを更新できる（キャラクター追加、ダメージ変更、計算式変更、新システム追加）。更新は FR701 の別ツールで最新の公式データを CSV 化し、本体側の取り込み機能（FR704）で反映することで行う | 重要 | 4 |
```

### 3.2 FR704 の新設(REQ-001 §3.8、FR703 の次行に追加)

```markdown
| FR704 | 公式データ取り込みツール（FR701）が出力した CSV を本体アプリに取り込み、技（moves）・キャラクターデータを登録・更新できる。プレビュー画面で対象を確認・選択して取り込む。コンボデータの CSV インポート（FR405）とは別系統として扱う | 重要 | 2 |
```

> §7 フェーズ定義(CHANGE-020 で改訂済み)のフェーズ2 には既に「取り込みツールが出力した技・キャラクターデータの本体への取り込み（moves・キャラクターの CSV インポート）」を記載済みであり、本 FR704 はそのロードマップ記述を正式な要件として明文化したもの。§7 の記述は本変更と矛盾しないため改訂不要。
