## 1. 変更の概要

M12-04 完了に伴う DES-005 反映。N-29 の実態は「6 画面未共通化」ではなく **7 箇所中 5 箇所が既に共通 `CharacterSelector` 使用済み**で、真の未共通化は 2 箇所(一覧フィルタ・技マスタ編集)だった(製造 §3.4.2 実態確認)。開発者確定により:
- **技マスタ編集**(§5.18): 生 Radix Select → 共通 `CharacterSelector` へ統一。
- **コンボ一覧フィルタ**(§5.4): native `<select>` 維持(隣接フィルタ群との一貫性優先)。
- 加えて **束ねセットプレイ名の必須表記是正**(§5.7 #11、C-03/VAL-S06 の取りこぼし、6.5-1)。

## 2. 変更の内容

- **DES-005 §5.18**: キャラ選択を共通 `CharacterSelector`(§5 L125、pick モード=未選択 placeholder「キャラクターを選択」→選択先行、URL `?character=` 文脈温存)へ統一。
- **DES-005 §5.7 #11**: 束ねセットプレイ登録行のセットプレイ名を**必須**(C-03/VAL-S06、空名不可・必須インジケータ + インライン警告、最終防衛 BE)。
- **DES-005 §5 共通要素 L125**: N-29 統一完了のトレーサビリティ追補(全系統が共通プルダウン、一覧フィルタのみ native 維持=コンテキスト選択とは別役割)。
- ヘッダ: v2.26.0、第37版。
