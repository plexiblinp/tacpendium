## 1. 変更の概要

DES-004 §3.4「サンプル表記」の通常技 code を、§2.1「技の内部識別子（move.code）」の現行規約（`standing_*` / `crouching_*`）に整合させる。`stand_light_punch` → `standing_light_punch`、`crouch_light_kick` → `crouching_light_kick` の2行のみ。

## 2. 変更の理由

- CHANGE-025 で §2.1 の code 規約を「英語表示名の機械変換」へ統一し、通常技を `standing_<強度>_<ボタン>` / `crouching_*` / `jumping_*` と確定した。しかしこのとき **§3.4 サンプル表記の表（旧形 `stand_light_punch` / `crouch_light_kick`）が未追従**で残り、§2.1 と §3.4 が文書内で不整合になっていた。
- この不整合は M10-01 完了報告 課題1（仮想コントローラ `BUTTON_TO_MOVE_CODE` が seed の旧形を参照し、取込キャラの新形 code を解決できない）の事実確認中に発見された。**正典は §2.1＝`standing_*`（取込／CSV 側が正典準拠、seed・コントローラが逸脱）**であることを確認したうえで、§3.4 を §2.1 に揃える。
- 本変更は**文書内部の整合是正のみ**で、code 規約そのもの（§2.1）の変更ではない。挙動・データ・実装契約への影響はない。

## 3. 変更の内容

DES-004 §3.4 サンプル表記の表で、内部表現（code）列を以下に修正（他列・他行は不変）。

| 修正前 | 修正後 |
|--------|--------|
| `stand_light_punch` | `standing_light_punch` |
| `crouch_light_kick` | `crouching_light_kick` |

> 特殊技・SA・システム技の行（`hadoken_light` / `shoryuken_heavy` / `sa1` / `parry_drive_rush` / `cancel_drive_rush`）は本 CHANGE の対象外（§2.1 の通常技規約に直接該当せず、課題1 のスコープ外）。

## 4. 影響範囲

### 4.1 設計書本体（CHANGE 管理対象）

| ファイル | 版 | 改訂内容 |
|----------|-----|----------|

他の設計書本体への変更なし。§2.1 規約は不変（既に `standing_*`）。

### 4.2 実装・派生

- 課題1 の実コード是正（seed の旧形 code → `standing_*` 移行、コントローラ `BUTTON_TO_MOVE_CODE` 更新、全キャラ回帰）は **M10 スコープ外の後続タスク**（followup-backlog B-7）。コントローラ更新と seed 新形化はロックステップ必須、かつ初期キャラの FR701 再取込＋seed 削除（M12-02 系）計画と突き合わせて実施。

## 5. 移行影響
