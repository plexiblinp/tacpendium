## 1. 変更の概要

M12-02(フォーム/レイアウト誤操作・スクロール負荷の解消)の完了に伴い、DES-005 を実装に整合させる。対象 4 点(連絡レポート §3):

1. **C-15 仮登録トグルの位置**(§5.7): 新規/コピー時はフォーム最上部へ(編集は従来位置)。共通 `ComboDraftToggleField`。
2. **C-04 セットプレイのエラー位置 + 保存失敗トースト**(§5.9): バリデーション警告を保存ボタン直上へ(コンボと統一)+ 保存失敗トースト追加。
3. **C-13 セットプレイ展開機構の除去**(§5.6): 紐づくセットプレイをアコーディオン展開→常時展開表示(行クリック遷移は維持)。
4. **C-09 キャンセル導線**(§5.7): コンボ登録/編集の最上部にもキャンセル導線を併置 + 最上部名称を「キャンセル」に統一。

## 2. 変更の理由

- M12-02 実装(`feature` 取込済み、Vitest 530 pass、実機 E2E 完了)と DES-005 の乖離解消。
- 先行リリースの妨げ(誤操作・スクロール負荷)の解消(M12-overview §2)。

## 3. 変更の内容

### 3.1 DES-005 §5.6 コンボ詳細
- 表示項目9「紐づくセットプレイ一覧」を**アコーディオン展開→常時展開表示**(レシピ全文・複数行折返し、行クリック遷移・紐付け解除は維持、開閉機構廃止)。

### 3.2 DES-005 §5.7 コンボ登録・編集
- 表示項目3「仮登録トグル」に**新規/コピー時はフォーム最上部**(編集は従来位置=基本情報末尾、共通 `ComboDraftToggleField`)を追記。
- アクションに**最上部キャンセル導線の併置 + 名称「キャンセル」統一**(下部と挙動同一 `navigate(-1)`)を追記。

### 3.3 DES-005 §5.9 セットプレイ登録・編集
- **エラー・警告表示**を新設: バリデーション警告(FR305 非ブロッキング)を保存ボタン直上へ(コンボと統一)+ 保存失敗トースト(409/バリデーション/通信エラー出し分け、コンボと統一)。検証内容・非ブロッキング方針は不変(位置・通知の統一のみ)。

### 3.4 ヘッダ
- バージョン 2.24.0、ステータスに第35版(CHANGE-045)を前置。
