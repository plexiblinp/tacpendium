## 1. 変更の概要

ドライブパリィ（drive_parry）の取込方針を是正する。旧 CHANGE-023 / CHANGE-026 では「ドライブパリィは非攻撃でコンボのステップにならない＝取込対象外」と確定していたが、**ドライブパリィを空ぶるセットプレイ等でステップ参照に用いるため、取込対象・move 化に方針転換**する。本体設計書は drive_parry 取込の受入準備が大半すでに整っており（Claude Code 前調査）、残存していた内部不整合は DES-002 §7.5 の取込スコープ記述のみ。これを是正し、併せて drive_parry（move）と parry_drive_rush（modifiers.type）の役割分担を明文化する。

## 2. 変更の理由

- ドライブパリィを空ぶるセットプレイが存在し、ステップ参照のために **move として必要**（M10-01 完了報告 課題5、開発者確認）。
- 旧方針（取込対象外）は CHANGE-023/026 で確定していたが、その後の運用実態と矛盾。**開発者の指示ミス・レビューミスの是正**として、旧方針の取り残し（DES-002 §7.5）を新方針へ揃える。
- Claude Code の前調査により、矛盾は **DES-002 §7.5 の取込スコープ記述だけ**で、他は受入準備済みと判明（例: DES-003 §3.3 の category enum に `system` が既存、DES-004 §2.1 に drive_parry が既存）。
- 加えて、drive_parry（move）と parry_drive_rush（modifiers.type）の二重定義懸念を解消するため、両者が別概念である旨を明文化する（タスク2・3・4）。

## 3. 変更の内容

### 3.1 DES-002 §7.5（FR704 CSVフォーマット仕様／取込対象）【必須＝B＋タスク2】

- 共通システムの取込対象を「ドライブインパクトのみ」→「**ドライブインパクト＋ドライブパリィ**」に変更。ドライブパリィは名称 `ドライブパリィ`＋位置で判別し、非攻撃だが `category=system`・`code=drive_parry`（全キャラ統一）で moves 化。
- 取込対象外リストから「ドライブパリィ」を除去（ジャストパリィ〔打撃・飛び道具〕は引き続き除外）。
- 役割分担注記を追加：drive_parry は move（`category=system`、`combo_steps.move_id` 参照）、parry_drive_rush は `combo_steps.modifiers.type` の値で move ではない＝二重定義ではない。

### 3.2 DES-003 §3.3（moves スキーマ）【推奨＝タスク3】

- 「ドライブインパクトの扱い」注記に並置して「**ドライブパリィの扱い**」注記を追加：非攻撃だがステップ参照に用いるため moves 登録、`category=system`・`code=drive_parry` 統一、active は空（公式の注釈付き範囲 `[※2] 1-12` のため）＋raw_data/notes 退避、parry_drive_rush との役割分担。

### 3.3 DES-004 §2.1（move.code 規約）【推奨＝タスク4】

- 共通システム行の move_code 例から `parry_drive_rush`（modifiers.type であって move_code でない）を除去し、`drive_parry` に整理。drive_parry の取込元が CSV 取込（FR701）である旨を補記し、parry_drive_rush は §2.3（modifiers.type）参照とした。

### 4.2 実装・外部ツール

- **外部 FR701 取込ツール**（別設計書・別チャット管理）: drive_parry を取込対象に含める実装は **過去担当チャットで対応中**（M10-01 完了報告 課題5）。本 CHANGE は本体設計書（DES）側の是正。
- 本体側 FR704 取込: §7.5 のスコープ拡張により drive_parry 行を受け入れる。`category=system` の写像・raw_data 退避は既存の取込ロジックで吸収される想定（実装確認は取込担当工程）。
- スキーマ変更なし（既存の moves スキーマ・category enum `system` で表現可能）。

### 4.3 旧 CHANGE-023/026 との関係

- CHANGE-023/026 の md ファイルは **改廃しない**。本 CHANGE-038 によって方針転換（drive_parry 取込対象外→対象）が起きた旨を、Claude Code が当該 md に追記予定（履歴の追跡可能性を保つ）。

## 5. 移行影響

- データ移行: 既存 DB への直接の移行は不要。drive_parry の投入は今後の取込（FR701 再エクスポート＋FR704 取込）で行われる。
- 後方互換: 取込スコープの拡張＝加算的変更。既存の取込済みデータ・スキーマに破壊的影響なし。

## 6. リスク

- drive_parry の active が空（公式注釈付き範囲）になるため、total 算出が NULL＋要確認になりうる（既存の total=NULL→要確認フローで吸収）。
- parry_drive_rush（modifiers.type）と drive_parry（move）の混同リスクは、本 CHANGE の役割分担注記（DES-002 §7.5・DES-003 §3.3・DES-004 §2.1）で低減。
