## 1. 変更の概要

コンボの新規登録・コンボ追加モーダルの**既定キャラクターを文脈追従**させる。DES-005 §4.3 の既定規定「デフォルト表示キャラがデフォルト選択」を拡張し、キャラ文脈のある遷移ではその文脈キャラを既定選択とする（文脈が無い場合は従来どおりデフォルト表示キャラ）。

## 2. 変更の理由

- M10-02（A-2）の本旨は「新規登録／選択モード／コンボ追加モーダルの**既定値・固定表示を選択キャラ追従へ**」（phase2-overview §M10）。一覧/マイコンボで特定キャラを見て「新規登録」した際にリュウ既定へ戻る摩擦、コンボ比較で「コンボ追加」した際のリュウ固定を解消する。
- M10-01 で ComboEditor 新規モードの既定は `INITIAL_CHARACTER_ID`（=リュウ）に統一済み。これを文脈追従へ拡張することが A-2 の達成に必要。
- 文脈追従は DES-005 §4.3／§5.7／§5.8 の既定挙動の規範的拡張のため、サイレントな DES 乖離を避け CHANGE で記録する（Plan Mode §3.4-5 の CHANGE 判断＝起票が結論）。

## 3. 変更の内容

### 3.1 DES-005 §4.3（共通要素）

- キャラクター選択プルダウンの既定説明を拡張：既定はデフォルト表示キャラだが、キャラ文脈のある遷移（一覧/マイコンボで選択中キャラからの新規登録、比較中コンボのキャラからのコンボ追加）では当該文脈キャラを既定選択とする（文脈なしはデフォルト表示キャラ）。

### 3.2 DES-005 §5.7（コンボ登録・編集）

- 「新規モードの既定キャラクター」節を追加：新規登録モードの既定キャラは、キャラ文脈のある遷移（一覧/マイコンボの選択キャラからの「新規登録」）ではその選択キャラ、文脈の無い遷移（フッターの汎用「新規登録」導線等）では `INITIAL_CHARACTER_ID`。文脈キャラは遷移時に伝播し ComboEditor 新規モードの初期選択に用いる（編集モードのキャラ固定表示は不変）。

### 3.3 DES-005 §5.8（コンボ比較）

- 「コンボ追加モーダルの既定キャラクター」節を追加：比較画面はページレベルのキャラ選択を持たないため、コンボ追加モーダルの既定キャラは比較リスト先頭コンボの characterId（比較リストが空なら `INITIAL_CHARACTER_ID`）。モーダル内セレクタで手動切替可。

## 4. 影響範囲

### 4.1 設計書本体（CHANGE 管理対象）

| ファイル | 版 | 改訂内容 |
|----------|-----|----------|
| DES-005（画面設計書） | v2.20.0 → v2.21.0 | §4.3／§5.7／§5.8 に既定キャラクターの文脈追従を追記 |

他の設計書本体への変更なし。登録系 API は character_id 既存（code-facts §7-2）＝API 契約変更不要。

### 4.2 実装（M10-02 で実施・フロント完結）

- 一覧/マイコンボ → 新規登録: 選択キャラを `?character=` で伝播し、ComboEditor に `initialCharacterId`（任意、不在時 `INITIAL_CHARACTER_ID`）プロップを追加。
- コンボ比較 → コンボ追加モーダル: `ComparePage` が `defaultCharacterId`（先頭コンボの characterId／空なら `INITIAL_CHARACTER_ID`）を `AddComboToCompareModal` へ渡す。
- いずれも M10-01 の ComboEditor 内部選択ロジック・モーダル内セレクタは不変（初期値を外から渡すのみ＝後方互換）。

## 5. 移行影響

- データ移行不要。挙動拡張のみ（プロップ不在時は従来挙動＝`INITIAL_CHARACTER_ID`）で後方互換。

## 6. リスク

- 文脈キャラの伝播経路（route param/nav state）の取り違えで既定が反映されないリスク → M10-02 指示書 §3.4 Plan Mode＋テストで担保。
- 比較リストがキャラ混在の場合、先頭コンボのキャラが既定になる（同一キャラ比較が主用途のため通常は的中。混在時も安定したアンカー）。

## 7. 承認・反映

Plan Mode 2 問（新規登録の既定キャラ文脈追従／コンボ追加モーダルの既定キャラ）とも開発者が選択肢1で確定。これを承認とみなし反映まで実施。反映手順は change-report-039 を参照。

## 8. 追補（実装整合 errata、2026-06-18、DES-005 v2.21.0 → v2.21.1）

M10-02 実装 survey で、`/combos/new`（非コピー）への新規登録導線は**ホーム／フッター／一覧（ComboListPage）の3箇所のみで、マイコンボ画面には存在しない**ことを確認（開発者確定＝マイコンボに新規登録導線は設けない）。これに伴い、本 CHANGE で「一覧／マイコンボで選択中キャラからの新規登録」と記した §4.3／§5.7 を「**一覧（ComboListPage）のみ**」に是正（DES-005 v2.21.1）。新規 CHANGE は起こさず CHANGE-039 の errata として記録。§5.8 コンボ追加モーダルは変更なし。E2E は一覧起点（A'）で実施・通過。
