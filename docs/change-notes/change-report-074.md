## 2. 修正概要

- **§5.13 用紙寸法**: 「比較＝A4 横」→「比較＝**幅 A4 長辺 × 高さ A4 長辺（297mm 相当）の正方形**」へ明確化。**CHANGE-073 の内部矛盾**（「A4 横」と「1122px に原寸」の非両立）を、**原寸/可読性を優先して用紙を正方形に定義**することで解消。実測根拠の文言も用紙定義と整合させた。
- **§5.13 項目名セル**: **折り返す**（`overflow-wrap: anywhere`・nowrap 廃止）を追記。用紙固定で固定幅化した項目名列から長いラベルがはみ出す実出力不具合の是正（as-built）。**実環境の折り返し目視は開発者確認事項**として明記。
