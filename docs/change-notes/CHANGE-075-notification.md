## 1. 変更の概要

import 体験の再設計（別紙 B-1〜B-6）。**UI 動線・重複挙動・表示品質のみ**を変え、**CSV 契約（DES-002 §7.6）・BE のエラー体系・VAL-S04・スキーマは不変**。

**本 CHANGE には設計判断の訂正が 1 件含まれる**（§2.1）: 旧 M17-05a 指示書 §5.1 の setups 重複 3 ケースが**既存 VAL-S04 と原理的に矛盾**していた（設計の実物確認漏れ）。製造がエスカレーションし、**VAL-S04 に整合する「レシピ一致で skip（名前非依存）」へ確定**した。

## 2. 変更の内容

### 2.1 【最重要】setups 重複判定を VAL-S04 整合へ補正（DES-006 §6）

- **問題**: 旧 M17-05a 指示書 §5.1 は「同名＋同レシピ＝skip／**別名＋同レシピ＝取込む**／別名＋別レシピ＝取込む」の 3 ケースを定義していた。だが既存 **VAL-S04**（DES-006 §2.3・L109）は「同一キャラの同じ親コンボに**同一レシピ**の setups が紐付いていないか」を **ERROR** とする＝**名前非依存**。よって「**別名＋同レシピ＝取込む」は原理的に実現不能**（`CreateSetup` が VAL-S04 で必ず failed）。**設計（指示書 §5.1）が既存 VAL-S04 を確認せずに書いた拡大解釈だった**。
- **確定（開発者エスカレーション・2026-07-18）**: **「レシピ一致で graceful skip（名前非依存）」**を採用（VAL-S04 に整合）。**検証結果が VAL-S04 のみで構成される場合だけ skip に翻訳**し、**他エラー併発時は failed 優先**（本当の不整合は隠さない）。**combos の `recipe_hash` は流用しない**（setup ドメインの正規判定を尊重＝意味の混線回避）。
- **DES-006 §6 に「重複時の挙動の正典」ブロックを新設**し、この判定を明文化。**旧 M17-05a 指示書 §5.1 の第 3 ケースは補正**（テスト `TestImportSetupsOnlyDuplicateSetupJudgement` も skip 期待へ更新済み）。

### 2.2 重複時 2 択（B-6・DES-005 §5.14／DES-006 §6）

- **「新規追加（add）」廃止・「セットプレイのみ取込（setups_only）」追加**。ワイヤ値 `"skip" | "setups_only"`（廃止 `"add"` を含む未知値は既定 `skip` へ倒す＝後方互換・安全側）。
- **「セットプレイのみ取込」**＝重複コンボは skip し配下 setups を既存コンボ（重複相手 id）へ親解決して取込。
- **「上書き（M13-i）」は未実装＝繰越**。**配列/型 union の構造で予約・UI 非表示**（要素追加だけで 3 択化・未対応機能を予告しない）。

### 2.3 入口一本化（B-1・DES-005 §5.14）

- 入口を「**ZIP または combos.csv（setups.csv 同時可）**」に一本化。**setups 単独アップロード導線を廃止**。**setups 欄は従属化**（コンボ CSV 未選択時 無効化＋「セットプレイのみの取込はできません」注記）＋**送信前ガード**（`comboFile` 必須＝成立しない setups 単独入力を作らせない）。

### 2.4 表示品質（B-2/B-3/B-4/B-5・DES-005 §5.14）

- **B-2 VAL エラー日本語化**: **FE 表示層で写像**（`comboImport.val.*`／`comboImport.col.*`・ja/en parity・**BE 不変＝register 分離**）。未写像は英語フォールバック・VAL コード原文は折りたたみ保持。**重複警告は「既存コンボ(ID N)と重複」表示で VAL-C02 のみ畳む**（既存 ID は実用情報として残す＝開発者 A 案確定）。**file レベルエラーは現状 英語のまま**（BE が code 非露出＝§3-2 で保留）。
- **B-3 表示名化**: キャラ・始動技を表示名（既存機構流用・未投入は生 code）。
- **B-4 local_id 非表示**: コンボ表から除去（CSV 列は維持）・**取込結果は「行」番号で識別**・**セットプレイ親列は解決した親コンボ名（解決不可時のみ生 local_id）**。
- **B-5 実行フィードバック**: 完了トースト（成功/スキップ/エラー件数）＋結果へ自動スクロール＋実行中の無効化・進行表示。

## 4. 整合性チェック結果

- **設計の実物確認漏れを是正**: VAL-S04（既存不変条件）を確認せず 3 ケースを書いた指示書 §5.1 を、DES-006 §6 で正典化して補正。**次に読む担当が「別名＋同レシピ＝取込む」で再び矛盾に当たらない**。
- **register 分離を維持**: B-2 は FE 写像のみ・BE 不変（CHANGE-066）。
- **M17-04 連携口を壊していない**: 回帰ゲート（指示書 v1.0.1 §5.2）通過・`intake/` 差分ゼロ。
- **節番号**: DES-005 §5.14／DES-006 §6 に**追記・改訂のみ**（新設節なし）。両 DES とも §番号 全件列挙で重複・欠落なしを確認（**確認出力を切らずに**＝playbook §5.4.1）。
- **後方互換**: 旧 `add` は既定 skip へ（真重複が挿入されない安全側）。
