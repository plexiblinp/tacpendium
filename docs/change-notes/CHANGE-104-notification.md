## 1. 変更の概要

### 1.1 何を確定させるか

**取込ヘルパーの逆引きは、`preset_aliases` の完全一致で引き、返り値が 1 件のときだけ確定する**（`DES-004` §5 冒頭注記）。**この決定論が今日 3 つの理由で空振りしている。**

| # | 空振りの理由 | 本サブが直すもの |
|---|---|---|
| 1 | **全角／半角の混在**（NFKC 差分 36 行 ／ 全角括弧 33 行 ／ 混在 12 行＝**D-307**） | **逆引きの前段に正規化を置く**（**範囲は実測で決める**） |
| 2 | **`alias_text_en` を引いていない**（`DES-004` §5 が「両方を引く」と定めたまま未実装＝**D-374** の実測） | **両引きにする** |
| 3 | **多候補ハッジ（`"A or B or C"`）が 1 つの文字列として扱われる**（**G-14b**） | **分割して候補として提示する** |

**★不可視文字は 0 件 / 1,653 行だった**（**D-307**）。**当初の見立て「見えない文字が混じっている」は外れていた。**

### 1.2 CHANGE 対象と対象外の切り分け

| 対象か | 内容 |
|---|---|
| **対象** | **`DES-004` §5 冒頭注記**（正規化を前段に置くこと ＋ 採った範囲）／**§5.6**（「未実装」の解消） |
| **対象**（as-built 次第） | **`DES-002` §4.2**（**多候補の返し方が変わる場合のみ**。**変わらなければ改訂しない**） |
| **対象外** | **`alias_text` のデータ書き換え**（**D-307** で採らないと決めた。**表示を変えずに照合だけを緩めるほうが影響が小さい** ／ `official_ja_move` は編集不可＝**D-290**） |
| **対象外** | **表示ロケール分岐**（**逆引きと表示は別である**。followup の (1) は未割付のまま） |
| **対象外** | **辞書の充実**（SA 番号・キャラ通称等＝`G-14b` の残り半分）。**★照合を直してから、増やす価値のある辞書を測る。順序を逆にすると効果が測れない** |
| **対象外** | **曖昧一致・編集距離**（`DES-004` §5 冒頭注記が禁じている） |
| **対象外** | **アプリ外プロンプトの表現力**（`G-14a`＝`M17-05d` の所管） |

## 2. 変更の内容（`DES-004` ／ `DES-002`）

| # | 節 | 変更内容 |
|---|---|---|
| **a** | **`DES-004` §5 冒頭注記** | **逆引きの前段に正規化を置くことを明記する**（**D-307** の帰結）。**★採った範囲と、採らなかった範囲の理由を書く**——**「正規化する」だけでは、次の担当が「もっと広げてよい」と読む。** **★入力側と辞書側の両方へ同じ関数を掛けることも書く**（片側だけだと、掛けた側だけが揃って一致しなくなる） |
| **b** | **`DES-004` §5.6** | **「逆引きの両引きは未実装」の注記を解消する**（**CHANGE-103 で入れたもの**）。**★解消するのであって消すのではない**——**いつ・どのサブが実装したかを残す** |
| **c** | **`DES-004` §5 冒頭注記** | **多候補ハッジの分割を明記する**（**G-14b**）。**★分割した結果は「候補」であって「確定」ではない**——**どれが正しいかはメモの書き手しか知らない** |
| **d** | **`DES-004` §5 冒頭注記** | **★「一意制約があるから逆引きが決定論になる」という読みを塞ぐ**（**G-11**）——**制約はプリセット内の一意であり、逆引きは全プリセット横断である。** **⇒ 横断すれば 1:N は当然成立する**（`DES-003` §3.9 が既に書いている）。**決定論を支えているのは「1 件のときだけ確定する」という規則そのものである** |
| **e** | **`DES-002` §4.2**（**as-built 次第**） | **多候補の返し方が変わる場合のみ改訂する**（**変わらなければ改訂しない**）。**★指示書 §2.3 は「契約が変わるなら着手前に上げること」としており、上がってきた時点で本項が動く** |

## 3. 確定した設計判断

| # | 判断 | 根拠 |
|---|---|---|
| 1 | **逆引きの前段に正規化を置く**（データは書き換えない） | **D-307**。**`alias_text` は技の表示名そのものであり、表示を変えずに照合だけを緩めるほうが影響が小さい** |
| 2 | **★正規化の範囲は実測で決める** | **D-307**。**過剰な正規化は別の技を同一視する。** **⇒ 指示書 §3.3-2 で実測させ、同一視が 1 組でも生まれるなら採らせない** |
| 3 | **逆引きは `alias_text` と `alias_text_en` の両方を引く** | **D-317** の (3)。**英語表示を見た利用者のメモも解決するため** |
| 4 | **多候補ハッジは分割して候補として提示する**（確定にしない） | **G-14b** |
| 5 | **辞書の充実は本サブに含めない** | **★照合が入力とすれ違えば、辞書を増やしても決定論は働かない**（**D-307**）。**⇒ 順序を守る** |
| 6 | **表示を 1 文字も変えない** | **本サブは逆引きだけを直す。** **正規化を表示側へ掛けると `alias_text` の見え方が変わる** |
