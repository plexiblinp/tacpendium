## 2. 起票タイミング（二段が自然＝digest §6 M13-3）

- **着手前**: 契約骨子（段階1 の出口=`move_code`／modifier flags の非スキーマ性／プルダウン残置方針）が固まれば、着手前 CHANGE として骨子を正典化する選択肢（M9-02 CHANGE-029 型）。
- **実装後**: 確定した列挙値・画面仕様を**三点セット**（通知書＋改訂 DES＋change-report-057）で反映（M14-1＝改訂 DES 適用は必須・「要請時適用」にしない）。
- **推奨**: M15-03 は実装で UI/flag 実値が固まるため、**実装後の三点セット反映**を基本とする。着手時 Plan Mode で「着手前に骨子を切るべき破壊的論点」が出れば前倒し。

## 3. 明確に除外するもの（過剰起票・越境の回避）

- **別技扱いの move_code 命名**（`_hold`/`_lv`/`_just` 等）＝**既存**（DES-004 §2.1・seed）。CHANGE-057 に含めない。着手時 view で DES-004 §2.1 に hold/just 等の記載が無ければ、**軽微 errata 候補**として別途拾う（CHANGE ではなく errata。playbook §16.4.4）。
- **target_combo（多段特殊技）の区分**＝**M16**（§6 データの根）。phase3-overview 記録側で扱う。CHANGE-057 対象外。
- **別技ボタン面（データ駆動）**＝**M14-03b 後のフォローアップ**。M15-03 では非対象。
- REQ-001 は不変（本サブは要件変更なし）。DES-006 は段階1/flags に検証追加が要るか着手時判定（不要なら含めない）。

## 4. 起票時チェック（着手時 view・§3.3-7 と対応）

1. DES-004 §2.1 に段階1 引き当ての記述追加が要るか（`move_code` 正典は既存）。
2. modifier flags の置き場は DES-004 §2.3 か DES-003 §3.3 か（既存の flag/type 記述の所在を grep で確定してから）。
3. DES-005 §5.7 の現行記述（レシピ入力領域＝仮想コントローラ）に対し、カテゴリタブ・プルダウン残置/区分絞り込み・直接指定の追記範囲。
4. 過去 CHANGE の決定を覆す点が無いか（あれば反転対象を明示＝digest §6 M14-3）。本サブは既存決定の反転を含まない見込み。
5. 反映は三点セット（通知書＋改訂 DES＋change-report-057）で registry を 057 消化・次 058 へ。
