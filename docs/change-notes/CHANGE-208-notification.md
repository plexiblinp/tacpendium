## 1. 足した条件

```
- starter_meaty が同じ（M37-07）
```

**★値域の正本は `SUPP-001` §2.2 である**（`CHANGE-207`）**。⇒ 本書は判定条件の列挙であり、値の定義は持たない。**

---

## 2. ★★★他の 5 列と述語の形が違う

| | |
|---|---|
| `position` / `opponent_stance` 等 | **NULL 同士は「一致」として扱う。⇒ 判定 SQL の `WHERE` へ `col IS NULL` を一貫して足す** |
| **`starter_meaty`** | **★`NOT NULL` である。⇒ 述語は常に `starter_meaty = ?`** |

**★★ここを揃えにいかないこと。⇒ `addNullable` に通すと、存在しない NULL の分岐を足すことになる。**

---

## 3. ★変えていないもの

| | |
|---|---|
| `deleted_at IS NULL` / `is_draft = 0` の固定条件 | **1 文字も変えていない** |
| `VAL-C14` / `VAL-S07` / `VAL-R03` / `VAL-R04` | **判定内容は変えていない** |

**★★後者はキーの器**〔`duplicateKeyPredicates`〕**を共有しているため、4 件へ*自動的に*及ぶ。⇒ 「4 件を個別に直した」ではない。★次に読む人が 4 件を探しにいかないよう明記する。**
