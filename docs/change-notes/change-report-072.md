## 4. 整合性チェック結果

- **「出力文書の内容は不変」（レビューチェックリスト §9）と一貫**: 出力生成関数 無改修・CHANGE-052/068 の規定を変えていない。
- **「エクスポート画面は温存（新機能なし・除去なし）」（§4）と一貫**: §5.13 は温存・A-3 の 2 改善（プルダウン/インクリメンタル検索・選択画面遷移）は**実装していない**（廃止予定画面への投資回避＝別紙 §2 段階案）。除去は第 2 段＝個別承認。
- **「作り直さない」と一貫**: 選択 UI＝`useSelectMode` 無改修・export 生成関数＝M13-02 無改修（伝達 §9 の「無変更」一覧で確認）。
- **i18n 境界と一貫**: ダイアログ/一覧 UI は i18n（`export.*`・`selectMode.countPlain`・`export.maxReached`）／出力文書内は固定 ja（`export-items.ts` は無変更）。
- **節番号**: **DES-005 §5.x を全件列挙して確認**し、**新設は §5.13a**（§5.13 直後への挿入・**§5.14 以降を繰り下げない**）とした（**確認出力を切らずに**＝playbook §5.4.1）。
- **「28」の誤読リスクを是正**: 製造が実物（`export-items.ts`＝17 チェックボックス）と DES の「28」を突き合わせて**書き分けを要求**＝DES に反映（**参照数値の実物未確認パターンの解消**）。
