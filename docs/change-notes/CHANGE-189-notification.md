## 1. なぜ要るか

**`DES-005` §6 の 2 つの表が、実装事実と食い違っていた。⇒ しかも片方は `CHANGE-176`（`M31-04`）で私が書いたものである。**

**★★機序＝`M31-04` が除外した `drive_reversal` は `category='system'` で*どのタブにも載らない code* だった。⇒ 「`unclassified` 分岐に置けば効く」が、そのデータでは真に見えた。**

**★★★`setup_only` は任意の category に立ちうる。⇒ 確実に踏む。★旧注記自身が「載る形の code を足すと、未分類とプルダウンからは消えるのにタブには出続ける。型検査もテストも緑のままである」と予告していた状態であった。**

---

## 2. 変更内容

### (a) ★★★`DES-005` §6 —— 適用点は `unclassified` 分岐ではなく**母集団**である

**着手時点の実測——`isInputExcluded()` を通っていたのは 2 か所だけであった。**

| 面 | 着手時点 |
|---|---|
| 全技一覧プルダウン ／ 未分類タブ | 通る |
| 特殊技 / SA / ターゲットコンボ / 共通技 / キャラ固有状態 の 5 タブ | **★通らない** |
| 通常技タブ ／ 必殺技タブ | **★通らない。★そもそもバケットを持たない** |

**⇒ `surfaceBuckets` の先頭で 1 回だけ母集団を絞る形へ引き上げた。**

**★★「押し下げ」（各バケットの push 直前へ足す）は採らなかった。⇒ 判定が 7 か所へ散り、しかもバケットを持たない 2 タブには依然として効かない。**

**★判定は `isInputExcluded` の 1 本のままである**（`D-810`）。**⇒ 2 本目を作っていない。**

### (b) `DES-005` §6 —— 8 タブの母集団表の「（不変）」「そのもの」を是正

**どのタブの母集団も「その述語 ∧ 非除外（面）」である。**

### (c) ★★`DES-005` §6 / §5.9 —— 除外が「面」を持つようになった

| 理由 | 由来 | 面での効き方 |
|---|---|---|
| `INPUT_EXCLUDED_MOVE_CODES` に載る code | 静的なフロント定数 | **両面**で外す |
| `move.setupOnly` | データ駆動のフラグ | **★コンボ側だけ**外す |

**★セットプレイのレシピ入力はコンボ登録と*同じ部品*を共有している。⇒ 部品の中で落とすとセットプレイからも消える。**

**★★案「セットプレイ側の呼び出しでだけ除外を外す」を採らなかった理由は 1 点である**——**静的除外まで面で分かれ、`drive_reversal` がセットプレイ側へ漏れる。**

**⇒ §5.9 へ「同じ部品だが同じ母集団ではない」を書いた。★「コンボ登録と同じ仮想コントローラ使用」という記述だけを読むと逆に読める。**

### (d) `DES-003` §3.3 —— `setup_only` を「予約列」から as-built へ

外す面 2 ／ 出す面（**セットプレイのレシピ入力＝唯一の入り口**）／ 対象外 2（物理入力・引っ越し取込は通す）／ 保存は禁止しない ／ **付与の口が無い**。

### (e) `CHANGE-176` §2.5 の等式 —— **崩れていない**

```
未分類 ＝ isControllerSurfaced の裏返し ∧ 非除外
```

**⇒ 変わったのは `∧ 非除外` の*位置*と、その `非除外` が*面*を持つようになったことである。★等式そのものは真のままである。**

## 3. 変更しないもの

- **`INPUT_EXCLUDED_MOVE_CODES` の中身**——`drive_reversal` 1 件のまま

- **共通技タブの固定 13 code**——不変

## 4. ★この改訂は「画面の見え方」を 1 か所も変えていない

**実 DB の `moves.setup_only = 1` は 0 件である。⇒ 本サブは「データが 0 件のうちに経路だけ作る」ものである。**

**★★したがって「入れた」は「効く」の証拠にならない。⇒ 効き目の証拠は陽性対照 22 本と破壊確認 5 通りである。**

**★とくに「指示書が想定していた実装（`unclassified` 分岐の中だけで落とす）へ戻すと 6 本が赤になる」形は、指示書の前提の誤りをテスト側から独立に裏取りしている。**

**★★★実機確認は未了である。⇒ 付与口が無いため通常操作では観測できない。★フェーズ5 でフラグを立てる手番では実データでの再確認が必須になる。**
