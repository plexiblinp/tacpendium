## 1. 変更内容

### 1.1 flag 表を 14 値へ

**★削除 3**〔`just` / `neutral_jump` / `forward_jump`〕**／ 追加 7**〔`no_cancel` / `late_cancel` / `whiff` / `meaty` / `cross_under` / `juggle_high` / `juggle_low`〕**／ `low_jump` の表示語を「低ジャンプ」→「低空」へ。**

**★★コードは 1 つも変えていない**（`CHANGE-057`＝flag コードは内部正典として不変）**。**

### 1.2 ★★分類を 4 → 5 区分へ

**★「当て方・位置系」を新設した。⇒ 追加 7 値が既存 4 分類のどれにも収まらないためである。**

**★「空中系」を「空中・浮かせ系」へ改めた。⇒ `juggle_*` は空中の*技*ではなく、相手が浮いている状態への*当て方*である。**

### 1.3 ★★「その他」の行を畳んだ

**★旧表の最終行＝「その他｜言語化が難しい技の当て方を表すコード｜－｜－」。⇒ 追加 7 値がその枠を実値で埋めた。**

**★★★値の集合は開発者が全件決めた**（`D-873`）**。⇒ 置き場を残すと、決めた集合の外へ値が足される余地が残る。**

### 1.4 ★★★「選択肢 14」と「表示語の引き当て 17」は**別物である**

**★選択肢＝14。表示語の引き当て＝17**〔14 ＋ 外した 3〕**。**

**★★★同じ配列を使い回すと、「選択肢に外した値が戻る」か「既存行が内部コードで出る」かのどちらかが必ず起きる。⇒ 次に flag を外す担当は、1 本の配列から削ってはならない。**

**★これを書かないと `B04`**〔生の `{}` 等で囲んだ表現を出さない〕**が逆行する。**

### 1.5 ★`link` と `no_cancel` の書き分け ＋ キャンセルの既定

**★2 行足した**（`D-873`）**。**

- **`link`＝*難易度*の注記 ／ `no_cancel`＝*接続の事実*。★両方が付く行がありうる。⇒ 排他にしない**
- **キャンセルの既定は「キャンセルである」。⇒ 何も付いていないステップはキャンセルで繋いだと読む。★「キャンセルした」を表す flag は作らない**

### 1.6 §2.1 との二重化が解消した

**★「ジャンプ→攻撃」の表現は move 側 1 通りになった。⇒ `back_jump` flag が無い非対称も同時に消えた。**

### 1.7 `parry_drive_rush` の表記を「生ラッシュ」へ確定

**★着手前はサーバ「生ラッシュ」／ UI「パリィドライブラッシュ」で割れていた。⇒ 一般語へ寄せた**（UI 側を変更）**。**

**★★`cancel_drive_rush` は割れたまま残る**〔サーバ「キャンセルラッシュ」／ UI「キャンセルドライブラッシュ」〕**。⇒ 2026-09-14 開発者裁定＝そのままでよい。★`followup` の `modifier-cancel-drive-rush-label-split`。**

### 1.8 ★★ヘッダの「機械検査は無い」を直した

**★`DES-004` のヘッダ ステータス行に「機械検査は無い＝`check-enum-sync.sh` は flags を見ていない」が在った。⇒ §2.3 本文の差し替えでは届かない位置である。**

**★★★失効したのは*全体についての断言*だけである。⇒ Go とフロントの表示語の一致は `M37-06` で機械検査になった。★`check-enum-sync.sh` が flags を見ていないことは今も事実であり、そこは消していない。**
