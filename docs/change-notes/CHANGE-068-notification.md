## 1. 変更の概要

発信者流通（M17）の一環として、コンボにメディア参照 3 フィールドを持たせる。**外部リンク 1（`link`）・動画の相対パス 1（`video_path`）・画像の相対パス 1（`image_path`）**。発信者がコンボに解説動画/画像/URL を添付し、export/import で流通させられるようにする。

性質の宣言:

- **非破壊・後方互換**: combos への NULL 可 TEXT 列 3 つの追加。既存行・既存 CSV に影響なし。
- **非 dup / 非 recipe**: 3 列とも `DuplicateKey`（VAL-C02）・`recipe_hash` の対象外（メディアはコンボの同一性を定義しない）。`RecomputeComboCache` 非波及。
- **スコープ＝文字列参照まで**: 本体はファイルを開く/配信/再生/存在確認を**行わない**（開発者確認 2026-07-09・M17-overview §4.6）。`link`（http/https の外部 URL）はクリックで遷移可、`video_path`/`image_path`（ローカル相対パス）は**文字列表示のみで遷移しない**。動画実体の配布・容量設計はスコープ外（phase3-overview §M17 ⑤ precedent）。

CHANGE 対象外（本通知書に含めない）: 既定実装の詳細（列の物理型・UI 配置）は指示書 M17-01 側。ファイル再生・プレビュー・存在検証は M17 スコープ外（将来別 CHANGE）。

## 2. 変更の内容

### 2.1 DES-003 §3.3（combos テーブル）

| # | 対象 | 変更 |
|---|------|------|
| a | `link` | TEXT・NULL 可。外部リンク URL（http/https 想定）。1 コンボ 1 件 |
| b | `video_path` | TEXT・NULL 可。動画の相対パス文字列（カレント基準）。1 コンボ 1 件。**本体は解決・再生しない** |
| c | `image_path` | TEXT・NULL 可。画像の相対パス文字列（カレント基準）。1 コンボ 1 件。**本体は解決・表示読込しない** |
| d | 同一性への非関与 | 3 列とも `DuplicateKey`（DES-006 §2.4 の重複判定キー）に**含めない**・`recipe_hash` 非対象。model の Combo 構造体に `*string`（`omitempty`）で加算・DTO 素通し |
| e | PATCH クリア規約 | `PATCH /api/combos/{id}` の **presence-detection 単一トライステート**（CHANGE-043）対象に 3 列を追加（キー不在=不変更 / null=NULL クリア / 値=更新）。custom_states 等と同列 |

### 2.2 DES-002 §7.6（コンボ CSV 契約）

| # | 対象 | 変更 |
|---|------|------|
| f | `link` / `video_path` / `image_path` | **任意列として列末尾に 3 列追加**（CHANGE-061/063 で正典化した「任意列末尾追加」標準に従う）。空セル=NULL・値=その文字列。旧 CSV（3 列なし）を後方互換で受理（`requiredImportColumns` に含めない） |
| g | 往復不変 | 意味単位（文字列そのまま）で export/import を往復。パス・URL の解決や書き換えを行わない（verbatim） |

### 2.3 DES-005（画面）

| # | 対象 | 変更 |
|---|------|------|
| h | コンボ詳細 | 3 フィールドの表示。`link` は `<a rel="noopener noreferrer">`（**スキーム http/https のみリンク化**・それ以外は非リンクのテキスト）。`video_path`/`image_path` は**テキスト表示のみ**（リンク化しない） |
| i | コンボ編集 | 3 フィールドの入力欄（任意）。空入力=クリア（PATCH null） |
| j | 比較表 | 3 フィールドの行（値がある列のみ・無ければ空）。列ペアリング前提を崩さない |
| k | export/PDF/PNG | メディア列の出力可否は UI 論点として指示書側で確定（暫定＝詳細画面は表示・PDF/PNG は URL/パス文字列を載せる。画像実体の埋め込みはしない） |

### 2.4 DES-006 §6（検証）

| # | 対象 | 変更 |
|---|------|------|
| l | 緩検証 | メディア 3 列は**緩検証**。`link` は VAL-I08（URL 非リンク化の無害化）とは別枠＝明示リンク用途だが**スキーム制限（http/https 以外はリンク化しない）**で無害化。`video_path`/`image_path` は文字列として保存（パス検証なし＝本体が開かないため CHANGE-049 級の検証は不要）。**閲覧不可（リンク切れ・ファイル不在）は許容**と明文化 |
