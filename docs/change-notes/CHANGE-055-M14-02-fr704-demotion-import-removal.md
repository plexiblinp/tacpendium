## 1. 変更の概要

M14-02（取込パイプライン段階削除）の実装・レビュー・E2E 完了に伴い、確定した取込削除範囲を設計書本体へ反映する。

- **REQ-001 §3.8 FR704 を降格**（公式データ取込を本体ユーザー機能から外す）。FR703（技編集）は温存。FR702 の FR704 参照を降格に整合。
- **DES-002**: §4.2 取込エンドポイント削除・warnings 再導出の中立パッケージ化（逆依存解消）・§7.5 CSV 契約の dev/test/別ツール責務への降格。
- **DES-005**: §2 画面一覧から画面17 削除・§5.17 削除・§4.1 ナビ「技取込」導線除去。画面18（技編集）は不変。

## 2. 変更の内容

### REQ-001 §3.8

- **FR704 降格**: 「公式データ取り込みは本体アプリのユーザー機能としては提供しない（M14 で降格）。配布 DB は手入力データ同梱（FR703 で是正）、CSV 取込は dev/test 検証および別ツール（FR701／moves-input-tool）責務に限る（本体に取込画面・取込エンドポイントを持たない）」。優先度欄を「（降格・M14-02）」に。
- **FR702 整合**: 「更新は FR701 の別ツールで CSV 化し、**開発者が配布 DB（手入力 seed）へ反映**（本体側取込機能 FR704 は M14 で降格。追従手段の本体組込はフェーズ4 で再設計）」。
- FR701（別ツール）・FR703（技編集）は不変。

### DES-002 §4.2 / §7.5 / warnings

- **§4.2**: `POST /api/import/moves`・`/preview` を削除（ルート未登録＝404）。GET/PATCH `/api/moves`（技編集）は不変。
- **§4.2 warnings**: 再導出ロジック（`WarningCode`/`StoredMove`/`DeriveStoredWarnings`）を中立パッケージ `internal/service/movewarning` へ移設（取込からの逆依存解消）。
- **§7.5**: 冒頭に降格バナーを付し、CSV 契約を「別ツール（FR701）の出力契約および dev/test 検証」の参照へ降格（本体は取込・正規化を持たない）。列セマンティクスは M14-01 後の DES-003 §3.3 を正とする（旧 recovery 非永続・削除列マッピング記述は読み替え）。配布 seed は SQL マイグレ経路で投入（取込非依存）。
- §13 ディレクトリ構成は高レベル（サブパッケージ非列挙）のため**変更なし**（movewarning 移設は internal/service 内の細粒度＝§13 対象外。漏れ検知）。

### DES-005 §2 / §4.1 / §5.17 / §5.18

- **§2 画面一覧**: 画面17（moves 取込プレビュー）を削除注記化。画面18 行の「画面17 とは別」参照を整合。
- **§5.17**: 本体を削除注記へ置換（取込画面・エンドポイント・FE 取込・Header 導線・ルート除去。配布 seed 同梱・技編集で是正）。
- **§4.1 ヘッダ**: 画面17 commit 後遷移導線・「技取込」エントリ・`/import/moves` ルートの記述を除去。
- **§5.18**: 冒頭の画面17 参照を整合（画面17 削除）。warnings の 2 種縮小は CHANGE-054 で既反映（本 CHANGE では不変）。

## 5. 移行影響・リスク

- 取込削除は破壊的だが、技編集（FR703・画面18・GET/PATCH /api/moves・rush 生成・notes_tool）は中立パッケージ参照差し替えのみで**挙動不変**（E2E 確認済み）。
- export/import（FR401/405・comboio）は moves 列・取込に非依存で不変。
- M14-01〜M14-02 間の一時不整合（取込が退避キー再生成）は M14-02 で恒久解消（ガードレール解除）。
- 画面18 E2E が一時 skip（M14-03 で再有効化）＝テストカバレッジの一時低下。

## 6. 直列化・後続
