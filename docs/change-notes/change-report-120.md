## 2. 反映の中身

### 2.1 §5.0.2——**射程を拡張し、規約 2 の主語を是正した**（通知書 §2-g ／ **D-446**）

| # | 改訂 |
|---|---|
| 1 | **前文の二分を「入力側／辞書側」から「入力側／照合先」へ。** **「段の源は辞書に限らない。規則から導く段もありうる」を明記した** |
| 2 | **★★規約 2 の主語を是正した**——「緩められるのは辞書側だけである」→ **「入力側の情報を捨ててはならない。緩めてよいのは照合先だけである」**。**旧記述は手段を主語にしており、「自分の段は辞書を使わない ⇒ 本規約は当たらない ⇒ 入力側を緩めてよい」と読む余地を残していた** |
| 3 | **★規約 3′ を新設**——**段の順序を守る検査は、実データ走査では足りないことがある**（§2.5） |

**★前文の枠組みそのものは残した。** **規則から導く段も書き分けられる**（入力側には何も掛けない ／ 照合先は規則で導く）。**⇒ 枠組みを捨てるのではなく、源が辞書に限らないことを言えば済んだ。**

### 2.2 §5.0.4 を新設——**規則から導く段**（通知書 §2-a / §2-b / §2-c）

**★最も重要なのは「前段がいずれも 0 件のときにだけ引く」の実現形である。**

**as-built は早期 return の直列であり、条件式で表現していない。** **⇒ 本段のコードへ到達する条件が「前段が 0 件」以外に存在しない。**

**★これを実現形まで含めて書いた。** **条件式で書く形にすると書き漏らしが起きうるが、早期 return の直列なら書き漏らす場所そのものが無い。**

> **★帰結**——**§5.0.2 規約 3 の充足は測定結果ではなく論理から出る。** **「(a) 0 ／ (b) 0」は実データを数えて 0 だったのではなく、構造上そうなりようがない。**

### 2.3 §5.5.1 を新設——**投入側と照合側で多義の扱いが違う**（製造の §1-4）

**★通知書が押さえていなかった反映先である。**

| | 多義に当たったとき |
|---|---|
| **投入側**（§5.5） | **両方落とす** |
| **照合側の規則から導く段**（§5.0.4） | **★捨てない。候補として返す** |

**★この違いは意図である**——**投入側は「入れてしまうと後から取り消せない」ため落とすが、照合側は毎回その場で判定するため落とす必要が無い。**

**⇒ 書き分けないと、次の担当が「規則から導く段でも多義は落とすべきだ」と読んで候補提示の経路を消す。** **候補として返せることは案 E を採った理由の 1 つである。**

### 2.4 §5.7.1——**4 案の決着を書いた**（通知書 §2-d）

**同表は「選定は未了であり、本書はまだどれも採っていない」と書いていた。** **⇒ E を採ったことと、A / C を却下した理由を残した。**

**★A / C の却下理由を残す理由**——**書かないと、次の担当が「なぜプリセットを足さないのか」を再検討する。**

**★B は保留であることも明記した**（導けない別名は 2026-08-18 に「いったん非対応・将来課題」＝**D-443**）。

### 2.5 §5.0.2 規約 3′——**実データ走査では足りない**（製造の §4-2）

**★通知書が押さえていなかった反映先であり、本反映で最も一般性が高い。**

**製造の破壊確認 A**〔第 3 段を前段より先に引く〕**で赤くなったのは合成 fixture のテスト 1 本だけであり、実データを走査する基準値テストは緑のままだった。**

**理由**——**実データに競合するキーが 1 件も無いため、順序を入れ替えても実データ上の答えが 1 つも変わらない。**

**⇒ 一般形として書いた**——**「この不変条件が破れたとき、実データ上で答えが変わるか」を先に自問すること。** **変わらないなら合成が必須であり、そのとき「対照」**〔後段が別の答えを持っていること〕**も同じ検査に入れないと主張が空振りする。**

### 2.6 §5.7.6 を新設——**導出規則は 1 か所に置く**（製造の §1-2）

**消費者が 2 つになった**（seed 生成の注記 ／ 逆引きの照合先）。

| 採ってはならない形 | 理由 |
|---|---|
| **同じ規則を 2 か所へ書く** | **片方だけ直したときに静かにずれる** |
| **seed 生成から公開し、逆引きが引く** | **★層が逆である**（実行時の逆引きが seed 生成のパッケージへ依存する） |

**★`D-5`（SA 番号は `move_code` から導く。技名からは推測しない）は、これまでコード内の注記にしか存在しなかった。** **⇒ 本節が正本になった。**

### 2.7 §5.4——**規則で解いた分は本表の対象外**（通知書 §2-e ／ 製造の §1-3）

**★`D-437` が警告した落ち方**〔新キャラだけ空になり、フォールバックで日本語技名が出る。画面は壊れずテストも緑〕**が、SA 番号については構造的に消えた。**

**★ただし消えたのは規則で解いた分だけである。** **本表に載っている対象は従来どおり波ごとの再適用が要る。** **⇒ 混同しないよう明記した。**

### 2.8 §5.7.5——**相互参照**（通知書 §2-f）

**規則から導く段が表示へ波及しないのは、読み口が別だからである。** **⇒ 読み口を 1 本へ寄せると、この性質は失われる。**
