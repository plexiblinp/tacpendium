## 2. 修正概要（DES-003 §3.3・DES-004 §2.1）

- **DES-003 §3.3**: `target_combo` enum 注記に運用を追記。target_combo は**入力支援ツールで熟練入力者が人手付与する分類**で、**本体は取込値を信頼**（自動判定・アルゴリズム分類をしない）。公式取込は多段特殊技を `special`／所属セグメント扱い・区分は入力ツール側の人判断・誤分類は非致命（ユーザー指摘→本体編集/再取込で是正）・本体追加ロジックなし。
- **DES-004 §2.1**: ターゲットコンボ行に運用注記（category=target_combo の付与は入力ツールで人が行い本体は取込値を信頼・詳細 DES-003 §3.3）。既存 `tc_<番号>` 温存記述は不変。
