## 1. 何を確認したいか

M19-01 §4.6.3「提案の制約の告知(初回のみ自動表示)」の**表示済みフラグ**として、新規 localStorage キー

- **`setplay-notice-seen-v1`**(boolean)

を追加した。CLAUDE.md §10.X は**公認3キー以外の追加に CHANGE 通知を要求**しているため、本書で通知する。**§10.X の公認キー表へ本キーを追記してよいか**を確認いただきたい。

## 2. 妥当性(なぜ許容されるべきか)

- **用途は UI 状態保持のみ**: 「制約ヒントを一度見たか」の boolean 1 個。機密情報でも、DB 永続化対象のユーザー入力データ(コンボ・タグ・セットプレイ本体等)でもない。§10.X の禁止用途に該当しない。
- **指示書が明示指定**: M19-01 §4.6.3 が「DB 列を追加しない・クライアント側のローカル保持で足りる」と明記し、本キーの新設を指示している(v1.3.0 で新設された節)。
- **既存パターン踏襲**: `onboarding-seen-v1`(§10.X 公認 #3)と同一の `<feature>-seen-v1` 命名・boolean 保持・専用ヘルパ(`web/src/lib/browser-storage.ts`)経由・try-catch・キーバージョニング。保持失敗時は**非表示に倒す**(毎回表示にしない)実装。
