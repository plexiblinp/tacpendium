## 1. 変更の概要

M15-06（初回オンボーディング FB⑯）の実装・再設計完了に伴い、確定した表示要素を設計書へ反映する。**全件 FE 表示層・非スキーマ・非破壊**（DB/API/`ConfigResponse` 不変）。⑰上級者モードは M15-05 折り畳みで充足＝新設なし（不変）。

- **DES-005 §5.2/§5.4/§5.16**: 初回オンボーディングの 3 表示要素を追記。
- **CLAUDE.md §10.X**: 初回既読フラグ `onboarding-seen-v1`（localStorage・UI 状態・DB 非対象）を許容表に追加（§10.X の「3件以外は CHANGE 経由で拡張」規定に準拠）。

## 2. 変更の内容

### DES-005 §5.2（ホーム・スマホ専用）

- 「表示項目（上から順）」に **5. 初回オンボーディングバナー**（初回訪問時のみ＝localStorage `onboarding-seen-v1` 未設定時。「新規コンボ登録」の位置・主要メニューへの案内文＋✕ 閉じる。閉じ以後非表示。再表示は設定画面から＝§5.16）を追加。**※ホームはスマホ専用のため、本バナーの自動表示はスマホのみ**（PC/タブレットの能動的初回案内は §5 の構造的残課題＝下記 §7-2）。

### DES-005 §5.4（コンボ一覧）

- 表示項目5「新規登録ボタン」に、**空状態（コンボ0件・フィルタなし）時は空状態メッセージにも新規登録CTAリンクを表示**する旨を追記（文脈キャラ〔CHANGE-039〕付き href。1件以上登録で非表示）。

### DES-005 §5.16（設定）

- 「6. 詳細」節に **「初回ガイドを見る」ボタン**（押下でオンボーディング内容をダイアログ表示＝いつでも呼び出し可・`onboarding-seen-v1` フラグとは独立）を追加。

### CLAUDE.md §10.X（許容表）

- 許容用途表に **`onboarding-seen-v1`（初回オンボーディング既読フラグ・DES-005 §5.2・M15-06）** を追加。DB 非対象・機微情報なし・`browser-storage.ts` 経由。
