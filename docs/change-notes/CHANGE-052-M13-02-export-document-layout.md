## 1. 変更の概要

M13-02（コンボ PDF/PNG/クリップボード エクスポート）の実装完了に伴い、人が見る出力（PDF/PNG/クリップボード）の**出力文書レイアウト**が DES-005 §5.13 の「表示項目選択」の粒度で具体化された。実装が §5.6/§5.8 を export 文脈で拡張・微変更しており「実装が事実上の契約」状態のため、端状態を DES-005 §5.13 に明文化する（M13-01 の CHANGE-051 と同型＝実装反映）。**新規契約の追加ではなく、§5.13 item4 の具体化**。画面上の §5.6/§5.8 表示そのものは不変。

## 2. 変更の内容

### DES-005（v2.28.0）— §5.13 item4「表示項目選択」の具体化

- **常時出力（固定）**：キャラクター名・始動状況（始動技 + カウンター種別 + ポジション）。
- **選択可能項目（既定 ON）**：recipe・ダメージ・起き攻め情報（**1 トグルで §5.8 準拠の 6 行へ展開**）・有利フレーム・状況・タグ・備考・セットプレイ・キャラ固有状態。
- **出力文書レイアウト**：単独コンボ=§5.6 詳細相当 / 複数コンボ=§5.8 比較表相当。比較表の既定は **§5.6 ∪ §5.8 の superset**。「状況」行は position/stance/hit_type に **opponent_size を畳んで 1 行**。セットプレイは **「名称: フルレシピ」**形式。
- いずれも画面上の §5.6/§5.8 表示は変えず、人が見る出力の整形に適用。

## 3. 確定した設計判断（伝達メモ §2/§5 への回答）

| 項目 | 判断 | 根拠 |
|------|------|------|
| 2-1 recipe トグル可（既定 ON） | **是認・反映** | 「表示項目選択が効く」を recipe でも体感。キャラ名・始動状況は常時固定維持 |
| 2-2 oki 1 トグル→6 行展開 | **是認・反映** | §5.8 の 6 行表示と UI 簡素化の両立 |
| 2-3 状況行に opponent_size を畳む | **是認・反映（§5.8 の export 拡張と明記）** | 詳細 §5.6 は size 別項目だが、export の「状況」1 行集約は情報密度上妥当 |
| 比較表既定 = §5.6∪§5.8 superset | **是認・反映** | 比較表でも詳細項目を見たい共有要求に合致 |
| 比較表セットプレイ「名称: フルレシピ」 | **是認・反映** | §5.8 は名称一覧だが、export はフルレシピまで出す方が共有価値が高い |
| DES 反映先 | **DES-005 §5.13 のみ**（§5.8 画面表示は不変） | export 固有の整形であり、画面上の比較（§5.8）は変えない |
