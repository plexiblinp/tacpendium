## 1. 変更の概要

**発信者が自分の形式（メモ・エクセル・テキスト）で管理している「コンボ」を移行する**ヘルパー。**moves の移行ではない**（moves は M14-03 系列の配布 seed で入る。**照合先として参照するだけ＝read only**）。

**二段の役割分担**（phase3-overview §M17 ④・**外さない**）: **① アプリ外プロンプト（AI）＝自由表記 → 候補トークン列**（曖昧）／**② 本アプリ＝候補トークン列 → move マスタへの厳密照合 → `move_code` 確定**（確実）。**AI に `move_code` を生成・確定させない**。**本体から LLM を呼ばない**。

性質の宣言:

- **非破壊・スキーマ変更ゼロ**。**`moves` への書き込みゼロ**（read only）。
- **エンジンを二度作らない**: `internal/moveindex` の**消費者拡張**（**索引モジュール本体は不変**＝`git diff` 差分ゼロで証明）。**段階2 の解決サービスとは別の消費者**（**取込側はフォールバックを持たない**ため流用できない）。
- **CSV 契約（§7.6）不変**: 生成は `csvcore.ExportCSV` の再利用＝**同契約の「生成側消費者」が加わっただけ**。**`combos.csv` のみ生成**（`setups.csv` は対象外）。
- **検証を迂回しない**: 生成 CSV は**既存の import プレビューへ渡す**（VAL-I01〜I10・重複判定・取込 UI をそのまま再利用）。

### 2.1 DES-002 §4.2（新規 API 2 本）

| # | 対象 | 変更 |
|---|------|------|

## 3. 真因の記録

**該当あり（設計の前提が実装で好転 1 件・§2.4-i）**: 指示書 §3.3-6 は既知の未解決 2 件を「**必ず未解決**として人レビューへ」と想定したが、**実装が別名照合を持つため決定論で解決し得る**。**悪化ではなく好転**（**AI を通さず引ける行が増える＝アーキ方向と一致**）だが、**記述が実態と食い違う**ため本 CHANGE で補正した。

## 4. 確定した設計判断（開発者確認 2026-07-17）

| 項目 | 判断 | 根拠 |

| **エイリアス照合＝含める** | 確定 | 発信者のメモは**日本語技名**が多い。**完全一致のみ・1 件のときだけ確定** |
| **新画面を選択** | 確定 | 指示書 §2.3/§3.3-3 が許容した範囲。既存 import 画面（§5.14）は**連携口の追加のみ** |
| **未解決ステップの扱い＝行ごとにドロップ/採用** | 確定（**案 1 ＋警告**） | **実コンボには技に割り当て不能な補足行が必ず混じる**（`適当`・`...`・`2KKK`）＝**除外の導線が無いと取り込めない**。**案 1**（未解決を落として取り込む）＋**「レシピから外れる（手数が減る）」警告**で**レシピ破壊のリスクを人に判断させる**。**案 3（自由文ステップ化＝`combo_steps.move_id` NULL ＋ `modifiers.type`）は将来の拡張余地**として残す |
| **i18n キー追加なし** | 確定 | import/export 系の**固定 ja** 流儀（§4.13.1 の境界）。**M17-05a の VAL→日本語写像に合流させる**のが自然（キー乱立を避ける） |
| **未投入キャラ・キャラ不明を同一扱い** | 確定 | ともに `movesAvailable=false`・全行未解決・エラーなし。**区別する UI 上の必要が無い** |

## 7. 開発者への確認事項

1. **【最重要】① プロンプトの表現力不足の引き取り先**: 〔何を〕**followup §G-14** として登録したが、**M17 の後続サブとして着手するか／M20（カスタムプリセット）と束ねるか／別マイルストーンにするか**。〔なぜ〕**② は 81% 解決で健全だが、① が SF6 のモダン表記に耐えないとパイプライン全体が実用に届かない**。**M17-04 は「動く」が「使える」には一段要る**。〔暫定案〕**M20（カスタムプリセット＝個人辞書）と束ねる**のが最も効率的（**別名辞書の充実がテコ入れの本命**であり、**M20 の個人辞書はそこに直接効く**）。**ただし優先度の判断は開発者**。
2. **高性能モデル前提の明示**: 〔何を〕**UI／運用ドキュメントに「GPT 等の高性能モデルを推奨」と明示するか**。〔なぜ〕**Gemini 無料版はフォーマット不遵守でパース不能**＝**ユーザーが「壊れている」と誤認する**。〔暫定案〕**§5.19 の画面に一行注記**（**別サブ or M17-05a の import 体験再設計に合流**）。
