## 2. 修正概要

- **DES-005 §5.6/§5.8/§5.7/§5.13**: 始動ラベルを正典「コンボ開始時の◯◯ゲージ残量」へ統一（「始動残量」「開始残量」の並立解消・ja/en parity）。
- **DES-005 §5.13**: 消費エクスポート項目 `driveConsumed`/`saConsumed`（既定 ON・始動と対称・ja 固定）。
- **DES-005 §5.7**: 始動入力欄も消費と対称に UI クランプ（F-1(a) 対称化・BE/CSV 非連動不変）。
- **DES-005 §5.6**: register 分離明文化（表示ラベル=正典／検証エラーメッセージ=簡潔内部表現「開始残量」等・BE 不変）。
- **DES-005 §5.4**: 一覧は始動/消費非追加を維持（不変明記）。
- **DES-004 §2.2**: FB⑥ の user 表示語彙（「技」／「共通システム（移動・その他）」・生表現 rendered UI 不在・fallback 2 箇所 SSOT 整合）。

## 4. 整合性チェック結果

- **始動ラベルの一貫性**: 詳細（§5.6）・比較（§5.8）・入力欄（§5.7）・出力（§5.13）で「コンボ開始時の◯◯ゲージ残量」に統一（2 表記並立解消）。§5.4 一覧は非追加で不変。
- **register 分離**: 表示ラベル（正典）と検証メッセージ（内部表現）の使い分けを DES-005 §5.6 に明記＝BE エラー文の「開始残量」残存が「揺れ」でなく「意図的分離」として整合。
- **① 方針の維持**: 始動クランプは UI のみ・BE/CSV 範囲非連動不変（DES-006 §2.5）。
- **FB⑥/taxonomy 整合**: DES-004 §2.2 の user 表示語彙が M15-03/CHANGE-057 の「共通システム（移動・その他）」と整合・内部 taxonomy（(a)/(b)/(c)）は不変。
