**指摘①: useEffect の配置が既存 useEffect 群の「末尾」でない**

- **該当箇所**: `RecipeBuilder.tsx` lines 43–47
- **状況**: 指示書 §4.1.3 は「既存 useEffect 群の末尾に追加する」と指定しているが、実装ではコンポーネント内唯一の useEffect であり、かつ `useMemo` 群（lines 49–55）より前に配置されている。M4-00 実装以前に既存の useEffect が RecipeBuilder に存在しなかったため、「末尾」という概念が実質的に適用不能だった。
- **影響**: 機能的には全く問題なし。フック呼出し順も変化していない。
- **対応方針**: 次回 RecipeBuilder に useEffect を追加する際は、本 useEffect の後に置くことを確認する。今回の修正は不要。

**指摘②: `docs/instructions/M4-overview.md` が git ステージングに含まれている**

- **状況**: git status にて `M docs/instructions/M4-overview.md`(staged)が確認された。M4-00 指示書 §2.3「変更しないもの」には記載がなく、M4 準備作業として別途ステージングされたとみられる。
- **影響**: M4-00 実装コードには影響なし。ただしコミット前にレビュー担当または開発者が M4-overview.md の変更内容を確認し、意図した変更であることを確かめることを推奨する。

**ModifiersEditor.tsx への console.warn 未実装（M4-00 スコープ外）**

- §3.4.2 で確認した通り、ModifiersEditor.tsx にも console.warn が実装されていない。M2-04 指示書 §4.1 が「実装済み」と誤記していた可能性がある(または M2-01 以来の持ち越し)。M4-00 スコープ外だが、handover に記録されていない課題として M4 担当が意識しておくことを推奨する。必要なら CHANGE 通知書経由で確認。
