## A. 初回起動ウィザード正常系（M6-02）

### 手順

1. `config.toml` を削除（初回起動状態に戻す）
2. サーバー起動（`go run ./cmd/combomgr`）
3. ブラウザで `http://localhost:47318/` にアクセス
4. **期待**: `/wizard` にリダイレクトされる
5. ステップ 1〜7 を通過:
   - ステップ 1: 言語選択 → 日本語
   - ステップ 2: 説明画面 → 次へ
   - ステップ 3: デフォルトキャラ選択 → リュウ（または「スキップ」ボタンで既定値適用）
   - ステップ 4〜6: 各設定ステップを通過
   - ステップ 7: 確認 →「完了」押下
6. **期待**: コンボ一覧（`/combos`）へ遷移
7. **期待**: `config.toml` がリポジトリルートに自動生成、`[defaults]` セクション（`character_id = 1`, `preset_id = 1`）含む
8. ステップ 3 で「スキップ」ボタンが動作することを確認（M6-02 v1.0.2 連絡事項 4 対応）

### 結果

## B. 設定画面での設定変更 + 永続化（M6-01 + M6-02）

### 手順

1. `/settings` にアクセス
2. **期待**: 6 セクション（基本 / ユーザー / ネットワーク / データ / プリセット管理 / 詳細）が表示される
3. 基本セクションでデフォルト表示キャラを変更（複数候補がある場合は別キャラ、リュウのみの場合は同キャラ）→「保存」押下
4. **期待**: Toast 通知「設定を保存しました」、`config.toml` の `[defaults].character_id` が変更後の値に書き換わる
5. ブラウザリロード → 設定画面で変更後の値が反映されていることを確認（永続化確認）
6. ネットワークセクションでローカルモード表示を確認 — **残課題 4 修正後の挙動確認**: `127.0.0.1:<port>` 形式で表示されること
7. ユーザーセクションの disabled 確認（全項目無効 + ツールチップ「今後実装予定」相当）
8. データセクションの disabled 確認（DB パス表示のみ実装、他ボタン無効）
9. プリセット管理リンクが disabled + ツールチップ「今後実装予定」表示

### 手順

1. ブラウザのデベロッパーツールでスマホサイズ（例: iPhone 12 = 390x844）に変更
2. `http://localhost:47318/` にアクセス
3. **期待**: スマホ専用ホーム画面が表示される
4. 表示確認:
   - アプリロゴ / 名称が見える
   - 主要機能ボタン 6 件が縦並びで表示（プリセット管理は disabled + ツールチップ「今後実装予定」）
   - 「最近更新したコンボ」セクションがある（コンボ 1 件以上なら上位 3 件、0 件時はプレースホルダ、全キャラ横断）
   - 画面下部にスマホフッター 4 ボタン（コンボ一覧 / マイコンボ / 新規登録 中央大 / 設定）表示
5. 主要機能ボタン「コンボ一覧」クリック → `/combos` 遷移、コンボ一覧表示
6. **期待**: スマホフッターが他ページでも継続表示される（M6-03 案 B 全画面共通配置）
7. フッターの「設定」ボタンクリック → `/settings` 遷移
