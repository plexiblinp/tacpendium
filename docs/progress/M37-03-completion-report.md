### 4.3 ★`B01` — 副次キーを `id DESC` にした理由

`deleted_at` は `datetime('now')` の **秒精度**である（`repository.go:1367`）。
同じ秒に消した 2 行は日時だけでは順序が決まらず、`LIMIT` / `OFFSET` のページ境界で
重複・欠落が起こりうる。**⇒ 全順序を確定させる**（既存の `resolveSortClause` が同じ理由で `id` を添えているのに倣った）。
