## 設計準拠性以外の指摘事項

### 1. `--self-test` の陽性対照が、実行エラーを「検出成功」と読む（`scripts/check-dist-readme.sh:126-131`）

陽性対照は `if compare ...; then ❌ else ✅` の形であり、`compare` が返す 1（差分あり）と 2（実行エラー）を区別していない。`compare` は `mktemp` 失敗・`render` 失敗で 2 を返す設計になっているため、対照が「差分を検出した」と名乗る条件に実行エラーが含まれる。

再現（スクリプトの複製を scratchpad に作り、`compare` の 2 回目の呼び出しだけ 2 を返すようにしたもの。リポジトリ内のファイルは変更していない）:

```
  ✅ 陰性対照: 無改変なら一致と判定した
  ✅ 陽性対照: 正本を 1 行変えたら差分として検出した
自己検査: 合格(陽性は赤・陰性は緑)
exit=0
```

`check-artifact-integrity.sh` が拾うマーカー行まで出て緑になる。指示書 §4.4 が警戒したのは「照合が何も検出しない形」であり、その番人である対照が自分では偽陽性を排除できていない状態は同じ型の穴にあたる。

直し方は小さい。`compare` の終了コードを変数へ受け、`-eq 1` のときだけ合格にすればよい（1 以外は「対照が壊れている」として赤にする）。あわせて `compare` 側で `diff` の戻り値 2（diff 自身のエラー）を 1 と同じ扱いにしている箇所も、区別して 2 を返すほうが一貫する。

なお陰性対照は同じ事象を拾える位置にあるため、両方が同時に壊れない限り全体が緑になる確率は低い。緊急ではないが、対照の意味としては直しておくべきである。

### 2. 配布される `README.txt` の末尾に、開発者向けの生成手順が載る

生成注記は正本と生成物のドリフトを防ぐ仕掛けとして妥当だが、`README.txt` は配布 zip の同梱物であり、読み手は利用者である。同じファイルの中で「本 zip に入っているのは実行ファイルと本 README.txt だけです」と述べた直後に、リポジトリ相対パスと `bash scripts/check-dist-readme.sh --write` を案内する 3 行が来る。利用者には意味が取れず、実行もできない。

注記の宛先はリポジトリを読む人であるため、たとえば「（この注記はリポジトリの管理用です）」の 1 語を足すか、配布時に落とす行として扱うか、リポジトリ側の `README.txt` にだけ残す形を検討したい。判断は設計卓へ回す事項（利用者体験に触れるためハード列寄り）である。

## 良かった点

1. **実査を逐語で出したこと。** 設計卓が「武装中で読めていない」と書いた 2 か所（`.github/` / `cmd/`）を実物で埋め、そのうえで「CI は zip 化も同梱もしていない。落ちるのは main.go と DES-002 の側である」と根拠の粒度を上げている。指示書の記述を写すのではなく、確かめてから書いている。
2. **破壊確認を指示書より 1 方向多く取ったこと。** 「正本を直して生成し忘れた形」だけでなく「生成物を直接いじった形」も確かめ、なぜ 2 方向必要かを 1 行で説明している。守りたいのはドリフトであり、ドリフトには向きが 2 つあるという理解が正しい。
3. **`check-artifact-integrity.sh` を 1 本目に回して実際に赤を踏み、その逐語を残したこと。** 「自己検査を書いた」という宣言が検査機構に繋がっていなかった事例として、そのまま教訓になる形で記録されている。
4. **生成注記に日付・コミットハッシュを入れない判断。** 赤が常態化して検出力を失う形を、先例（`cmd/seedgen` の `-check`）を引いて避けている。
5. **章番号を CSS カウンタにしたこと。** 22 章の手書き番号は必ずずれる。目次側も独立のカウンタで振っており、本文と目次が別々に壊れない。
6. **改名の参照走査を件数ではなく性質で仕分けたこと。** 27 件を「生きている参照 2 件」と「歴史記録 25 件」に分け、`D-274` (3) に従って後者を書き換えていない。`future-notes/INDEX.md` を機械置換せず、役割が変わった事実を注記した判断も正しい。
7. **指示書 §5-4 の「旧名 0 件」が達成できないことを、黙って読み替えず宣言したこと。** 読み替えの根拠（歴史記録は書き換えない）と、代わりに何で判定したか（ルール面・運用面のヒット 0 件）が書かれている。
