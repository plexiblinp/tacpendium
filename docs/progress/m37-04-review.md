## 総評

**本サブは合格水準にある**。芯（初段を同定せず値を直接持つ）は指示書どおりに実装され、除外述語は開発者裁定の 4 条件で入っている。**私が独立に数え直した CSV 側の集計は、完了報告の 7 つの数値すべてと 1 件も違わなかった**（126 / 117 / 9 / 109 / 106 / 105 / 4）。**`startup` の値は全 31 CSV を機械突合して差分 0 であり、内容の変更は chun_li 1 行の `is_aerial` 1 セルだけであることを確認した**。束 C（触っていないもの）は全項目クリアである。

**差し戻しに当たる事項は 1 件も無い**。一方で**失効した記述がコード上に 3 件残っている**——うち 2 件は本サブが触った当のブロックにある。本プロジェクトの較正ではこれは「高」である（テストも lint も型検査も緑のまま、人が読む以外に見つける経路が無い）。

**最も実害が近いのは「高」ではなく中-4 である**——`first_hit_startup` は seedgen が SQL へ出力しないため、**開発者が CSV の 109 行を埋めても DB には 1 行も入らず、`csv_db_sync_test.go` が赤になる**。器は半分であり、backfill マイグレが要ることがコード・完了報告・マイグレヘッダのどこにも書かれていない。次の手番を持つのが開発者であるだけに、ここは渡す前に埋めておきたい。
