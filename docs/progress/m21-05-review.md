原因は環境のロケールである。本環境の `LC_CTYPE` は `POSIX` であり、この状態では `grep -E` の否定文字クラス `[^。]` が**バイト単位**で解釈される。`。`（`E3 80 82`）の構成バイトが除外集合に入るため、`を`（`E3 82 92`）が `[^。]` に一致せず、`供給元を 1 個` が拾えない。

```bash
# 報告書 §6 の [3]（POSIX ロケールでは 0 件を返す＝false negative）
grep -rnE "供給元(は|が)?[^。]{0,30}1 ?個|供給元は 1|ポーリングも判定も 1 組" \
  --include='*.ts' --include='*.tsx' web/src/
# → exit 1（ヒット無し）

# 是正: ロケールを固定して回す
LC_ALL=C.UTF-8 grep -rnE "供給元[^。]{0,40}1 ?個|単一の供給元|供給元を 1" \
  --include='*.ts' --include='*.tsx' web/src/
# → web/src/App.tsx:35 ／ GamepadInputProvider.tsx:4（後者は是正済みの説明文）
```
