### 3.1 `web/src/features/combo/inputResolution.ts`（**唯一の実装変更**）

`stripStrengthLabel`（**非 export・呼び出し元は `deriveSpecialFamilies` の 1 か所だけ**）へ、**先頭装飾の直後形**を落とす規則を 1 本足した。

```ts
const STRENGTH_LABELS = "弱|中|強|OD";
const STRENGTH_SEPARATOR = "[・･\\s]*";
const LEADING_DECORATION = "【[^】]*】|\\[[^\\]]*\\]";

const STRENGTH_AFTER_DECORATION = new RegExp(
  `^(${LEADING_DECORATION})(?:${STRENGTH_LABELS})${STRENGTH_SEPARATOR}`, "u",
);
```

- **★強度語の literal を 1 か所へ寄せた。** 3 本の正規表現はすべてそこから組む。**着手時点は接頭形・末尾形の 2 か所に `弱|中|強|OD` が書かれており、3 本目を足すと 3 か所になる**（同ファイルの `SPECIAL_STRENGTH_TOKENS` が同じ理由で「書き起こさない」形を採っている）。

- **★丸括弧の中は見ない。先頭以外の装飾も見ない。**
