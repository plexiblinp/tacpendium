## 総評

案 E の核心である「前の段の答えを変えない」は、**気をつけて守る形ではなく構造で守られている**——`Lookup` は早期 return の直列であり、第 3 段のコードへ到達する条件が「前 2 段がいずれも 0 件」以外に無い。したがって (a)(b)=0 は測定結果ではなく論理から出る。実測値（母集合 X の 53/15/8、`preset_aliases` 4184 行、`go test` 53 ok/FAIL 0、凍結領域 diff 0）はレビュー側で独立に再現でき、1 件も食い違わなかった。指摘は「実装が変わったのに記述が旧のまま」の型に集中しており、動作の欠陥は見つかっていない。
