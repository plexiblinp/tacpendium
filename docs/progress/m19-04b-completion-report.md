## 8. ★`go test ./...` が clean にならない — **本サブと無関係の既存 3 テストの失敗**

### 8.1 本サブ着手前の HEAD で同一の失敗を再現した（判定根拠）

**本サブの成果物 5 ファイル（マイグレ 4 ＋ テスト 1）をすべて退避した状態**で `go test ./internal/infra/migration/` を実行し、**同一の 3 件が同一のメッセージで落ちる**ことを確認した。

### 8.2 原因の診断 — **M19-04 と M14-03e の並行作業がマージ時に衝突した**

3 件とも**同じ 1 つの原因**から出ている。**M19-04（`000049`〜`000052`）と M14-03e（`000053`〜`000059`）は並行に作られ、それぞれ単独では green だったが、両方が main に載った状態を誰も実行していない。**

**推奨する是正の形**（数字だけを合わせない・増分の内訳を明示する既存運用に沿う）:
