### 13.1 「キーボード操作」とは何だったか

**対象＝検索欄付きドロップダウン（`SearchableSelect`）の候補移動。** ⇒ **一覧のタグフィルタ ＋ キャラ選択（13 コントロール全部）**。

**★確認項目に「どこを見ればよいか」を書いていなかったのが欠落である。** 手順は次のとおり:

1. `/combos` の **タグ**（または **対象キャラ**）のドロップダウンを開く
2. フォーカスは検索欄にある。**`↓` で先頭の候補へ移る**
3. **`↓` `↑` で候補を移動。端で回り込む**（先頭で `↑` → 末尾へ）
4. **`Enter` / `Space` で選択**
5. **検索語で絞った後は、残った候補だけを移動する**
6. タグ（複数選択）は選んでも閉じない ／ キャラ（単一選択）は選ぶと閉じる

**★既知の制約**: `role="combobox"` の `aria-controls` は Radix が Popover content（`role="dialog"`）を指しており、中の `<ul role="listbox">` とは別要素。**支援技術での読み上げは別途の確認が要る**（レビュー 低-4）。

### 13.2 要約ピルの 2 件の要望 —— **対応済み**

#### 要望 1: ピルを「フィルタ・ソート」の見出しの隣へ

**逐語＝「少しでも縦の枠を確保するのが目的」。**
**⇒ `CollapsibleFieldset` へ任意 prop `summaryPlacement`（既定 `"below"`）を足し、一覧のフィルタ欄だけ `"inline"` にした。**
**★本番の既存呼び出しは `RecipeBuilder.tsx:153` の 1 件だけであり、prop を渡さないので見た目は変わらない**（テストで固定）。
**★要約は `<button>` の外に置いた**——中へ入れるとボタンのアクセシブル名がピル全文（8 軸で約 80 文字）を含んで冗長になるため。

**★★追補2（2026-08-26・開発者要望「隠すボタンは従来通り右端に」）**: **inline のヘッダ行を 3 分割にした。**

```
[ フィルタ・ソート ] [ タグ: 2 件  登録状態: 仮登録のみ  … ]            [ 隠す ⌄ ]
```
