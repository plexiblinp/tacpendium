**(1) 書き出しの件数上限**（`docs/usermanual/tacpendium-readme.html:741` / `:781`）

> ch15：「**書き出しには件数の上限がありませんが**、取込のほうは 1000 行・10MiB を超えると受け付けません。……上限に当たったときは件数を示した確認が出ます。」

実装は `internal/service/comboio/export.go:17-18` で `exportRowLimit = csvcore.DefaultMaxRows`、`internal/service/comboio/csvcore/rules.go:10` で `DefaultMaxRows = 1000`。`resolveTargetCombos` は `len(out) >= exportRowLimit` で打ち切り、`ExportResult.Truncated()` が立つと画面に `export.truncation.body`「対象 {{total}} 件のうち {{included}} 件までしか出力できません。残りの {{dropped}} 件は出力に含まれません。」の確認（`data-testid="export-truncation-confirm"`）が出る。**書き出しはコンボ 1000 件で打ち切られる。**

出所は `DES-005` §5.13a の `CHANGE-165` 注記の逐語「書出に行数・バイト上限が無いのに、取込は 1000 行 / 10MiB で弾く」である。**設計書の記述を写した結果、実装と食い違った**形であり、優先度較正の「実装が変わったのに記述が旧のまま」と同型である。設計書側の是正は製造の手番ではないため、**本文の修正 ＋ 設計卓への申し送り**の 2 本立てが要る。
