### 1.2 `gosec` とは何か（開発者の問いへの回答）

Go ソースを AST で解析するセキュリティ静的解析器であり、`golangci-lint` の汎用 lint とは別枠である。検出するのは、ハードコードされた資格情報（G101）／ SQL の文字列組み立て（G201・G202）／ 弱い暗号（MD5・SHA1）／ ファイル・ディレクトリのパーミッション（G301・G306）／ パストラバーサル（G304）／ サブプロセス起動（G204）／ Cookie 属性（G124）／ 整数変換のオーバーフロー（G115）など。
