3. **★★`DES-006` §2.1（`VAL-C09` の定義）と §2.2（仮登録の緩和ルール）を読む。**
4. **★★`DES-004` §2.2 を読む**——**`move_id` の NULL は非技ステップ（ドライブラッシュ類）の正規表現でもあり、本登録でも普通に存在する。★これを知らないと 1-3 を判定できない。**

## 8. 重大な問題の判定基準（完了承認を妨げる）

- **仮登録でステップ 0 本が保存できてしまう**（1-2）。
- **★★技が未指定のステップ 1 本の仮登録が保存できなくなっている**（1-3）／ **非技ステップ 1 本が保存できない**（1-3b）。
- **`move_id` の有無でステップを数えている**（1-4）。
- **本登録の挙動が変わっている**（1-6）。
- **`M24-12` の成果が落ちている**（1-8 / 5-5）。
- **`DES-002` §4.2 の応答を変えた／`DES-003` に触れた／契約 F-1 に触れた**（2-1 / 2-2 / 2-3）。
- **★★既存データを書き換えている**（2-5）。
- **★★`VAL-S04` を内側へ移したが `*sql.Tx` を読みに使っていない**（1-16）／ **判定条件を変えている**（1-18）。
- **保存後の遷移先の表が変わっている**（2-7）。
- **新規依存が提案なしで追加されている**（2-6）。
- **★★保存ボタンを消している**（4-1）／ **`disabled` がタブ依存になっている**（4-2）。
- **E2E の書き換えで検証内容が緩められている**（5-4）。
