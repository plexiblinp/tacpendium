## 1. 設計意図との一致

### 1.1 ★受け手の調停に乗っている（§4.1・**差し戻し判定の 1 本目**）

- [ ] **受け手の表示を本サブで別に足していない**（`E-76`）

> **★ここが差し戻し判定の 1 本目である。** **保存も削除も破壊的な操作であり、意図しない面へ効いたときの被害がステップ 1 個の追加より重い。** **`DES-005` §6.4.3 の注記が名指しで禁じている。**

### 1.2 ★既存導線を呼んでいる（§4.2・**差し戻し判定の 2 本目**）

- [ ] **削除が `M21-03` の削除導線を呼んでいる**（**新しい削除経路を書いていない**。§5 (c)）
- [ ] **保存が既存の保存導線を呼んでいる**（**検証・エラー表示・遷移を作り直していない**。§5 (d)）
- [ ] **★並び替えを実装していない**（**D-358** で対象外。**★実装されていたらスコープ逸脱として指摘する。「作ってあるなら良い」としない**——**`DES-005` §6.5 の 5 番目は followup へ送られている**）
- [ ] **修飾が `DES-005` §6.7 の既存の入口を呼んでいる**（**または停止条件 3 で外され、理由が報告されている**）
- [ ] **★修飾情報の選択肢を物理側で持っていない**（`DES-003` §3.5 の固定選択式）
- [ ] **★「ステップの追加確定」を実装していない**（**D-364** で対象外。§1.2″）

> **★「入口が無かったので自分で書きました」は採らない。** **それは `D-352` が差し替えたばかりの誤りの型である**（**現物を持たない側が具体的な写像を書き、実行者が独断で解いた**）。**正しい対応は、当該操作だけを外して報告することである。**

### 1.2′ ★前置き方式（§4.2′・**差し戻し判定の 3 本目**・**D-358**）

- [ ] **前置きボタン ＋ 後続ボタンの順次入力になっている**（**同時押しで実現していない**）

- [ ] **前置き状態から抜けられる**（§5 (f3)。**押したまま入力できなくなる形になっていない**）
- [ ] **前置きを押していないとき、後続ボタン単体が通常どおりステップになる**（§5 (f4)。**`M21-03` までの挙動が変わっていない**）
- [ ] **前置き中であることが画面に出る**（§4.5 の 1′）
- [ ] **前置きに使うボタンを機体ごとに決め打ちしていない**（**登録で決めている**＝§4.2′-6）

> **★同時押しで実現していたら差し戻す。** **開発者のドメイン知識による裁定である**（**D-358**）——**開始ボタン等は他のボタンより固いことが多く、押し切りの遅れが同時押しの判定へそのまま出る。** **`DES-005` §6.4.2 の実測でも押し始めのズレは最大 45.80 ms ある。**

## 9. ★このレビューで判定してはいけないこと

- **どのボタンにどの操作を割り当てたか**——**§9.2-2 で「委ねる」とされている。** **`DES-005` §6.6 が「机上では最適解を導きにくい」と定めた領域そのものである。** **★誤爆への配慮が報告にあるかだけを見る。**
- **★「ステップの追加確定」が無いこと自体**——**実機確認の結果、開発者判断で対象外になっている**（**D-364**。**10 回とも空振り・押しっぱなしでも変わらず**）。**「`DES-005` §6.5 が挙げている」を根拠に不足と判定しない。**
- **★`closePendingStep` が呼出元 0 件のまま残っていること**——**撤去しないと決めている**（§4.7-4）。**`M21-06` が使いうるためであり、`M21-02` の as-built を動かさないためでもある。** **docblock が事実へ是正されているかだけを見る。**
- **修飾トグルをどちらの意味で解釈したか**——**§9.2-3 で「委ねる」とされている**（「特定の修飾を付け外し」か「編集を開く」か）。
- **★並び替えが無いこと自体**——**開発者判断で対象外になっている**（**D-358**）。**「`DES-005` §6.5 は 5 つ挙げている」を根拠に不足と判定しない。**
- **★前置きにどのボタンを使ったか**——**§4.2′-6 のとおり登録で決まる。** **特定のボタンを想定して判定しない。**
- **★前置き状態からの抜け方**——**§9.2-7 で「委ねる」とされている**（再度押す ／ 時間で戻る ／ 他の入口）。**抜けられるかだけを見る。**
- **「割り当てられるボタンが無い」ことの伝え方**——**§9.2-4 で「委ねる」とされている。**
- **操作が効いたことの見せ方**——**§9.2-5 で「委ねる」とされている。**
- **判定窓の値そのもの**——**`M21-02` が実測から導いて決着済みである**（`DES-005` §6.4.2）。**本サブで狭める・広げるのはスコープ外。**

- **アーケードコントローラで確認していないこと**——**開発者が非所有である**（**D-328**）。**「未検証」と書かれているかだけを見る。**
