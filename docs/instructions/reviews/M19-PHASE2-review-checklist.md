## §0. 使い方

### 0.1 このレビューが守るもの

**本サブは「値を変えないマイグレ①」と「値を変えるマイグレ②」の 2 本立てである。** レビューの中心は次の 3 点。

1. **①が値を変えていないこと**
2. **②が解除された 21 行だけを変え、それ以外に波及していないこと**
3. **①②それぞれの直後で canary が測られ、動いた場合に全数説明があること**

### 0.2 ★重大判定の基準

**次のいずれかに当たれば「重大」とする。**

| # | 重大の条件 |
|---|---|
| R-1 | **指示書 §0.2 で解除した 21 行以外の `startup` / `active` / `recovery` / `total` / `on_hit` / `on_block` が変わっている** |
| R-2 | **`is_projectile` / `is_aerial` が変わっている**（解除していない＝契約 F-1） |
| R-3 | **`internal/service/` に diff がある**（契約 F-1／F-3） |
| R-4 | **`internal/seedgen` の SQL 出力が変わっている**（新列が SQL に出るようになっている＝契約 F-6／D-219） |
| R-5 | **canary の期待値が書き換えられている**（動いた事実を期待値の更新で消している） |
| R-6 | **`unknown` / `保留` / `非攻撃技` / 空欄 が同一視されて数えられている**（D-138／D-207） |
| R-7 | **`move_code` 単独で転記しており、改名 3 件の読み替えが行われていない**（指示書 §2.5） |

### 0.3 ★重大でないもの（**誤判定しないこと**）

| # | 内容 | 理由 |
|---|---|---|
| N-1 | **`startup` / `total` / `recovery` / `on_block` が変わっている行が 21 行ある** | **指示書 §0.2 で解除済み。** これは仕様である |
| N-2 | **`startup_basis = 'unknown'` の行が Phase 2 の後も残っている** | **仕様。** 記入値が `unknown` / `保留` / 空欄の行は投入しない（指示書 §1.3） |
| N-3 | **`fastest_unreachable = 0` の行に「攻撃技ではない」ものが含まれている** | **仕様。** 記入値 `非攻撃技` は投入しない（D-207） |
| N-4 | **CSV の新列 3 本の値が SQL に出ていない** | **仕様。** seedgen は「保全のみ・SQL 非投入」（D-219） |
| N-5 | **既存マイグレが改変されている** | **★本サブでは改変を想定していないが、改変があった場合は「重大」ではなく「要説明」とする。** 設計伝達レポート §2 に記載があるかを確認する |
| N-6 | **ken のノーマル版 4 行が `unknown` のまま** | **仕様**（D-206。通し値が一意に決まらない） |
