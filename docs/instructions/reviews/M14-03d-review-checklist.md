## 2. `move_code` を是正していない（重点）

- [ ] **`move_code` の再採番・自動リネーム・自動修正を一切していない**か（**CSV が正**＝§4.2）。

- [ ] **dup 検出時に自動リネーム・自動 skip をしていない**か（**生成 fail ＋一覧報告**が正）。

## 3. 変換インフラの再利用（「二度作らない」）

- [ ] **M14-03b の seedgen を再利用**しているか（**新規実装・コピー実装・手作業生成をしていない**）。

## 9. 重大な問題（完了承認を妨げる）

- **§4.3 の実測表・判定が無い / 判定が曖昧**（本サブの核が欠けている）。Plan Mode §3.3-3 を提示せずに実装へ進んだ。
- Plan Mode 8 項目のいずれかが未確認のまま実装（推測実装）。
- **`move_code` を是正した**（再採番・自動リネーム・自動修正。**CSV が正**）。
- **dup 検出が非 0 で自動リネーム・自動 skip して投入した**。
- **seedgen の変換規則を改変した**（**`000026` の golden が byte-identical でない**・差分を放置して続行した）。**新規実装・コピー実装・手作業生成した**。
- **input-tool（別 module）を修正した**（スコープ外＝報告のみ）。
- **移動 system move 9 種を再投入・削除した**。**`drive_parry` を巻き込んだ**。
- **他キャラ・ryu に波及した**（件数で減っている／変わっている）。
- **dev DB 残渣が混入している**（clean 構築の証跡が無い）。
- スキーマを変更した。既存マイグレを改変した。`dbtest.Setup` を破壊した。down 整合が無い。
- **配布 blocker を「解除した」と報告している**（解除は全キャラ充足時点＝最終波）。
