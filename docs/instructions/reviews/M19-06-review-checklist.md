### 0.3 ★重大でないもの（**誤判定しないこと**）

| # | 誤判定しやすい状態 | 実は仕様である理由 |
|---|---|---|
| **N-1** | **一部のセットプレイが `ng` なのに、そのコンボが `ok` に該当している** | **仕様**（指示書 §2.1 (a) の EXISTS 意味論）。**セットプレイは選択肢であり、1 つでも成立すれば該当する** |
| **N-2** | **`ng` の述語が `ok` の単純な否定になっていない** | **仕様**（同 (b)）。**`ng` は「`ok` が 1 つも無い」ことを含意する**。 **★【2026-08-09・D-271】ただし「`ok` が 1 つも無い」の射程はセル内に限定された**——**コンボ全体ではない。** **同じコンボが別のセルで `ok` に該当することは、違反ではない。** |
| **N-3** | **成立状態を指定せずに軸だけ指定しても絞り込まれない** | **仕様**（同 §2.2）。軸だけでは絞り込みにならない |
| **N-4** | **一覧に成立条件の列が増えていない** | **仕様**（同 §2.4）。**本サブは絞り込みだけであり、列カスタマイズに触らない** |
| **N-5** | **マイコンボやエクスポートに絞り込みが効かない** | **§2.5 の実査で「本サブでは触らない」と判定されていれば仕様。** 完了報告に理由があるかを確認する |
| **N-6** | **native select を使っている** | **仕様**（M12-04 の as-built＝一覧フィルタのみ native 維持）。**新しい流儀を作らない** |
| **N-7** | **`migrations/` に新規ファイルが無い** | **仕様。** 本サブはスキーマ変更なし |
| **N-8** | **同じコンボが `ok` にも `ng` にも出る** | **仕様**（**2026-08-09・D-271**）。**裁定 B により 3 値は排他ではなくなった。** 画面端では成立し画面中央では不成立、という実態そのままである |
| **N-9** | **3 値の合計がセットプレイを持つコンボ数と一致しない** | **仕様**（同上）。**この検算は裁定 B で成立しなくなった。** 代わりの不変条件は **単調性**〔個別指定の結果 ⊆ 全ての結果〕 |
| **N-10** | **一部のセルを記録済みのコンボが `unverified` に出る** | **仕様**（同上）。**`unverified` は「埋め残しがある」であり「手つかず」ではない。** ラベル文言の再検討は followup `setup-result-unverified-label` |

## §2. ★3 状態の意味論（**本サブの中心**）

- [ ] **2.1** **`ok` の述語が `EXISTS(... AND result='ok')`** である（指示書 §2.1 (b)）。
- [ ] **2.2** **`ng` の述語が `EXISTS(... AND result='ng')` かつ `NOT EXISTS(... AND result='ok')`** である。
  → **`ok` の単純な否定になっていれば R-1。**
- [ ] **2.3** **★【2026-08-09・D-271 で改訂】`unverified` の述語が「セットプレイを 1 つ以上持つ」かつ「対象セルのうち未記録のセルが 1 つ以上ある」** である。
  → **「1 セルも記録が無い」で実装していれば、裁定 B の反映漏れ**（**v1.0.0 の定義であり、現行仕様ではない**）。
  → **「`ok` でない」で実装していれば R-1**（**これは変わらない**）。
- [ ] **2.4** **セットプレイを 1 つも持たないコンボが、3 値のどれにも該当しない。**
  → **`unverified` に含まれていれば R-2。**
- [ ] **2.5** **★語彙が `web/src/constants/setup-result.ts` の既存定数を再利用している**（`SETUP_RESULT_UNVERIFIED` ほか）。**第 3 の語彙を作っていないか**（R-7）。
