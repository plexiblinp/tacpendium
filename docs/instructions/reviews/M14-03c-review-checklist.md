- [ ] **FK=OFF と明示 DELETE が同一マイグレに同居していない**か（digest §5）。FK=OFF に頼らず明示順で消しているか。
- [ ] ryu の **旧 moves（000004 由来）だけ**が削除対象か。**旧 code 体系で厳密に特定**しているか（「ryu の全 moves を消す」ではない＝移動 move を巻き込まない）。
- [ ] ryu の旧 moves に紐づく **`preset_aliases` も削除**されているか（**移動 move の alias は残す**）。

## 9. 重大な問題（完了承認を妨げる）

- Plan Mode 6 項目（§3.3）のいずれかが未確認のまま実装されている（推測実装）。
- **削除が ryu 限定でない**（他キャラの moves/combos が減っている）。
- **M14-03b が投入した移動 system move（9 種）を削除・再投入している**。
- **旧 moves の特定を誤り、移動 move や `drive_parry` を巻き込んで削除している**。
- FK 依存順を誤り FK 違反が出る、or **FK=OFF と明示 DELETE が同居**している。
- 既存マイグレ（000001〜000028）を改変している。**M17-01 と連番が衝突**している。
- スキーマを変更している。
- **変換インフラ（seedgen）を新規実装・コピー実装・手作業生成している**（「二度作らない」違反）。※**I/O 境界の追加的拡張は違反でない**（§4.3.1）。
- **seedgen の変換規則を改変している**（＝**000026 の golden が byte 一致しない**・差分を放置して続行した）。
- **seedgen 拡張が ryu ハードコード**になっている（第二波で再改修が必要な形＝§4.3.1-3 違反）。
- `move_code` を再採番している（CSV が正）。
- alias が欠落している（生 code フォールバック発生）。
- dup 検出が非 0 で自動リネーム・自動 skip して投入した。
- clean 構築の証跡が無い／dev DB 残渣が混入している。
- `dbtest.Setup` を破壊した、or down 整合が無い。
