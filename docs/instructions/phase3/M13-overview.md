## 1. 目的・位置づけ

M13 はフェーズ3 の先頭マイルストーン。スコープ優先順位 C-1(開発者確定)に基づき、**データ保護・データ共有クラスタを先頭**に置く。完了 = 利用者(先行リリース中の友人)のコンボ/セットプレイデータを **export で保護(バックアップ・移行・共有)し、import で復元できる**状態。

本マイルストーンの肝は **「先行リリース中のデータと善意を壊さないこと」**。先行作成済みの export/import 成果物(別の自律製造 Claude による `autopilot-combomgr/projects/` の 3 プロジェクト)を**ゼロから作り直すのでなく、既存の設計契約(DES-002 §4.2・DES-005 §5.13/§5.14・DES-006 §6・FR401〜405)へどれだけ適合するか調査 → 契約準拠で統合**する方針を採った。あわせて破壊的 FS 操作・依存ライセンスを read-only 監査し、配布健全性の入力を得た。

## 4. 主要設計判断・調査結果の反映

### 4.1 統合方針(M13-RESEARCH-01 で確定 → M13-01/02 で実装)
- 既存 3 成果物は **全 FR が「部分」カバー**(往復テスト済み CSV コア・厚い検証層・PNG/PDF コアはあるが、比較表・setups・local_id・FR404 クリップボードが欠落)。**契約準拠で改修統合**を採用(ゼロ作り直しでない)。
- **export は意味単位(code ベース・DB 管理列除外)**(M13-RESEARCH-01 §C-4)。物理列直書きを避け、**M14 の moves 列変更に頑健**(M13↔M14 の順序依存リスクなし)。

### 4.2 旧形是正(M13-01・統合元の契約差を本体で吸収)
- **drive_damage**: 統合元 `*int` → 本体 **REAL(*float64・-6〜6・VAL-C13)**。小数欠落を防止。
- **起き攻め 6 列**: 統合元 非 NULL → 本体 **nullable(*bool)**。nil/false を区別して往復。
- **starter_move_id**: CSV に持たせず **import 時にレシピ先頭から再導出**(VAL-C03・重複判定 VAL-C02 整合。レガシー starter≠先頭は正規化)。

### 4.3 案A(DES-005 §5.13/§5.14 完全準拠)
- コンボ CSV `local_id` + セットプレイ CSV `parent_combo_local_id` の別ファイル紐付け。配送は **2 CSV を ZIP 1 個に同梱(in-memory・サーバ FS 非書込)**・import は ZIP も受理(往復対称。CHANGE-051)。
- import プレビューの**行選択はコンボ行単位**・セットプレイは親追従取込(CHANGE-051)。

### 4.4 セキュリティ・FS 安全
- **CSV 式注入無害化(VAL-I10・CHANGE-050)**: 先頭 `= + - @` を式評価しない・表示エスケープ・再 export 時 `'` 接頭辞。**自由文セル限定**(数値・JSON セルは往復同一性のため非適用 = VAL-I10 の正しい実装解釈)。
- **FS 安全(M13-RESEARCH-02)**: 破壊的 FS 操作 16 件は全て管轄内(config.toml/database.path/logging.file・CHANGE-049 検証済)・ユーザ入力パス流入 0・DB DROP なし。M13-01/02 は **in-memory 生成でサーバ FS 書込ゼロ**を維持。

### 4.5 ライセンス(M13-RESEARCH-02)
- Go require 22 件・web 44 件は全数寛容。唯一 `hashicorp/golang-lru/v2`(MPL-2.0)は require 非掲載・直接 import 0(配布前に `go mod why` 確認 = followup F13-3)。本体 **MIT 確定**だが LICENSE ファイル未配置・README「未定」(OSS 前に整備 = F13-4)。

## 5. 依存関係・進行順序

1. **M13-RESEARCH-01**(統合可否)を先行 → 完了(report 受領)。
2. **M13-RESEARCH-02**(FS/ライセンス監査)は read-only で M13-01 と並行 → 完了(report 受領・FS クリーン)。
3. **M13-01**(CSV)は RESEARCH-01 結果に依存 → 実装・レビュー完了(CHANGE-050/051)。
4. **M13-02**(PDF/PNG/クリップボード)は M13-01 の画面13 を拡張 → **起票済み・着手前**(本書時点)。
