- 画面13 エクスポートで **PDF / PNG / クリップボード**を選択でき、**単独コンボ**(画面6 詳細レイアウト相当)と**比較表**(画面8 §5.8 レイアウト相当)の**両方**を出力できる(FR402/403)。

## 4. 詳細仕様

### 4.1 画面13 への形式追加(DES-005 §5.13)
- M13-01 で実装済みの画面13 エクスポートに、形式 **PDF/PNG/クリップボード**を追加。形式選択時に**表示項目選択 UI**(§5.13-4)を出す。対象選択(全/フィルタ/選択/マイコンボ)は M13-01 と共通。
- **アクション**: PDF/PNG = ファイルダウンロード、クリップボード = コピー完了トースト(DES-005 §5.13)。

### 4.2 単独 / 比較表の両対応(FR402/403)
- **対象が単独コンボ** → 画面6 詳細(§5.6)相当のレイアウトを画像/PDF 化。
- **対象が複数コンボ** → 画面8 比較表(§5.8・横:各コンボ/縦:全項目)相当のレイアウトを画像/PDF 化。
- 切替は出力対象数で決定(§3.4-2 で確定)。

### 4.3 セットプレイ同梱(DES-005 §5.13)
- PDF/PNG/クリップボードは**コンボの下に紐づくセットプレイを並べた構造**で同梱(CSV の別ファイル方式とは異なり、人が見る形式は 1 つにまとめる)。

### 4.4 FR404 クリップボード(新規・正道)
- **`text/html`(表構造)+ `text/plain`** を `ClipboardItem` で `navigator.clipboard.write`。Excel/Google スプレッドシートに貼ると**表として**展開される(列=項目・行=コンボ/セットプレイ)。
- 権限不可/旧ブラウザのフォールバック(`text/plain` のみ等)を用意。

### 4.5 生成の所在・FS 安全(M13-RESEARCH-02 含意)
- **フロント生成**(DOM → `html-to-image` 等で画像、`pdf-lib` 等で PDF、Clipboard API でコピー)。**新規 BE エンドポイント・サーバ FS 書込を作らない**(DES-002 §4.2 が PDF/PNG を予約していないことと整合)。

### 4.6 依存追加(ライセンス確認)
- 画像/PDF 生成依存を `web/package.json` に追加する際、**実 `node_modules/<pkg>/package.json` の license が MIT 等寛容**であることを確認(followup-backlog F13-6)。非寛容なら代替を検討し Plan Mode で相談。

## 5. テスト要件

### 5.1 必須テスト(Vitest 中心・ケース数で語る)
- **形式選択**: PDF/PNG/クリップボード各で生成関数が呼ばれ、対象(単独/複数)に応じ詳細/比較表レイアウトが選ばれる。

- **FR404 クリップボード**: `ClipboardItem` に `text/html`(表)+ `text/plain` が積まれる。HTML が表構造(列=項目・行=コンボ/setup)である。フォールバック経路。
- **表示項目選択**: 選択項目のみ出力に含まれる。
- **日本語描画**: 日本語を含むコンボ/セットプレイが出力レイアウトに正しく入る(描画結果のスナップショット or DOM 検証)。
