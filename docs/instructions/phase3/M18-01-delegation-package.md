## 0. あなた（M18 指示書担当）の作業範囲と境界

**やること**: M18-01 のサブ設計の詰め・**実装指示書／レビューチェックリストの作成**・製造 Q&A の一次受け・完了報告の一次受け・**実装後の「DES 反映要点」の抽出**。

**やらないこと（重要・§15.7）**:
- **CHANGE 番号・マイグレ連番を自採番しない**（マイグレ連番は実装着手時に**中央へ請求**して払い出しを受ける）。**※中央の払い出し対象はこの 2 つ＋DES/REQ 本体反映の計 3 リソースのみ。指示書番号（`M18-NN` 等）はマイルストーンローカル＝自採番**（衝突なし・中央の払い出し不要）。
- **DES・REQ 本体を直接改訂しない**（読むのは可）。設計変更が要るときは**「DES 反映要点」を中央へ渡す**（採番・CHANGE 三点セット起票・DES 反映は中央が行う）。
- 現行版は**中央から受領した版のみ**を正とする（自前の M17 終了時点コピーを勝手に正としない）。
- チャット間の受け渡しは**開発者リレー経由**。

## 3. 実装指示書に必ず入れる観点（DoD・回帰ゲート）

- **可逆前進マイグレ＋事前バックアップ**、**FK=OFF × 明示 DELETE を同一指示書に同居させない**（digest §5）、down 整合、**既存マイグレ非改変（新規連番）**。
- **マイグレ連番は実装着手時に中央へ請求**（自採番しない）。搬送順 G-c→G-d→G-e→G-b。
- **E-14**: 触ったファイルと改造対象を突合し回帰ゲートを足す（M18-01 は M18-02/03 の前提＝特に）。
- **E-16/E-18**: 指示書に書く集計値・件数は「何を・どの単位で数えたか」を併記し検算。
- **hit_type 拡張の後方互換**（新値は新コンボのみ・旧 CSV/データ不変）を回帰で確認。
- **guard_type を combo_punishes に作らない**（block/ジャストパリィは hit_type で判別）。

## 6. 委任スコープ＝M18 全体（M18-01 だけでなく M18-02/03 も）

**M18 は全サブをあなたに委任する**（開発者確定 2026-07-19）。中央は採番・DES 反映・現行版正本に専念する。

- **M18-01（スキーマ基盤）**: 設計は確定済（本パッケージ）。あなたは**実装指示書化**が主。
- **M18-02（確定反撃ファインダー・探す）／M18-03（materialize＋マイリスト・使う）**: **設計から委任**。走査 UX・materialize 導線・curation UI・note・手動入力（ジャストパリィ始動）等の**新規設計をあなたが行い**、設計判断は「DES 反映要点」として中央へ渡す（採番・CHANGE 三点セット・DES 反映は中央）。**中央は M18-02/03 の設計骨子を先行して書かない**（半端な二重設計を避ける）。
- M18-02/03 は**新スキーマを追加しない見込み**（承認ゲートは M18-01 で完結）。もし新テーブル/新列が必要と判明したら、それは新たな承認ゲート＝**着手前に中央経由で開発者の個別承認**を得る（勝手に足さない）。
- 進行順序（overview §5）: M18-01 → M18-02 → M18-03（E-20 の 1 本動線）。**worktree 並列は M18 内では限定的**。
- **整合先（作り直さない）**: export 正典（用紙固定 A4・メディア link のみ・セットプレイ名称のみ）／M17 selectedIds（DES-005 §5.13a）／VAL-S04・FR301 dup。
