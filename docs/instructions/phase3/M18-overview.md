## 1. 目的・位置づけ
- **性格**: 新テーブル **3**（combo_punishes／combo_punish_prunings／combo_punish_curations）・新列 2（combos.materialized_from_combo_id／moves.is_projectile）・enum 拡張 1（hit_type 新区分）を伴う**新ドメイン**。後方互換・非破壊（既存行への破壊的変更なし）。破壊的マイグレは無い（すべて CREATE TABLE / ADD COLUMN）。
- **達成目標**: 相手技をガード／ジャストパリィした後の有利フレームに始動する確定反撃を記録し、パニッシュカウンター版をオンデマンドで別コンボとして materialize する（出自記録・独立フォーク）。2 画面（探す＝ファインダー／使う＝マイリスト）をツリー表示で提供。
- **依存**: 上位＝phase3-overview §M18。M14（seed/契約）確定済。**M19 とは相互独立**（限定的並列の対象）。
- **横断原則**: 走査はキャラ非依存（seed 実データ駆動・E-15）／2 画面と登録導線は「上から下へ 1 本の動線」で通し設計（E-20）／materialize コンボも export 対象（E-17・出力正典 = 用紙固定 A4・メディア link のみ・セットプレイ名称のみに従う）。
