## 1. 目的とスコープ

### 1.1 目的

base M17-05c の PDF は **「ページ＝内容の自然サイズ」で A4 に厳密に合わせていない**ため、印刷/用紙フィット時に**リスト末尾（動画パス・画像パス）が用紙下端で見切れ**、**比較表は幅も A4 を超える**。これを **用紙寸法固定＋縮小フィット＋出力内容の圧縮**（メディア視覚除外・セットプレイ名称のみ・総題削除）で解消する。**実測で、是正後は 4 列・レシピ 4 行まで A4 縦相当に原寸で収まる**（縮小不要）ことを確認済み（CHANGE-073 §2.5）。

### 1.2 スコープ（DES-005 §5.13／§5.13a・CHANGE-073 のとおり）

1. **用紙寸法を固定**（内容幅ページをやめる）。**単独＝A4 縦／比較＝A4 横**。
2. **行分割を廃止**し、**用紙超過時のみ縮小フィット**（通常は原寸）。**下限 70%**＝下回るときは**縮小せず、原寸のまま「用紙に収まりきらない」旨を注記して出力**（切らない）。**レシピは最大 4 行まで原寸**、それ超は対象外（縮小で潰れて可）。
3. **メディアは視覚出力で `link`（URL）のみ**。**`video_path`／`image_path` は視覚出力から除外**。**CSV は 3 列すべて維持**（roundtrip 契約不変）。
4. **セットプレイは視覚出力で名称のみ**（複数は `" / "` 連結）。**名称未設定（＝レシピ流用）は従来どおりレシピ表示**。
5. **比較表の総題「コンボ比較」を削除**（各コンボ列見出しは残す）。
6. **ExportDialog（§5.13a）の出力項目チェックボックスを形式別に出し分け**（**視覚のみ選択時＝15／CSV 含む選択時＝17**・案B）。

### 1.3 スコープ外（触らない）

- **列分割・見出し再掲・ページ番号・範囲ラベル・PNG の 1 枚維持＋22 件警告**（base M17-05c で完成＝**非回帰で維持**。作り直さない）。
- **出力項目の意味・値**（CHANGE-052/068 の定義）。**CSV 契約・BE export クエリ・スキーマ・M17-05b の動線/形式選択/選択上限**。
- **比較列数の可変 UI（3 列/A3 切替）**＝**今回やらない**（`PDF_COLUMNS_PER_PAGE` を名前付き定数で持つだけ・followup）。
- **縮小下限を下回る場合の列自動削減**＝**今回やらない**（下限で注記＝§1.2-2 が正）。
- **fonts.ready（§151）**＝任意・今回必須でない。

## 3. 実装の要点

### 3.1 必読

- **CHANGE-073 通知書＋DES-005 §5.13／§5.13a（v2.44.0）**（実装対象の正典）。
- **base の完了報告 `m17-05c-completion-report.md` §2〜§4**（生き残る機構＝`planPages`・`ComboExportDocument` の page prop・定数）と**引き継ぎ §0/§1/§3-1**（DOM ラスタ多重キャプチャの前提・「単独 28 項目は常に 2 ページ」問題）。
- **code-facts**（`ComboExportDocument`／`export-image/`／`ExportDialog`／`run-export.ts`／`export-items.ts`）。

### 3.2 実装

- **用紙寸法固定**: 現行の「内容幅ページ」を **A4（単独縦・比較横）固定**へ。**DOM ラスタ多重キャプチャの方式は維持**（pdf-lib ネイティブ描画にしない＝JP フォント問題回避・引き継ぎ §0）。
- **行分割の撤去**: `planPages` の行分割経路を外し、**列分割のみ**残す。**A4 超過時は縮小フィット**（原寸を優先・超過分だけスケール）。**縮小率 < 70% は縮小せず注記**（新規挙動）。
- **メディア視覚除外**: 視覚出力の描画（`ComboExportDocument`／`export-data.ts` の視覚経路）から `video_path`／`image_path` を落とす。**CSV 経路は不変**。
- **セットプレイ名称のみ**: 視覚出力のセットプレイ描画を「名称のみ・複数は `" / "`」へ。**名称未設定はレシピ表示のフォールバック**を残す。
- **総題削除**: `ComboExportDocument` の比較表総題「コンボ比較」を除去。
- **ExportDialog 出し分け**: 選択形式に応じて出力項目チェックボックスを 15/17 で出し分け（**視覚のみ 15／CSV 含む 17**）。**CSV と視覚を同時選択したら 17 を出す**（CSV に必要なため）。**PDF には video/image を描かない・CSV には出す**（出力側で分岐）。

### 3.3 Plan Mode 着手前確認（**必須**）

1. **A4 寸法の実定義**（縦/横それぞれの usable px＝縮小フィットの基準）と、**現行「内容幅」からの差し替え箇所**を実査で提示。
2. **縮小フィットの実装位置**（capture 後のスケールか・DOM 側の transform か）と、**下限 70% で注記に切り替える分岐**の位置。**注記の文言は仮でよい**（確定は開発者）。
3. **メディア視覚除外の実装点**（視覚経路と CSV 経路が同じデータ源から分岐する箇所を特定し、**CSV に波及しないこと**を示す）。
4. **セットプレイ名称のみ**の描画点と、**名称未設定フォールバック**の条件。
5. **ExportDialog の出し分け**（形式選択の state と `EXPORT_ITEMS` のフィルタ点。**CSV 含む時に 17 へ戻る**ことを含む）。
6. **base の列分割・見出し再掲・ページ番号を壊さない**ことの確認（行分割撤去の巻き添えで落ちないか）。
