## 1. 背景と目的

### 1.1 背景

- friend FB⑭（followup-backlog §A）: **新規登録のタグ色が灰色固定**で選べない。
- friend FB⑮: **タグ色がカラーコード（HEX）のみ**の入力で分かりにくい。**色名・サンプル（スウォッチ）で選びたい**。
- **非スキーマ**: `tags.color` は既存の TEXT（HEX）列（DES-003 §3.6・`NULL可`）。本サブは**保存形態を変えず（HEX を格納）**、**色の選び方（入力 UI）と既定色**を改善する。スキーマ・API・マイグレは不変。
- **入力の実体**（code-facts §1）: タグ作成/編集は `TagFormDialog`（Props `open`/`tag?`/`onOpenChange`/`onSubmit: (values: TagFormValues) => Promise<void>`）。値型 `TagFormValues`・hook `useTagFormDialog`/`useTagManagement`。表示は `TagBadgeList`・`TagListTable`、選択は `TagSelector`。**現行の色入力 UI（HEX テキスト入力か・既定灰色の出所）は §3.3 で実査特定**。

### 1.2 目的

完了時に達成される状態:

- タグ作成/編集で、**スウォッチ（色見本）＋色名の付いたパレット**から色を選べる（FB⑮）。
- **新規登録時の既定色が「灰色固定」でなくなる**（FB⑭。パレットの既定色 or ランダム/巡回など・§3.3 で確定）。
- 選んだ色は**既存 `tags.color`（HEX）に格納**（保存形態・API 不変）。上級者向けに HEX 直接入力を残すかは §3.3 で判断（残す場合もパレットが主）。
- `TagBadgeList`/`TagListTable`/`TagSelector` の色表示が新しい選択と整合。既存タグ（既存 HEX 値）は不変で表示できる。

### 1.3 このマイルストーンで作らないもの（スコープ外）

- **スキーマ・API・マイグレ・Go 側の変更**（`tags.color` は既存 HEX 列＝非スキーマ）。
- タグの分類（category）・並び・フィルタ等、色以外のタグ機能の変更。
- 色の**意味付け**（色に状態を紐づける等）＝本サブは見た目の選択のみ。
- M16 依存の表記・他 M15 サブ（入力方式=M15-03／表示整理=M15-05／オンボーディング=M15-06）。
- i18n: 色名は日本語表示。新規 i18n キーを足す場合は ja/en 両ロケール必須（parity・playbook §4.13）。ハードコード JA なら parity 非抵触（M15-03 の i18n 方針に整合）。

## 4. 詳細仕様

### 4.1 カラーパレット（スウォッチ＋色名）

- **色名＋HEX の固定パレット**を単一定義（例: 赤 `#e5484d`／橙／黄／緑／青／藍／紫／桃／茶／灰 …識別しやすい 8〜16 色・色覚配慮）。色名は日本語表示。
- `TagFormDialog` の色入力を**スウォッチ選択**に（各色見本＋色名・選択中を可視化＝枠/チェック）。タップ/クリックで選択（モバイル/LAN・arch §10）。
- 選んだ色の HEX を `TagFormValues.color` に格納（保存形態不変）。

### 4.2 既定色の是正（FB⑭）

- 新規登録の既定色を**灰色固定から是正**（**確定＝パレット既定色を固定初期選択**〔青系の目立つ 1 色・毎回同じで予測可能〕。v1.0.1）。**灰色固定にしない**のが目的。

### 4.3 HEX 入力の扱い（§3.3-3 で確定）

- **確定＝HEX 直接入力は残す**（パレットを主導線としつつ上級者向けに HEX 入力を併存。v1.0.1）。**既存タグのパレット外 HEX** は編集時に壊さず表示（近い色をハイライト or そのまま保持）。

### 4.4 表示整合・test-id

- `TagBadgeList`/`TagListTable`/`TagSelector` が新しい色選択と整合（既存 HEX 表示は不変）。
- 既存 tag 系 test-id 規約を grep 実値確定 → パレット/スウォッチ/選択状態に test-id 付与（範囲は本サブが触れる箇所に限定）。
