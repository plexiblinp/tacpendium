## 1. 設計書本体との照合(最重要)

- [ ] アクションが PDF/PNG = ダウンロード、クリップボード = コピー完了トースト(DES-005 §5.13)になっているか。

### 1.2 単独 / 比較表の両対応(FR402/403、指示書 §4.2)
- [ ] **出力対象が単独コンボ → 詳細(§5.6 画面6)相当**、**複数コンボ → 比較表(§5.8 画面8・横:各コンボ/縦:全項目)相当**のレイアウトで出力されるか。切替条件が Plan Mode 確定どおりか。
- [ ] 比較表の項目が §5.8 の比較表(全項目常時表示)と齟齬ないか。

### 1.3 セットプレイ同梱(DES-005 §5.13、指示書 §4.3)
- [ ] PDF/PNG/クリップボードで **コンボの下に紐づくセットプレイを並べた構造**で同梱されるか(人が見る形式は 1 つにまとめる。CSV の別ファイル方式とは異なる)。

### 1.4 FR404 クリップボード(新規・指示書 §4.4)
- [ ] **`text/html`(表構造)+ `text/plain`** を `ClipboardItem` で `navigator.clipboard.write` しているか。HTML が**表**(列=項目・行=コンボ/セットプレイ)で、Excel/スプレッドシートに貼ると表化するか(手順書で目視)。
- [ ] 権限不可/旧ブラウザの**フォールバック**(`text/plain` のみ等)があるか。

### 1.5 表示項目選択(DES-005 §5.13-4、指示書 §4.1)
- [ ] PDF/PNG/クリップボードで**選択した項目のみ**が出力に反映されるか。項目セットが §5.6/§5.8 に準拠するか。

### 1.6 DES 直接編集の禁止
- [ ] PDF/PNG/クリップボードの出力詳細・FR404 形式を製造担当が DES に直接書いていないか(DES 反映は設計担当判断。実装具体化は伝達メモで申し送り)。

## 9. 重大な問題の判定基準(完了承認を妨げる)
- Plan Mode 7 項目(§3.4)のいずれかが未確認のまま実装されている(推測実装)。
- 単独/比較表の両対応が欠ける(FR402/403 未達)。
- セットプレイが人が見る形式に同梱されない(DES-005 §5.13 違反)。
- FR404 がプレーンテキストのみで、スプレッドシートに表として貼れない(HTML 表の欠如)。
- サーバ FS 書込/新規 BE エンドポイントを新設している(フロント生成方針違反・M13-RESEARCH-02 含意)。
- 非寛容ライセンスの依存を確認なく追加している。
- 日本語が文字化け/欠落して出力される。
- 製造担当が DES 本体を直接編集している。
