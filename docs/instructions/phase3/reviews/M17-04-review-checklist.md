## 0'. 【最重要】スコープの取り違えが無いか（指示書 §1.0）

- [ ] **移行しているのが「ユーザー（発信者）のコンボ」**か。**moves マスタを作る・変える実装になっていない**か（**`moves` テーブルへの書き込みがゼロ**＝read only か）。
- [ ] **出力が「コンボ CSV」（`combos.csv`／`setups.csv`＝DES-002 §7.6）**か。**手入力 CSV（20 列＝seed 源）と取り違えていない**か。
- [ ] **`moves-input-tool`（別 module）を触っていない**か（phase3-overview の逐語に出てくるが、**人レビュー動線の"形"の前例**として挙げられているだけ）。**拡張したのは本体の CSV import 突合動線**（DES-005 §5.14）か。
- [ ] **`move_code` を確定しているのは「コンボのレシピの各ステップ」**か（技マスタを作っているのではない）。

## 1. 【最重要】二段の役割分担（§1.2-1）

- [ ] **AI に `move_code` を生成・確定させていない**か。**本体から LLM API を呼んでいない**か（**① アプリ外プロンプトはアプリ外**＝本体の実装対象でない）。
- [ ] **AI（外部プロンプト）の出力を `move_code` として信じる実装になっていない**か（**必ずアプリ側の厳密照合を通す**。**存在しない code・別キャラの code・綴り違いが素通りしないこと**）。
- [ ] **② コード確定は move マスタ（キャラ別・エイリアス込み）への厳密照合**で行っているか。
- [ ] **キャラを明示的に受けている**か（**AI に推測させていない**＝別キャラの技を引く事故の防止。§4.5）。

## 2. 【最重要】決定論照合（§1.2-2）

- [ ] **曖昧一致・あいまい検索・編集距離・「たぶんこれ」を実装していない**か。**引けなければ未解決**か。
- [ ] **`Lookup` はクエリを常に正規化する**（DES-002 §7.5.1）＝**呼び出し側で正規化を再実装していない**か。

## 3. 【最重要】フォールバックなし（§1.2-3・M17-overview §4.3）

- [ ] **未解決を未解決のまま返している**か（**通常技へフォールバックしていない**＝**段階2〔M17-03〕とは挙動が違う**）。
- [ ] **段階2 の解決サービス（M17-03）を流用していない**か（**索引 IF は共通・消費者は別**が正。**流用するとフォールバックが混入する**）。
- [ ] **未解決がエラーで止まらない**か（**人レビュー動線に出る**のが正）。

## 4. 【最重要】エンジンを二度作らない（§1.2-4）

- [ ] **`internal/moveindex` の消費者拡張**か（**新規実装・コピー実装をしていない**）。**`internal/moveindex` に差分が無い**か（**改変していない**）。
- [ ] 索引データ（`move_commands`）を改変していないか。

## 4'. プロンプトひな形の調整（§4.5・成果物）

- [ ] **1 キャラずつ**・**moves は必要なキャラ分だけ渡す**運用になっているか（**全キャラ分を渡していない**）。
- [ ] 調整の観察（§4.3）が報告にあるか（`?` が多すぎ／少なすぎ〔＝**推測で埋めている疑い**〕／確信度 `高` の誤り／別キャラの混入）。

## 4''. 「プロンプトをコピー」ボタン（§4.6）

- [ ] **取込ヘルパー画面に「プロンプトをコピー」ボタン**があり、押すと**プロンプト本文＋選択中キャラの moves 一覧＋カスタムプリセットのエイリアス（あれば）**が結合されてクリップボードへ入るか。

## 9. 重大な問題（完了承認を妨げる）

- **AI に `move_code` を生成・確定させている**（**本体から LLM を呼んでいる**／**AI の出力を code として信じている**）＝**二段の役割分担の崩壊＝本サブの意味が無くなる**。
- **スコープの取り違え**（**moves を作る・変える実装**／**手入力 CSV を出力**／**moves-input-tool を触った**）＝**本サブはユーザーのコンボの移行**（§1.0）。
- **プロンプトの死守部分を壊した**（§4.1＝AI に code を書かせる・推測で埋めさせる・語彙を広げる・他キャラを許す）。
- **「プロンプトをコピー」が全キャラ分の moves を入れている**（§4.5＝**1 キャラずつ**・別キャラの技を引く事故の温床）。
- **曖昧一致・編集距離・「たぶんこれ」を実装した**（決定論違反）。
- **フォールバックを実装した**（未解決を通常技へ落とした）＝**取込側はフォールバックを持たない**（M17-overview §4.3）。
- **段階2 の解決サービスを流用した**（フォールバックが混入する）。
- **`internal/moveindex` を改変した／新規実装・コピー実装した**（「二度作らない」違反）。
- **未解決がエラーで止まる**（**人レビュー動線に出るのが正**）。**未投入キャラ・キャラ不明で落ちる**。
- **CSV 契約・重複判定キー・`recipe_hash`・段階2 の解決サービス・API・スキーマを変更した**。
- **公式 HTML の取込を作った**（FR704 降格違反）。
- Plan Mode 8 項目のいずれかが未確認（推測実装）。**とくに 1/2/3 を製造の独断で決めた**。
- `make e2e` が回帰した。
