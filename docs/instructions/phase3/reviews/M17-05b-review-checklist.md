## 1. A-1: 選択 → エクスポート動線

- [ ] **一覧・マイコンボの両方**に動線があるか。**既存の選択 UI（M15-02「比較対象選択」）を流用**しているか（**新しい選択機構を作っていない**か）。
- [ ] **選択ゼロ時に「全選択（現フィルタ結果）」扱い**になるか。**対象件数が UI に明示**されるか（取り違え防止）。
- [ ] 選択 N 件・選択ゼロ（フィルタ結果全件）の**両方でテスト**があるか。

## 2. A-2: 複数形式・クリップボード排他

- [ ] 形式が**チェックボックス（複数同時選択可）**になっているか（ラジオのままでないか）。
- [ ] **クリップボードは単独選択時のみ活性**か（複数形式と同時に選べない＝**テストがあるか**）。
- [ ] 複数形式が**順次生成・ダウンロード**されるか。**ZIP に束ねていない**か（個別ファイル＝別紙 A-2）。
- [ ] **export 生成関数を新規実装していない**か（M13-02 の既存を呼んでいるか）。

## 3. ダイアログ・出力項目

- [ ] 出力項目が **28**（メディア 3 項目＝リンク／動画パス／画像パスを含む）で既定 ON か（**25 のままでないか**＝CHANGE-068 の反映漏れ）。
- [ ] **出力文書の内容・レイアウトが不変**か（単独＝§5.6 相当／複数＝§5.8 比較表相当・superset・状況行の畳み込み・セットプレイの「名称: フルレシピ」＝CHANGE-052）。**メディアは URL/パスの文字列のみ**（画像実体の埋め込みなし＝CHANGE-068）。
- [ ] ダイアログの容量（28 項目＋形式＋PDF/PNG オプション）が**スマホ幅でも成立**するか。**収まらない場合、無理に詰めず報告**しているか（**第2段の判断材料**）。

## 4. エクスポート画面（§5.13）の温存

- [ ] **新機能を足していない**か（**A-3 の 2 改善〔キャラのプルダウン/インクリメンタル検索・選択画面遷移〕を実装していない**か＝廃止予定の画面への投資は指示書 §1.3 で明示的に禁止）。
- [ ] **画面を除去していない**か（ナビ・ルート・E2E が不変か）。**除去は第2段＝個別承認**。
- [ ] 既存の export 画面の動作が**非回帰**か。

## 5. BE・契約の非改変

- [ ] **BE に export 用の新 API を足していない**か。足す必要があると判断した場合、**Plan Mode で提示し設計担当へ報告**しているか（**推測で足していないか**＝DES-002 §4.2 の CHANGE 対象）。
- [ ] **CSV 契約（DES-002 §7.6）が不変**か。**スキーマ変更ゼロ**か。

## 6. i18n 境界

- [ ] **ダイアログ・一覧の UI ラベルは i18n**（ja/en 両キー・parity テスト通過・仮英訳可）か。

## 9. 重大な問題（完了承認を妨げる）

- **クリップボードの排他が効かない**（複数形式と同時に選べる）。
- **ZIP に束ねた**（個別ファイルが正）。
