- [ ] **出口が必ず `move_code`** か。後段（修飾情報 §6.7・ラッシュ版トグル）が従来どおり働くか。
- [ ] **段階2 スコープ厳守**: **単方向（斜め含む）＋ボタン**のみ。**必殺技・SA・投げ・空中特殊技・溜め・一回転を段階2 で解決していない**（**解決表に載っていないので自然に落ちる**＝**FE で無理に引こうとしていない**か）。

## 3. 【最重要】一様フォールバック（DES-004 §2.4.5）

## 9. 重大な問題（完了承認を妨げる）

- **死守 3 契約違反**（汚い入力の解決・**モーション解析**・出口が `move_code` でない・**236 等を仮想コントローラで実演させている**）。
- **段階2 スコープ超過**（必殺技・SA・投げ・空中特殊技・溜め・一回転を段階2 で解決している）。
- **FE に解決規則を実装した**（正規化・特殊技優先・タイブレーク＝**二重実装＝「二度作らない」違反**）。
- **方向ゾーンで経路を分岐した**（**一様フォールバック違反**＝DES-004 §2.4.5）。
- **段階1 の構造引きを改変した**（**索引非依存＝未 seed キャラでも動く**性質を壊した）。
- **既存タブ（特殊技・必殺技・SA・投げ・システム・全技プルダウン）を削除・改変した**（**段階2 は代替でなく追加**）。
- **空 entries／取得失敗で画面が壊れる**（**段階1 だけで動く**が正）。
- **入力ごとに API を呼んでいる**（キャラ選択時に 1 回が正＝入力テンポを損なう）。
- **BE を触った**（§4.5 の報告なしに索引・解決規則・API を変更した）。
- **lily の 下＋強P で `great_spin` が出る**（`is_aerial` 除外が効いていない）。
- Plan Mode 8 項目のいずれかが未確認（推測実装）。**とくに 1（入力面の形）を製造の独断で決めた**。
- スキーマを変更した。`make e2e` が回帰した。
