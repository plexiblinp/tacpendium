## 1. 【最重要】出力内容の不変

- [ ] **出力文書の内容・レイアウト・既定が不変**か（単独＝§5.6 相当／複数＝§5.8 比較表相当・superset・状況行の畳み込み・セットプレイの「名称: フルレシピ」＝CHANGE-052）。
- [ ] **出力項目が 28**（メディア 3 項目を含む）か（**25 のままなら CHANGE-068 の反映漏れ**）。**メディアは文字列のみ**（画像実体の埋め込みなし）。
- [ ] **収めるために内容を削っていない**か（**切る場所を工夫するのが正**）。

## 2. 【最重要】PDF の分割規則

- [ ] **単独出力**: **カード境界で切れている**か（**カードを跨いで切っていない**）。1 枚のカードが 1 ページに収まらない場合、**継続ページに「どのコンボの続きか」が分かる見出しが再掲**されるか。
- [ ] **複数出力（比較表）**: **列方向（コンボ）で分割**され、**各ページに項目名の見出し列が再掲**されるか（**再掲が無いと右ページが読めない＝重大**）。**行（28 項目）が溢れる場合に行方向でも分割**され、**継続ページに列見出し（コンボ名）が再掲**されるか。
- [ ] **ページ番号**（`N / M`）があるか。**どの範囲か**が分かるか（例「コンボ 1–4 / 全 12」）。
- [ ] **分割規則の数値（1 ページあたり N 列 等）が実測に基づく**か（**机上の決め打ちでない**か）。**開発者の判断記録があるか**。
- [ ] **境界値のテスト**（1 件／ちょうど 1 ページ分／1 件超過）があるか。

## 3. 【最重要】PNG の上限対処（静かに壊れない）

- [ ] **PNG を分割していない**か（**1 枚のまま**＝承認済みの方針。**分割していたら重大**）。
- [ ] **canvas 16384px に当たる件数が実測**され、**現状の振る舞い**（切れる／空になる／エラー）が報告されているか。
- [ ] **上限に当たる場合に静かに壊れない**か（**上限で切って情報が欠ける実装は不可**）。**採用した振る舞いが開発者の判断どおり**か。
- [ ] **枚数上限の注意書き**が UI にあるか（**実測値に基づく件数**）。

## 4. オプション・独立性

- [ ] **分割が既定挙動**か（**「分割する/しない」のオプションを作っていない**か）。オプションを足した場合、**Plan Mode で報告し開発者の判断を得ている**か（**M17-05b のダイアログとの整合が要る**＝推測で足していないか）。
- [ ] **export の動線・形式選択（M17-05b）に手を入れていない**か。**BE の export クエリ・CSV 契約・スキーマが不変**か。

## 5. i18n 境界

- [ ] UI に文言を足した場合、**ja/en 両ロケール**（parity テスト通過・仮英訳可）か。

## 9. 重大な問題（完了承認を妨げる）

- **出力文書の内容・レイアウト・既定を変えた**（CHANGE-052／068＝本サブは「どこで切るか」だけ）。**収めるために内容を削った**。
- **出力項目が 25 のまま**（メディア 3 項目の反映漏れ）。
- **PNG を分割した**（**1 枚のまま**が承認済みの方針）。
- **PNG が静かに壊れる**（**上限で切って情報が欠ける**・現状のまま放置）。
- **比較表の分割で見出し列（項目名）を再掲していない**（右ページが読めない）。**カードを跨いで切った**。
- **分割規則の数値を実測なしで決め打ちした**（Plan Mode §3.3-2 の実測・開発者判断の記録が無い）。
- **オプション UI を推測で足した**（M17-05b のダイアログとの整合を経ていない）。
- **export の動線・形式選択（M17-05b の領域）に手を入れた**。**BE／CSV 契約／スキーマを変更した**。
- **エクスポート文書内のラベルを i18n 化した**（固定 ja の境界を破った）。
- Plan Mode 7 項目のいずれかが未確認（推測実装）。`make e2e` が回帰した。
