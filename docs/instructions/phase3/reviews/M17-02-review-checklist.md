## 3. 派生技フラグ・非派生のみ索引

- [ ] 索引に**非派生技（`is_derived=false`）のみ**が載っているか（派生技が索引に不在＝解決対象外か）。
- [ ] **`is_derived` が `moves` 本体の BOOLEAN 列**（NOT NULL・DEFAULT false・`is_aerial` と同型）として追加されているか（**索引テーブル側フィルタでない**＝§1.5-1 確定）。
- [ ] 1:N（同一 token に非派生技複数）が **id 最小タイブレーク**で決定論的に 1 つに決まるか。決めきれない組が**解決表に載っていない**か（直接指定へ）。

## 9. 重大な問題（完了承認を妨げる）

- 死守 3 契約違反（汚い入力の解決・モーション解析・出口が move_code でない）。
- 段階2 スコープ超過（溜め/一回転/空中/必殺技を解決している）。
- `moves.command` 列を復活させている（index-only 違反）。
- 索引に派生技（`is_derived=true`）が載っている、or 非派生複数が id タイブレークでない。
- 特殊技優先/フォールバック/曖昧未解決のいずれかが動かない。
- 索引が M14-03b と別エンジン（「二度作らない」違反＝二重実装）。**解決規則（正規化・特殊技優先・タイブレーク）を FE にも持たせた**（二重実装）。
- **`is_aerial=true` が解決表に混入**している（空中特殊技が地上技と衝突＝§1.5-4 違反）。
- **索引段階で必殺技・空中技を落とした**（M17-04 が使えなくなる＝§1.5-6 違反）。
- **`is_derived` を索引テーブル側フィルタにした**（§1.5-1 違反＝moves 本体列が確定）。**backfill を手書きした**、or **ユーザー生成行を UPDATE した**。
- **方向ゾーンで経路を分岐した**（§1.5-3 の一様フォールバック違反）。
- recipe_cache に波及している（解決が RecomputeComboCache を呼ぶ・command が dup/recipe に参入）。
- 既存マイグレ改変・`dbtest.Setup` 破壊・down 整合なし。
- Plan Mode 9 項目のいずれかが未確認（推測実装）、とくに 1/2/3 の着手直前ゲート承認なし。
