## 9. 重大な問題の判定基準（完了承認を妨げる）

- Plan Mode 7 項目（§3.4）のいずれかが未確認のまま実装されている（推測実装）。
- **承認ゲート G-f の着手前承認を経ずにマイグレ実装している**。
- **消費列に検証（VAL-C/D or FE zod 範囲 ERROR）を付けている**（① VAL 非連動に反する＝最重要違反）。
- **追加の接地経路を取りこぼしている**（model/DTO/repo/FE/CSV/表示のいずれか＝表示・往復の欠落）。
- **消費列を dup キー（DuplicateKey/VAL-C02）or recipe_cache に入れてしまった**（メタデータ・非対象前提に反する）。
- **CSV の後方互換を壊した**（列末尾追加でない／旧 CSV〔消費列なし〕の import が失敗）。
- **既存始動列（drive/sa available）を触って型・値を変えた**（本サブのスコープ外）。
- 000020 が ADD COLUMN でなく再構築で combos を壊す。down 整合がない。`dbtest.Setup` 経由で既存テストを壊す。FK=OFF と明示 DELETE が同居。既存マイグレ改変。製造担当が DES 本体を直接編集している。
