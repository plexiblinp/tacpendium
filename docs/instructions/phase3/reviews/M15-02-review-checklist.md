- [ ] **モバイル/LAN でタップで開く**挙動が担保されているか（arch §10）。

### 1.2 test-id・命名（指示書 §4.1・M15-overview §4.7）
- [ ] ⑤ info-mark の test-id が `info-mark-modifier` で、M15-01 の `combo-editor-*` と**衝突しない別系統**か。**③ は改称のため info-mark test-id を持たず、既存ボタン test-id を温存**しているか。

### 1.3 適用（③ 改称・⑤ info-mark）（指示書 §4.3）
- [ ] **③**「選択モード」ボタンがコンボ一覧＋マイコンボの**両箇所**で「**比較対象選択**」へ改称され、**info-mark は付いていない**か（改称で置換）。既存の選択モード動作・test-id・導線が不変か（ラベル文言のみ変更）。
- [ ] **③ 前提**: 当該選択モードが**比較専用**であることを実査確認したうえで改称しているか（汎用マルチセレクトを兼ねる場合に不正確な名称になっていないか＝§3.3-2）。
- [ ] **⑤** modifier UI（`ModifiersEditor`＋起動導線・§3.3-3 で確定）に info-mark が付き説明が出るか。
- [ ] 適用範囲が **③⑤ のみ**（決定）で、他項目へ info-mark を勝手に広げていないか。

### 1.4 説明文の内容（指示書 §4.2）

## 9. 重大な問題の判定基準（完了承認を妨げる）
- Plan Mode 実査項目（§3.3 #1/#2/#3/#5）のいずれかが未確認のまま実装されている（推測実装）。
- **既存 Tooltip/Popover を実査せず自作再発明している**（playbook §4.6）／i18n キー占有調査をせず命名衝突している（digest §4）。
- **③ が改称されていない／③ に info-mark を付けている**（③ は「比較対象選択」改称が正・info-mark は付けない）。または**比較専用性を実査せず不正確な名称**にしている。
- **⑤ の検証を脆いレシピ E2E で組んでいる**（決定は ⑤＝Vitest・③＝E2E）。
- 説明文/ラベルが **M16 依存概念（始動 vs 消費・技/非技）に踏み込んで**いる（誤説明・M15-07 の領分）。
- 既存操作・レイアウト・E2E が非回帰でない（改称/付加が既存を壊した）。
- 既存 API/データ契約が変わっている／info-mark test-id が `combo-editor-*` と衝突している。
- spec が永続 dev DB 残渣に依存して通っている。
- 製造担当が DES 本体を直接編集している。
