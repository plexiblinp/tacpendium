## 1. スキーマ・非破壊

- [ ] combos に `link`/`video_path`/`image_path`（TEXT・NULL 可）が新規連番マイグレ（**000031**・着手時の実査で確定）で追加され、**既存マイグレ 000001〜000030 が非改変**か。※直列運用のため先着調整は不要（M14-03b=000024〜000028／M14-03c=000029＋000030）。
- [ ] down で 3 列が drop（or table rebuild）・冪等・`dbtest.Setup` 全テスト通過。
- [ ] 既存列・他テーブル・setups が不変か。

## 2. 非 dup・非 recipe（重点）

- [ ] `DuplicateKey`（VAL-C02）に 3 列が**含まれていない**か（3 列だけ異なるコンボが重複判定される、のテストがあるか）。
- [ ] `recipe_hash`・`RecomputeComboCache` が 3 列で発火しないか（PATCH で 3 列変更時に cache 再計算を呼ばない・起き攻め CHANGE-063 と同型）。

## 3. model/DTO/repository・PATCH トライステート

- [ ] Combo 構造体に 3 フィールド（`*string`・omitempty・db タグ）が memo/situation と同型で加算されているか。
- [ ] SELECT/INSERT/UPDATE の 3 列追従。
- [ ] PATCH `/api/combos/{id}` が presence-detection 単一トライステート（CHANGE-043）で 3 列を扱うか（**キー不在=不変更 / null=クリア / 値=更新**を各列テスト）。

## 4. CSV（後方互換・verbatim）

- [ ] 3 列が**任意列末尾追加**（`requiredImportColumns` に含めない）か。旧 CSV（3 列なし）を後方互換で取込（3 列 NULL）できるか。
- [ ] export→import 往復で 3 列が verbatim 一致（パス/URL の解決・書換をしていない）か。

## 5. 表示・無害化（XSS 面）

- [ ] `link` が **http/https のみリンク化**、他スキーム（`javascript:` 等）は非リンクのテキスト表示か（危険スキーム無害化のテストがあるか）。`rel="noopener noreferrer"` が付くか。
- [ ] `video_path`/`image_path` が**テキスト表示のみ**（リンク化・遷移なし）か。
- [ ] 編集で空入力=クリア（PATCH null）・比較表に 3 行・PDF/PNG は文字列出力（画像実体埋め込みなし）か。

## 6. スコープ遵守

- [ ] ファイルを開く/配信/再生/プレビュー/存在確認を**実装していない**か（文字列参照まで）。リンク切れ・ファイル不在をエラーにしていないか（許容）。
- [ ] メディアを複数（配列）化していないか（各 1 件）。

## 7. コード品質・i18n

- [ ] 禁則表現・簡体字・「起き攻け」誤字・「DR」略記の grep 除去。
- [ ] **i18n 境界の遵守（指示書 §4.4-i18n）**: **詳細/比較**で追加したキーが **ja/en 両方**にあり `locales.test.ts`（parity）が通るか（仮英訳可）。**編集画面・PDF/PNG のラベルに i18n キーを足していない**か（**固定 ja＝既存流儀・DES-005 の M16-06 境界**）。※編集画面の i18n 化は followup §124(b)/§151 M13-j の別マイルストーン＝**本サブでやったら軽微でなく指摘対象**。

## 9. 重大な問題（完了承認を妨げる）

- Plan Mode 6 項目のいずれかが未確認のまま実装（推測実装）。
- 既存マイグレ改変・連番衝突（M14-03b と重複）。
- **3 列が dup キー（VAL-C02）または recipe_hash に参入している**。
- **link で危険スキーム（`javascript:` 等）がリンク化される**（XSS 面）。
- path をリンク化・遷移させている、or ファイルを開く/再生/存在確認を実装している（スコープ踏み越え）。
- CSV で 3 列を必須列にした（旧 CSV 後方互換を壊す）、or verbatim でない（解決・書換している）。
- PATCH トライステートが効かない（クリアできない or 不在で誤更新）。

- NULL 項目の詳細画面での非表示/空表示の流儀。
