### 1.3 判定ロジック（指示書 §4.3）

- [ ] `total` が **NULL のキャラはレーンごとスキップ**され、例外・0 除算・NULL 伝播で壊れない。
- [ ] 定数 `DASH_MIN_SLACK` / `JUMP_SLACK` が **1 箇所定義＋根拠コメント付き**（マジックナンバー化していない）。

## 9. 重大な問題の判定基準（完了承認を妨げる）
- 既存マイグレの改変／**seedgen の改変**（golden 破壊）。
- 連番の自採番（中央払い出し不使用）。
- **CHANGE-083 以外の新テーブル／新列の追加**（承認ゲート無視・委任 §6）。
- **ジャンプ判定に空中技自身の `total` を使っている**（キャラのジャンプ全体が正）。
- **`damage=0` と `damage IS NULL` を同一視**している（NULL を黙って除外＝本来反撃できる技が消える）。
- 除外された技を**画面から消している**（手動確認レーンに出していない）。
- backfill 件数を検算せず断定（E-16/E-18）／値の出所コメントが無い（E-24）。
- 走査規則を **FE に二重実装**している（DES-002 §4.2 の一元化方針違反）。
- 未 seed／不存在 ID で 404・500 を返す。
- `total` が NULL のキャラで例外・クラッシュする。
