## 4. 詳細仕様

### 4.1 A-1: 選択 → エクスポート動線（一覧・マイコンボ）

- **既存の選択 UI（M15-02「比較対象選択」）を流用**し、選択中に「**エクスポート**」ボタンを出す（配置は既存の比較導線に準ずる＝実コードの流儀に合わせる）。
- **選択ゼロ時**＝「**全選択（現フィルタ結果）**」扱い（＝いま画面に見えているものを出す＝WYSIWYG）。**件数をボタン or ダイアログに明示**する（「3 件をエクスポート」等）＝対象の取り違えを防ぐ。
- 押下で**エクスポートダイアログ**（§4.2）を開く。

### 4.2 エクスポートダイアログ

- **形式（A-2）**: **チェックボックス（複数同時選択可）**＝ CSV / PDF / PNG / クリップボード。**クリップボードのみ排他**＝**単独選択時のみ活性**（複数形式と同時実行すると最後の 1 つしか残らず無意味＝別紙 A-2・承認済み）。
- **出力項目**: **DES-005 §5.13 の選択可能項目（28・既定 ON）**をそのまま提示（**メディア 3 項目を含む**）。**項目の意味・既定は CHANGE-052/068 の規定を変えない**。
- **実行**: 選択された各形式を**順次生成・ダウンロード**（**ZIP に束ねない**＝個別ファイル。既存 CSV は既に ZIP）。実行中はボタン無効化。完了トースト。
- **出力文書の内容は不変**（単独＝§5.6 相当／複数＝§5.8 比較表相当・superset。CHANGE-052）。

### 4.3 エクスポート画面（§5.13）の扱い

- **温存する。新機能を足さない**（A-3 の 2 改善は実施しない＝§1.3）。**既存の動作は非回帰**。
- **第2段（画面除去）は本サブのスコープ外**＝実物確認後に個別承認（§10）。
