#### 2.6.1 ★★★ブラウザ起動の一本化

**★★経路が 2 本ある＝既存の `github.com/pkg/browser`**（BSD-2-Clause・`go.mod` の direct 依存）**を `cmd/tacpendium/main.go:637` の `launchBrowser` が使い、新設の `desktop.OpenURL` は `rundll32` を自前で叩く。**

**★★★移植元の選定理由は本体では成立しない**——**移植元のコメントは「`cmd /c start` だと黒窓が一瞬出る」を理由に自前実装を選んだが、`pkg/browser` の Windows 実装は `ShellExecute` であって黒窓を出さない。⇒ 移植元が外部依存 0 本のリポジトリだったという前提が効いている。**

**★★設計卓の案＝`pkg/browser` へ寄せる。⇒ `desktop.OpenURL` は `ValidateURL` を残したまま、実際の起動を `pkg/browser` へ委譲する。**

**★★★`ValidateURL` は捨てないこと。⇒ 設定由来の文字列が任意のプロトコル起動に化けるのを防ぐ唯一の関門である。**

**★両方残すと `CLAUDE.md` §6「重複機能ライブラリは導入しない」の趣旨から外れる。⇒ 寄せ先を変えるなら理由を書くこと**（**自己判断でよい実装詳細**）**。**
