## 4. テストの妥当性（ケース数で確認。指示書 §5 ↔ §7 DoD）
- [ ] {{テスト観点(Vitest/Go/E2E)}}
- [ ] **★完了報告のテスト結果が、コマンド自身の出力（スイート名・pass/fail の件数）で書かれているか**（教訓 **E-125**）。**「`go test ./...` 全緑」「exit 0」だけを根拠にしていないか**——**依存が未インストールでも終了コード 0 を返す経路がある**（M20-06 で `vitest: not found` が exit 0 として報告され、一度「フロントは緑」と誤報告された）。**件数が書かれていない報告は、そのテストが 1 件も走っていない可能性を排除できない。**

- [ ] **★★結果表示・警告表示を主張するテストが、実アプリと同じ状態遷移で描画されているか**（教訓 **E-217** / **E-223**。**`M23-06` / `M23-07` の 2 サブ連続で再発したため昇格**）。次の 2 点を見る。
  - **(a) 親のコールバックを no-op モックにしていないか。** 操作の完了で親が選択状態を空にし、子が「選択が空なら描画しない」で `null` を返す形は、**`onComplete` を no-op にすると親の再描画が起きず、実アプリでは 1 フレームも表示されない機能がテスト上は緑になる**（`M23-06` の一括復元の警告は、**実アプリで一度も表示されていなかった**。同じ理由で既存の「N 件失敗」表示も 2 サブ前からずっと不可視だった）。
  - **(b) 「〜が残っていない」を主張する走査型テストが、走査の前に「対象が実際に描画されたこと」を 1 行アサートしているか。** アサートが無いと、対象が `null` を返しているだけで**何も検査しないまま緑になる**（`M23-07` の i18n テストは、選択が空の状態で走査していたため**バーの文言 6 件を 1 文字も走査していなかった**）。
  - **★この型はテスト・lint・型検査のいずれでも検出できない。** `M23-06` で検出できたのは**レビューの静的読解だけ**であり、**人が呼び出し連鎖を追う以外に見つける経路が無かった。**

## 6. コード品質・規約遵守
- [ ] 曖昧語依存でない（Playbook §4.1）。定数化・命名一貫。
- [ ] i18n 追加時は ja/en 両ロケール parity（Playbook §4.13）。
- [ ] **★「N 件」「N か所」「N ルート」を書いたコメント・godoc・報告文が、実数と一致しているか**（教訓 **E-220** / **E-236**。**`M23-07` / `M23-10` の 2 サブ連続で再発したため昇格**）。次の 2 点を見る。
  - **(a) 既存の件数コメントを機械的に +1 していないか。** `M23-07` は「登録される N ルート」を `10 → 11` と増やしたが**実数は 12** だった——**元から 10 と 11 でずれており、+1 がそれを温存した。**
  - **(b) 「〜だけである」「全 N 件」と断定した文について、異なるキーワードの走査がもう 1 本回されているか。** `M23-10` は `migrations/000049:37` を落として「1 件だけ」と申告した——**同じ主張が別の言い回しで書かれていると、片方の文字列走査では出ない。**
  - **★どちらもテスト・lint・型検査で検出できない**——動作は正しく、数だけが嘘になる。**目録は、数が違えば目録として機能しない。** **★誤った件数は下流（CHANGE 反映）で拾い損ねを生む。**

- [ ] 指示書に否定形確認の節が無い場合、**「本サブでは撤回・変更した定義は無い」と明記されているか**（節の欠落と、対象が無いことは違う）。
- [ ] **★並列サブの as-built との突合が行われているか**（教訓 `E-121` ／ ボード **D-284**・**D-297**）。**同時に発行された指示書とチェックリストは、他の並列サブが完了した後の as-built を知らない。** 完了報告に、**他の並列サブの完了報告の「触ったファイル」と、本サブの改造対象の交差**を確認した記録があるか。**交差があれば回帰ゲート（壊れていないことを E2E で証明）が足されているか。**
- [ ] **「触るファイルが違うから大丈夫」で済ませていないか。** 面が交差しないことは編成時の見込みであり、**追補や開発者要望で後から交差しうる**。**並列サブが無い場合は「本サブに並列相手は無い」と明記されているか。**
