### 2.1 ★CSV・golden・DB の三点のどれに届くか

|---|---|---|---|

### 2.2 ★CSV を編集する場合

<!-- 記入指針: CSV を触らないサブでは「本サブは `character_data/*.csv` に触らない」と明記する -->

**手入力ツールで CSV を往復させないこと**（**D-218**）。往復すると **boolean 列の空欄が `false` で埋まり、列順が入れ替わる**（既存 20 列は byte-identical）。

**転記スクリプトの要件 5 つ**:

1. **RFC4180 準拠のパーサで読む**（`notes` にダブルクォート内カンマがある。`awk -F,` は誤検知する）
2. **列順を保存する**（正＝`internal/seedgen/model.go` のヘッダ定義）
3. **空欄を空欄のまま保つ**（boolean 列でも埋めない）
4. **対象行・対象列以外に 1 バイトも触らない**
5. **実行後に「変更した行数」と「変更した列」を報告し、既存列の差分がゼロであることを機械検証する**

### 2.3 ★UPDATE の書き方（契約 F-4 (2')）

**一次源が DB / CSV に無い転記マイグレ**は、**1 行 1 UPDATE でキャラクターコードと `move_code` を明示すること**（`SUPP-001` §5.5 (4)）。**条件式で束ねると写像の誤りが目視レビューで見えず、誤ってもエラーにならない。**

**(c) 既存値の保護**——**目的は「保護すべき値を上書きしないこと」であり、形の指定ではない**（**D-231**）。

| 状況 | 形 |
|---|---|
| **人手値を投入する**（既定値の行に入れる） | `AND <列> = '<既定値>'` |
| **機械規則が付けた誤値を是正する** | **遷移元の値を明示する**（`AND <列> = '<機械付与値>'`）**か、無条件とし、冪等であることと保護すべき値が無いことを設計伝達レポートに明記する** |

### 2.4 ★down は up の反転にできない

**up の `AND <列> = '<既定値>'` を down に持ち込むと 0 行にしか当たらない**（`SUPP-001` §5.5 (5)）。**down は「up が付与した値そのもの」を条件にすること。**

### 2.5 ★改名（`move_code` の変更）を含む場合

<!-- 記入指針: 改名が無いサブでは「本サブは `move_code` を変更しない」と明記する -->

- **新規 DB は golden 由来で既に新 code を持つ。** 素朴な `UPDATE ... SET code = ...` は**改名後の別行に当たり UNIQUE 衝突で落ちる**。**`NOT EXISTS` ガードを入れること。**
- **「静かに 0 行」ではなく「エラーで止まる」形の失敗がある。** 改名を含むサブではこれを前提にする。
- **転記キーは `move_code` 単独にしない。** `name_ja` との対で確認させること。**`move_code` だけで突き合わせると、別の技を上書きしてもエラーにならない。**
- **旧 code の文字列は実装経路から完全には消せない。** **改名マイグレ自身が旧 code を名指しする必要がある。** 除外対象を §5 に明記すること。

### 2.6 ★`code` 列挙型の backfill を書き換える場合

<!-- 記入指針: 該当しないサブでは「本サブは `code` 列挙型の backfill を書き換えない」と明記する -->

**中間版で止まった DB に欠陥が残る**（`v26`〜`v38` のコホートなど）。**書き換えと「前コホート救済 UPDATE」を対で入れること**（followup `is-projectile-middle-version-cohort`）。**エラーにならないため、テストを書かないと誰も気づかない。**

### 8.3 ★一次源が自由記入欄の場合

**値そのものより先に「値以外の書かれ方」を調べさせること**（Phase 2 の教訓 1）。

**実例**——309 行の記入欄に、タイポ 2 件・全角スペース混入・セル先頭の空白ゆれ・**「`through` が入っているが誤りなので `standalone` に変更したい」という先頭トークンが意味と逆になる行** 2 件・列ずれ 1 件が含まれていた。**先頭トークンだけを見る素朴なパーサは、最後の 2 件を静かに逆に読む。**

**⇒ 機械処理の前に「値の種類を全列挙して件数を出す」工程を挟ませる。** 想定外の書かれ方が**件数の異常として先に見える。**
