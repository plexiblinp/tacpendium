## 9. 重大な問題の判定基準（完了承認を妨げる）

- Plan Mode 7 項目のいずれかが未確認のまま実装されている（推測実装）。
- `GET /api/moves` の API 契約（MoveResponse）が変わっている。
- total を曖昧 recovery で自動算術し誤値を格納している（§4.3 違反）。
- name_ja を moves へ入れている / preset_aliases 投入が無く GET の表示名が解決しない。
- 取込が全体ロールバックする / 部分成功しない / upsert が冪等でない（重複行が増える）。
- combo_scaling の未知キーを黙って格納（追従漏れ検出ゲート不在）。
- 既存 seed クリアで参照データの不整合（外部キー破壊・孤児行）が生じる。

## 10. 軽微な問題の判定基準（持ち越し許容）

- 要確認強調の視覚表現の細部（色・アイコン）。
- 取込プレビューのレイアウト微調整。
- ログメッセージ文言・行レポートの体裁。
- フィクスチャの網羅度（代表行で足り、全行網羅は不要）。
