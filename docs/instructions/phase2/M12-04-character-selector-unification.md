## 1. 背景と目的

### 1.1 背景

- M12 先行リリース仕上げのうち、**キャラクター選択方式が画面ごとにバラバラ**(N-29)である点を統一する。現状(DES-005):
  - コンボ一覧(§5.4): キャラクター情報バー(切替可)+ キャラクター選択プルダウン。
  - コンボ新規登録(§5.7 #2): キャラクター情報バー + キャラクター選択プルダウン(新規時のみ、編集時固定)。
  - マイコンボ(§5.5): キャラクター情報バー + キャラクター切替プルダウン。
  - コンボ比較の追加ダイアログ(§5.8): モーダル内のキャラクター選択。
  - 技マスタ編集(§5.18): キャラ選択 → moves グリッド表示。
  - 設定(§5.16)/初回ウィザード(§5.1): デフォルト表示キャラ選択(characters 一覧から 1 体)。
- 共通要素として「キャラクター選択プルダウン」(§5 L125、既定=デフォルト表示キャラ、文脈追従=CHANGE-039)が定義済みだが、実装は画面ごとに方式・コンポーネントが分かれている。
- **方式の統一**であり、**画面別の既定・挙動(文脈追従・編集時固定・複数キャラ切替・比較の先頭コンボ既定・設定の 1 体選択)は温存**する(§1.3)。

### 1.2 目的

本指示書完了時:
- **N-29**: 6 画面のキャラクター選択 UI を**単一の共通方式/コンポーネントに統一**する。画面ごとにバラついた選択 UI(プルダウン・モーダル内選択・グリッド前選択・1 体選択)を、一貫した見た目・操作に揃える。
- **(同梱)`MoveEditGrid` の aria-label 内部値掃除**: aria-label に内部値(`is_aerial` 等、M12-01 連絡レポート §4.2)が露出している点を、C-20(内部値を出さない)の趣旨で是正(技マスタ編集を本サブで触るため同時対応)。

### 1.3 このマイルストーン(指示書)で作らないもの

- **キャラ選択の既定・挙動の変更**: 文脈追従(CHANGE-039: 一覧の選択キャラからの新規登録は当該キャラ既定 / 比較追加モーダルは先頭コンボのキャラ既定 / 文脈なしはデフォルト表示キャラ)・**編集モードのキャラ固定**(§5.7)・新規モードのキャラ変更時の確認破棄(§5.7、CHANGE-036)・マイコンボの複数キャラ切替・設定/初回の 1 体選択は**いずれも不変**。UI 方式の統一のみ。
- マイコンボへの新規登録導線の追加(無い=不変、§5.7 第32版-errata)。
- 表示項目・ソート/フィルタ・起き攻め・検証(他サブ)。
- 比較画面のページレベルキャラ選択の新設(§5.8 はモーダル内のみ=不変)。

## 4. 詳細仕様

> §3.4 の実態確認に基づき、統一先コンポーネント・置換対象を確定してから実装する。

### 4.1 キャラクター選択方式の統一(N-29)

- 6 画面のキャラ選択 UI を、**単一の共通方式/コンポーネント**(§3.4.2 で確定。既存の共通 `CharacterSelector` を正とし、未共通化箇所をこれへ寄せる方針)に統一する。見た目・操作(プルダウンか情報バー一体型か等)を一貫させる。
- **画面別の既定・挙動は温存**(§1.3 / §3.4.3):
  - 一覧・新規登録: 情報バー + 共通セレクタ。新規登録は文脈追従(CHANGE-039)・編集時固定・確認破棄(CHANGE-036)を維持。
  - マイコンボ: 共通セレクタで複数キャラ切替を維持。
  - 比較追加モーダル: モーダル内に共通セレクタを配置(先頭コンボのキャラ既定を維持、ページレベル選択は新設しない)。
  - 技マスタ編集: キャラ選択 → グリッド表示の流れを維持(選択 UI を共通セレクタへ)。
  - 設定/初回ウィザード: デフォルト表示キャラの 1 体選択(用途が異なるため、選択 UI の見た目を共通化しつつ「1 体選択・保存」の挙動は維持。グリッド選択が適切なら踏襲)。
- 統一先の具体的な見た目/操作(プルダウン中心か情報バー中心か等)は §10 で確定。
- → **CHANGE 候補**: DES-005 §5 共通要素(L125)+ 各画面節のキャラ選択記述を統一方式へ整合(画面別の既定/挙動は不変)。

### 4.2 MoveEditGrid aria-label の内部値掃除(C-20 趣旨・同梱)

- `MoveEditGrid` の aria-label に露出する内部値(`is_aerial` 等)を、ユーザー向け日本語ラベルへ是正(画面表示・スクリーンリーダー双方で内部値を出さない)。
- 技マスタ編集の編集ロジック・データは不変(aria-label の文言のみ)。
- → CHANGE 不要の見込み(i18n/表示の正しさ。DES 規定文言でなければ)。

- D(技マスタ/設定): 技マスタ編集のキャラ選択 → グリッド。設定のデフォルト表示キャラ選択 → 保存。
- E(非回帰): 既存のキャラ選択・コンボ一覧/マイコンボ/比較/編集が不変。

## 10. 開発者への確認事項(文末集約)

1. **統一する「方式」の見た目/操作**
   なぜ: N-29 は「方式統一」だが、統一先の具体形(プルダウン中心 / 情報バー一体型 / アイコングリッド等)で体験が変わる。
   暫定案: 既存の共通「キャラクター選択プルダウン」(§5 L125・情報バーからの切替を含む)を正とし、未共通化の画面(比較追加モーダル・技マスタ編集・設定)をこれへ寄せる。設定/初回の「1 体選択」は用途が異なるため見た目を共通化しつつ挙動は維持。この方針でよいか(特定の見た目の希望があればご指定ください。§3.4.2 の実態を見て Plan Mode で最終確定)。

2. **`MoveEditGrid` aria-label 掃除の同梱**
   なぜ: M12-01 §4.2 の将来掃除候補を、技マスタ編集を触る本サブで同時対応する想定。
   暫定案: 本サブに同梱(C-20 趣旨)。スコープを分けたい場合はフェーズ3 へ切り出します。
