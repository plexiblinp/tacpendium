| コード | 何を表すか（**開発者の逐語ベース**） |
|---|---|
| **`link`**〔目押し〕 | **★★*難易度*の注記である。⇒ 「特定のタイミングでぴったりボタンを押さないといけない」。★狙いは「難しい目押しコンボだから、失敗しているだけで、コンボ自体の正当性は揺らがない」ことを示すこと** |

```
2中P ＞ キャンセル〔ここは省略される〕 ＞ SA3
```

**★★★両方が付く行がありうる。⇒ 難しい目押しで、かつキャンセルしていない場合である。**
