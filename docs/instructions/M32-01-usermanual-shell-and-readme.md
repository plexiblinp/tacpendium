**★★これが本サブ最大の破壊である**——**正本を起こすとき、古い版をそのまま写すと、`main` 側で既に入っている是正が、生成のたびに巻き戻る。⇒ 生成経路を作ることが、是正を消す機構に化ける。**

**⇒ 段 1 で現物を読み、`main` の最新を正本の出発点にすること。**
