## 4. 詳細仕様

### 4.1 残課題 4 軽微修正: ネットワークセクションのローカルモード表示

#### 4.1.1 修正対象

`web/src/pages/SettingsPage.tsx`(または相当ファイル、§3.4.1 で実態確認)内の **ネットワークセクションのローカルモード時の接続情報表示部分**。

#### 4.1.2 修正前(現状の軽微乖離)

ローカルモード時にポート番号のみ表示されている(`8080` のような形式)。M6-02 v1.0.2 §4.5.4 規定との乖離。

#### 4.1.3 修正後(M6-02 v1.0.2 §4.5.4 規定通り)

```typescript
// 概念コード(製造担当が実装で確定)
{config.server.mode === "local" && (
  <div>
    <span>接続可能 IP / ポート:</span>
    <span>127.0.0.1:{config.server.port}</span>
  </div>
)}
{config.server.mode === "lan" && config.network?.primaryLanIp && (
  <div>
    <span>接続可能 IP / ポート:</span>
    <span>{config.network.primaryLanIp}:{config.server.port}</span>
  </div>
)}
{config.server.mode === "lan" && !config.network?.primaryLanIp && (
  <div>LAN IP が取得できません</div>
)}
```

ポイント:
- ローカルモード時に `127.0.0.1:` プレフィックスを明示
- LAN モード時の既存ロジック(`<network.primaryLanIp>:<port>` 表示 + LAN IP 取得失敗時のエラー表示)は変更しない
- 実装方法はテンプレートリテラル / 文字列結合のどちらでも可、製造担当の既存コードスタイルに揃える

#### 4.1.4 テスト追加

`SettingsPage.test.tsx`(または相当)に以下のテストケースを追加:

- [ ] `mode === "local"` 時、表示文字列が `127.0.0.1:<port>` 形式である(`127.0.0.1:8080` 等)

- [ ] `mode === "lan"` かつ `network.primaryLanIp` が空文字時、「LAN IP が取得できません」エラー表示(既存テストの存在状況を §3.4.2 で確認した上で、既存実装の有無に応じて回帰確認 or 新規追加)
