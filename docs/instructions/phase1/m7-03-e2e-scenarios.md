## シナリオ B: R-3 解消の動作確認(最重要 = M7-03 メイン実装)
**重要注記(2026-06-01 追記、開発者 E2E 実施結果由来)**: 本シナリオ B-2 / B-4 のキャラ切替動作確認は、現時点でリュウのみが登録されているため **テスト不能**(他キャラのテストデータが存在しないため切替動作の動作確認不可)。**M7-04 で残り 3 キャラ + AKI が追加された後** に B-2 / B-4 の完全動作確認を実施する。M7-03 完了承認時点では B-1(初期キャラ表示)+ B-3(再オープン挙動)+ B-5(Dialog scroll 制約継続)で実装の正しさを動作確認済み。テスト不能項目は M7-04 完了承認時に再実施として記録(retrospective-log v1.0.26 §6.6 開発者補足由来として記録予定)。

### B-1: AddComboToCompareModal を開く
1. ComparePage(コンボ比較画面)を開く
2. 「コンボを追加」ボタンクリック → AddComboToCompareModal が開く
3. **キャラクターセレクタ(shadcn/ui Select)が表示される**(M7-03 追加部分)
4. **キャラセレクタの初期値が `INITIAL_CHARACTER_ID` 定数で指定されたキャラ**(従来の固定キャラ、M7-RESEARCH-02 §4.4 (b) 起点状態と整合)
5. キャラセレクタの下に既存のコンボ候補リストが表示される
6. **コンボ候補リストには初期キャラのコンボのみ表示**(従来と同じ初期表示)

### B-2: キャラ切替動作確認(主要な追加機能)
1. キャラセレクタをクリック → shadcn/ui Select のドロップダウンが開く
2. キャラ一覧(全既導入キャラ)が表示される
3. 別のキャラ(例: Ken)を選択
4. **コンボ候補リストが再フェッチ → Ken のコンボ一覧に更新される**(R-3 メイン動作)
5. ローディング表示(必須項目 2 確定どおり、推奨「読み込み中...」表示)が一瞬表示される or シームレスに切り替わる
6. DevTools Network で `GET /api/combos?characterId=<Ken の ID>` リクエストが発火されている
7. さらに別のキャラ(例: Luke)を選択 → 同様に Luke のコンボに更新される

### B-3: モーダルを閉じる / 再オープン時の挙動(Q28 (A) 確定方針反映 2026-06-01)
1. モーダル右上の X ボタン or キャンセルボタンで閉じる
2. 再度「コンボを追加」ボタンで開く
3. **キャラセレクタの選択値が前回選択したキャラのまま維持される**(Q28 (A) 前回選択キャラ保持確定、`useState` がコンポーネントマウント中維持される設計、`useEffect` による `open` トリガーリセットなし)
4. **初回モーダルオープン時の挙動と比較**:初回は `INITIAL_CHARACTER_ID` 定数値、再オープン時は前回選択キャラ = 別の挙動であることを確認
5. **動作確認の手順例**:
   - 1 回目: モーダル開く → 初期キャラ(`INITIAL_CHARACTER_ID`)表示 → 別キャラ(例: Ken)に切替 → モーダル閉じる
   - 2 回目: モーダル開く → **キャラセレクタが Ken のまま** = 前回選択保持確認
6. **方針違反の不採用確認**: `useEffect(() => { setCharacterId(INITIAL_CHARACTER_ID); }, [open])` のようなリセット実装が **含まれていない** ことを実装側コード確認 or 上記動作確認で確認

### B-4: コンボ追加動作の維持確認(既存機能、回帰なし)
1. キャラセレクタで Ryu(または任意のキャラ)を選択
2. Ryu のコンボ一覧から 1 件選択(「追加」ボタンクリック等の既存 UX)
3. **モーダルが閉じる → コンボが比較対象に追加される**(既存動作維持、回帰なし)
4. 再度「コンボを追加」でモーダルを開く → 別キャラから別コンボを追加
5. **複数キャラのコンボが比較対象に並ぶ**(M7-03 で実現した新機能の利点)

### B-5: Dialog scroll 制約パターンの継続動作(M7-02 §7 適用済み確認)
1. コンボ候補が多数あるキャラ(例: Ryu)を選択
2. **コンボ候補リストが内部スクロール**(`max-h-[60vh] overflow-y-auto` 適用)
3. **モーダル自体はビューポートを超えてはみ出さない**(M7-02 適用済みの動作維持)
4. DialogHeader(タイトル「コンボを追加」)+ キャラセレクタ + DialogFooter(キャンセル等)はスクロールせず常時可視

## G. UX 評価項目(画面ショット提示推奨、playbook §14)
