DES-005 §5.12「タグ管理」現行規定:

```
**表示項目**：
1. タグ一覧（名前、カテゴリ、色、使用コンボ数）

```

= **システムタグ(`category === "mycombo_status"`)の編集・削除可否について明示規定なし**。

選択肢:

- **(A)** 設計書本体改訂不要 = 運用解釈で対応(playbook §17.2 個人開発の規模感、本件は軽微 UX 改善であり「画面実装が規定に書かれていない動作を判断する」運用解釈で対応可能。システムタグの存在自体は規定に違反しない)
- **(B)** DES-005 §5.12 改訂 = CHANGE-019 起票してから着手(「システムタグは編集・削除不可」を明示)

**設計担当の推奨**: **(A) 運用解釈で対応**。理由:
- 本件はシステムタグの存在を否定するものではなく、UI 上の表示制御に留まる
- 「タグ作成、編集、削除」というアクション規定はユーザー作成タグに対する規定として読める(システムタグはアプリ側が生成・管理するタグであり、ユーザー操作の対象外として解釈可能)
- CHANGE 通知書起票 → 開発者反映 → 着手の往復よりも、本追加タスクで運用解釈で対応する方が効率的(playbook §17.2 過剰な手順化の警戒)

製造担当は Plan Mode CLI 上で本選択肢を開発者に確認(playbook v1.9.0 §8.4.1)。**(A)** 確定後に §4 詳細仕様に着手。
