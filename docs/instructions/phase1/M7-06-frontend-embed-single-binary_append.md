【A-1】起動時のユーザー向け案内を stdout にも出す（NFR303/304 の UX）
- 問題: ブラウザ自動起動 URL・LAN アクセス URL 一覧・FW/AV 許可ヒントが
  slog.Info 経由でログファイルのみに出る（level=info）。スマホ接続したい利用者が
  LAN URL を見られず「exe 起動だけで使える」が成立しない。
- 方針: 起動時のユーザー向け案内は「運用ログでも debug でもない CLI UX 出力」と位置づけ、
  level 非依存で stdout に出す。
  - 散発的な fmt.Println ではなく、起動案内専用の stdout 出力関数（明確に命名、
    例: printStartupNotice）として実装する。CLAUDE.md §10 の fmt.Println 禁止は
    「散発的デバッグ出力の残留防止」が趣旨であり、意図的なユーザー向け起動案内は
    その対象外、という整理。
  - 出力内容: アクセス URL（PC: localhost:実ポート / LAN モード時は LAN URL 一覧）、
    FW/AV 許可のヒント。L-04 フォールバックの実ポートに追従すること。
  - 既存の slog による運用ログ（ファイル出力）は維持。二重に持つ（ログ=記録、
    stdout=ユーザー案内）。
- 設計反映（製造担当はコード実装のみ、設計書追記は設計担当が行う）:
  SUPP-001 §5.6 に「起動時ユーザー向け案内は level 非依存で stdout に出す
  （ログとは別カテゴリの CLI UX）」を後日追記予定。製造側は実装と progress-log 記録まで。
