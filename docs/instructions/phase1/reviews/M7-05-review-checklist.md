## 9. 重大な問題の判定基準(完了承認を妨げる)

- バグ#6 / E-3 の真因が誤特定 or 未修正、回帰テストなし
- window.confirm が残存(grep でヒット)
- スキーマを Plan Mode 停止なしに変更 / L-02 で DES-006 を独断改訂
- ビルド / `go test` / `npm test` 失敗、M1〜M6 or 複数キャラに回帰
- 統合 E2E でフェーズ 1 完了を妨げる重大不具合を検出
- スコープ外(新機能 / フェーズ 2-3 先行実装 / フェーズ 2-3 送り確定項目への着手 / handover の製造担当作成)に手が入っている

## 10. 軽微な問題の判定基準(持ち越し許容)

- E-2(リュウ固定 UX)を §3.4 項目 8 でフェーズ 3 前提作業に送った場合の未対応
