## 0. レビュー担当の作業手順

1. 本ファイル、対象指示書本体、CLAUDE.md、DES-005 v2.6.0 §5.4 §5.6 を読む
2. 製造ターミナルで作成されたファイル群を `view` ツールで読む
3. 下記チェックリストに沿ってレビュー実施
4. レビュー結果を `docs/progress/m1-05-review.md` に出力

**重要ルール:**

- コードは一切変更しない
- ファイル作成は `docs/progress/m1-05-review.md` のみ
- Git 操作はしない
- 不明点があれば報告書に記載し、推測で進めない

## 2. コード品質

- [ ] TypeScript: `strict` 有効、`any` 使用がないか

- [ ] TanStack Query のキー設計が一貫している
- [ ] ページコンポーネントが肥大化せず、サブコンポーネントに適切に分割されている

## 3. UI 品質

- [ ] ローディング表示・エラー表示が実装されているか

- [ ] 削除確認ダイアログがあるか

- [ ] `getSetupDisplayName` のテスト(name あり/null かつ短い/null かつ長い)

- [ ] `localStorage`、`sessionStorage`、`IndexedDB` の使用なし
- [ ] `console.log` の本番コード残存なし
- [ ] 設計書に記載のない機能の追加なし
- [ ] M0 プロトタイプの古い列構成(CHANGE-002 反映前)を採用していないか

## 6. 統合確認

- [ ] router.tsx に `/`(コンボ一覧)、`/combos/:id`(詳細)が登録されているか
