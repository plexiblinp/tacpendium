## 10. 重大な問題の判定基準

以下のいずれかに該当する場合、**重大な問題** と判定し M4-05 完了承認を保留する:

- §1.1 L-01 型定義の変更が未完了(`?` が残っている、最重要)
- §1.4 スコープ外への変更が含まれている(新機能追加、新規コンポーネント実装、L-02 / L-03 解消、下書き保存仕様、DB マイグレーション、設計書本体変更等、本指示書 §1.3 規定違反)
- §3.1 / §3.2 C-1 検証が未完了または DES-005 §5.7 (b) 規定との **重大な不整合** が解消されていない(最重要)
- §4.1 / §4.2 統合 E2E シナリオ A〜E + U-1〜U-4 の手順書が完了報告に含まれていない(8〜9 シナリオ以下の場合は不整合発覚も含めて再確認)
- §6 ビルド・型チェックが通っていない(`pnpm test` / `pnpm build` / `go test` 失敗等)
- §7 architecture-patterns.md v1.0.3 §1.1 違反(新規フックを追加した場合 ※本指示書スコープ外、新規追加なしのはず)
- §7 shadcn/ui が使用されている(playbook §4.6 違反)
- §7 / §1.4 設計書本体(REQ-001 / DES-001〜DES-006)の変更が含まれている(M4-15 反省踏襲違反、本指示書 §1.4 規定違反)
