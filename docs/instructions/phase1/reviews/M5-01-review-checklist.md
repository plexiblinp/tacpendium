- [ ] 全クエリ成功時の通常表示が動作
- [ ] **クエリ単位での失敗**: 失敗列のセルに「取得失敗」表示 + 上部の比較対象一覧カードに削除ボタンで個別除去可能
- [ ] **loading 中の列**: スケルトン or スピナー表示で「-」フラッシュを防止(本 v1.0.1 で改訂、最重要):
  - [ ] `CompareTable.tsx` の `renderCell` が `queries[index].isLoading` を Props として受け取り、loading 中の表示分岐がある
