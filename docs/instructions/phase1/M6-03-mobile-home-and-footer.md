## 1. 背景と目的

### 1.1 背景

M6(初期体験系)スコープのうち、スマホ専用ホーム画面 + スマホフッター(共通 UI 要素)を M6-03 として実装する。M6-overview v1.0.0 §4.4 で確定したスコープに加え、m6-design-session-handover §2.1 で示された **M6-6 教訓(対応表のスコープを指示書で扱う UI 全範囲まで拡張)** を踏まえて、共通 UI 要素であるスマホフッター(DES-005 §4.2)も本指示書に含める。

M6-02 完了報告(2026-05-23)で以下が確定済み:

- `/wizard` / `/settings` ルートが M6-02 で追加済み
- ヘッダの「設定」リンク追加(M6-02 v1.0.2)が SettingsPage に反映済み(他ページへの反映は別指示扱いで現状維持、本指示書 §1.3 既定)
- `Config.Defaults.CharacterID` / `PresetID` フィールドが確定(M6-02 v1.0.1)、ウィザードでデフォルトキャラ / プリセットが永続化される運用が確立済み

### 1.2 目的

本指示書完了時に以下を達成する:

- スマホ専用ホーム画面(`/` または `/home`、§3.4 着手前確認で確定)が動作し、DES-005 §5.2 規定の表示項目(アプリロゴ / ユーザー名 / 主要機能ボタン 6 件 / 最近更新したコンボ上位 3 件)が表示される
- スマホフッター(DES-005 §4.2)の主要ナビゲーション 4 ボタン(コンボ一覧 / マイコンボ / 新規登録 / 設定)が動作する
- アプリ起動時のリダイレクト分岐に **スマホ判定** が追加され、スマホ環境ではホーム画面へ、PC/タブレット環境ではコンボ一覧(`/combos`)へ自動遷移する(`isInitialized: false` 時の `/wizard` 遷移は M6-02 既存挙動を温存)
- 「最近更新したコンボ」の取得は既存 `GET /api/combos` を流用(クエリパラメータの実態は §3.4 着手前確認)
- プリセット管理ボタン(主要機能ボタン 6 件のうちの 1 つ)は M6-02 v1.0.2 と同じく **disabled + ツールチップ「今後実装予定」**(P-1 持ち越し、retrospective-log v1.0.20 §6.6)
- 既存機能(M1〜M5 + M6-01 + M6-02)に回帰なし

### 1.3 このマイルストーンで作らないもの

- **既存画面(コンボ一覧 / マイコンボ / コンボ詳細 / コンボ登録 / セットプレイ / タグ管理 / ゴミ箱 / 比較 / 設定 / ウィザード)のスマホ向けレスポンシブ調整**: handover §3.1 R-1 持ち越し、M7「レスポンシブ仕上げ」で対応。本指示書では「スマホ専用ホーム画面」「スマホフッター」の **新規実装** に絞る
- **既存ヘッダの他ページへの「設定」リンク / プリセット disabled 反映**: M6-02 v1.0.2 完了時点で SettingsPage のみ反映済み、他ページは開発者ご判断「現状維持、別指示があるので待機」(2026-05-23)で別タイミングで対応予定。本指示書のスコープには含めない
- **「最近更新したコンボ」用の新規 API 追加**: 既存 `GET /api/combos` のクエリパラメータで満たせない場合、§3.4 着手前確認で発覚 → Plan Mode で対応方針確定。原則として **新規 API は追加しない**(YAGNI、既存 API でフロント側ソート + slice 対応で代替可能)
- **複数ユーザー認証 UI**: SUPP-001 §4.2 でフェーズ 2 送り、本ホームでは「現在のユーザー名表示」のみ(複数ユーザー時に有意)
- **プリセット管理画面 `/presets`(DES-005 §5.10 + §5.11)の実装**: P-1 持ち越し(retrospective-log v1.0.20 §6.6、M6 終了間近で再協議予定)。本指示書ではホーム画面の「プリセット管理」主要機能ボタン + スマホフッターには「プリセット」ボタン自体が存在しない(DES-005 §4.2 はコンボ一覧 / マイコンボ / 新規登録 / 設定 の 4 ボタンで規定)ため、フッターには P-1 影響なし。ホームの「プリセット管理」ボタンは disabled で対応
- **下書き自動保存(FR603)**: M6-04 で実装、本指示書では扱わない
- **設計書本体(REQ-001 / DES-001〜DES-006)の改訂**: 現時点で M6-03 期間中の追加 CHANGE 起票見込みなし(M6-overview §9)
