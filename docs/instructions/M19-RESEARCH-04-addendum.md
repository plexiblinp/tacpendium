## X-1. `seed_imported=済` の保護機構は、新列の書き込みを阻むか

### なぜ必要か

本編 C-2 が `character_data/seed-progress.md` の記述を引用している——

> 「**既配布の保護**: `seed_imported=済` のキャラを修正対象に含める場合、コマンドは警告して停止する（**既配布 CSV の変更は後続 UPDATE マイグレ扱いになる**ため）」

**開発者判断により、新列の値は CSV に持つことが確定している**（ボード D-36）。**seed 済み 10 キャラの CSV にも新列の値を書き込む**ことになる。**この保護機構が、その書き込みを阻むかどうかが分からない。**

阻むなら、**M19-04 の作業手順そのものが変わる**（保護を外す／例外を設ける／別経路を使う、のいずれかが要る）。

### 調べること

- **X-1-a**: この「コマンド」の実体を特定する。**リポジトリ内のコマンドか、手入力ツール側（別 go module・調査対象外）のものか。** リポジトリ内なら実装箇所（ファイル・関数）を示す。**手入力ツール側なら「ツール側」と報告するだけでよい**（中身は見ない）。
- **X-1-b**: 保護の**発動条件**を実コードまたは文書から特定する。「修正対象に含める」とは具体的に何の操作か（CSV の書き換え全般か、特定の列か、特定のコマンドの引数か）。
- **X-1-c**: `seed-progress.md` の**現在の内容**を報告する。`seed_imported` の値がキャラごとにどうなっているか（seed 済み 10 キャラが「済」か）。
- **X-1-d**: **新列を追加した CSV を保存する操作**が、この保護に抵触するかどうかを、実コード・文書の範囲で判定する。**判定できなければ「判定できない」と報告する**（推測しない）。

## X-2. 新列の backfill マイグレを seedgen のモードとして作れるか

### なぜ必要か

**裁定により、新列の DB 投入は backfill マイグレが担う**（CSV は正本だが seedgen は保全のみ＝本編 A-4 の案 1）。**その backfill マイグレをどう作るかで、M19-04 の指示書の作業手順が変わる。**

本編 A-2 は seedgen に `-mode derived-backfill`（000034）と `-mode move-commands`（000035）があり、**いずれも golden で固定されている**ことを示した。本編 C-1 は「値を持つ code だけを列挙して UPDATE」型の前例が **is_derived / is_projectile / movement total の 3 件**あることを示した。

**つまり「CSV から backfill マイグレを生成する」機構は既に存在する。** 新列で再利用できるなら、**CSV が正本であることが実装として成立する**（人が SQL を手書きしない）。再利用できないなら、手書き SQL になり、**CSV と DB の値が乖離する余地が生まれる**。

### 調べること

- **X-2-a**: `internal/seedgen` の **`-mode` の全数**と、各モードの入力・出力・golden テストの対応を列挙する。
- **X-2-b**: `-mode derived-backfill`（`generate_m1702.go`）の実装を読み、**「CSV の特定列を読んで、値を持つ行だけ UPDATE 文に列挙する」部分がどこまで汎用か**を示す。**列名がハードコードされているか、引数で渡せるか。**
- **X-2-c**: **is_projectile の backfill（000039 / 000041）は seedgen 生成か、手書きか。** 生成なら生成コマンドを、手書きなら手書きである根拠（golden テストの有無等）を示す。
- **X-2-d**: 新列 3 本の backfill を **既存モードの拡張**として作る場合と、**新モード**として作る場合の、**それぞれで触るファイルと壊れる可能性のあるテスト**を列挙する。**どちらが良いかは判断しない**（併記）。
- **X-2-e**: **golden テストを新規に追加する手順**（既存 4 stem のテストが `generate_test.go` / `generate_m1702_test.go` にどう書かれているか。新しい生成物に golden を付けるとき、何を書けば足りるか）。
