## 0. この指示書の特殊性

### 0.1 ★★★開発者が「対応したい」と言っている。⇒ やるかどうかは決まっている

**`M30-05` の実機確認（2026-09-12）で開発者が確認し、逐語で「D は対応したい」と回答した。⇒ 起票の可否を問う段階は終わっている。**

**★決まっていないのは「どう作るか」だけである。**

### 0.2 ★★何が起きているか

**弱/中/強が選べるファミリー行なのに、行の名前が「弱…派生」で固定されている。⇒ 中や強を選んでも名前が変わらない。★利用者から見ると、行の名前が最弱メンバーの名前になっている。**

**★対象は cammy の 4 行**（`M30-05` の実測）:

| `family` | 現在の表示名 |
|---|---|
| `silent_step` | サイレントステップ(**弱**フーリガン派生) |
| `cannon_strike_hooligan_combination` | キャノンストライク(**弱**フーリガンコンビネーション派生) |
| `reverse_edge_hooligan_combination` | （同型） |
| `fatal_leg_twister` | （同型） |

**★機序＝代表名の選択が `light → none → medium → heavy → od` の優先で 1 件の `nameJa` を採っている**（`web/src/features/combo/inputResolution.ts:289-296` 付近。**★行番号は `M30-05` 時点のものであり、実物で取り直すこと**）**。⇒ 4 行はいずれも `byVariant.plain` に light/medium/heavy を持つ。**

### 0.3 ★★★「落とす」方向では解けない（**`M30-05` の規則を広げないこと**）

**丸括弧の中の強度語を落とすことは `DES-004` §2.1 の規約が禁じている**——**丸括弧の中は*派生元*の強度であり、その技自身の強度ではない。**

**★★★実害のある反例が在る＝`cannon_strike_{light,medium,heavy}_od_hooligan_combination` のような OD だけの兄弟 3 行では、落とすと 3 行とも同一表示になって区別できなくなる。⇒ `M30-05` の実機確認 C が「区別できること」を確認した形を壊す。**

**⇒ 本サブは「落とす」ではなく「代表名をどう作るか」を設計する。**

### 0.4 ★★方式は決まっていない（**★製造が段 1 の実査で材料を出し、段 2 で選ぶ**）

**`M30-05` が挙げた候補は 2 つである。★どちらも設計判断であり、製造が実測を添えて選んでよい**（`CLAUDE.md` §9-2）**。⇒ 選定理由を報告に書くこと。**

| 案 | 内容 | 見立て |
|---|---|---|
| **(a) 丸括弧の中身から強度語だけを落として代表名を作る** | `サイレントステップ(弱フーリガン派生)` → `サイレントステップ(フーリガン派生)` | **★表示の側だけで閉じる。⇒ マイグレ 0・`name_ja` は不変。★§0.3 の反例に当たらないかを実測で確かめること**（**OD 兄弟 3 行が区別できるままか**） |
| **(b) 代表名を強度非依存の別フィールドで持つ** | ファミリーの表示名を `move` の `name_ja` から採らない | **★重い。⇒ 「どこから採るか」の設計が要る。★データを触るなら止まって請求すること** |

**★★★(a) を先に試すこと。⇒ (a) で §0.3 の反例に当たらないなら、それで足りる。★(b) は (a) が成立しないと分かってから検討する。**

> **★★`M30-05` は「落とす方向では解けない」と書いたが、それは*その技自身の強度を落とす*方向の話である。⇒ (a) は*丸括弧の中の派生元の強度*を、**代表名を作るときだけ**落とす。★表示名そのものを書き換えるのではない。★この区別を報告で明示すること。**

### 0.5 ★並列上の注意

**`M30-05` と `M31-06` の両方が着地した後に投入する。⇒ 3 サブとも `web/src/features/combo/` を触る。**

**★共有テスト `web/src/features/combo/moveSurfacing.roster.test.ts` と `specialFamilyLabel.roster.test.ts` は、触ったら何をどう変えたかを報告に書くこと。**
