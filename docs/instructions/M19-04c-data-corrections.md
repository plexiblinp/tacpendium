## 2. ★最重要 — CSV と golden への波及

**本サブは「UPDATE マイグレを 1 本書けば終わり」ではない。**

**`startup` / `total` / `code` / `command` は `character_data/*.csv` が正本であり、CSV から seedgen が生成した SQL がマイグレとして着地している。** したがって:

| 経路 | やること | やらないと何が起きるか |
|---|---|---|
| **(1) CSV** | **`character_data/guile.csv` / `kimberly.csv` / `lily.csv` / `mai.csv` / `manon.csv` を是正する** | **正本が誤ったまま残る。** 次に seed を作り直すと誤りが復活する |
| **(2) golden** | **該当 stem の golden を再生成する** | **golden が red になり CI が通らない** |
| **(3) マイグレ** | **UPDATE マイグレで既存 DB へ届ける** | **適用済み連番は再実行されないため、CSV を直しても既存 DB には届かない**（RESEARCH-04 C-2） |

**★(1)(2)(3) は不可分である。** どれか 1 つを欠くと、**CSV と DB が食い違う**か、**CI が落ちる**か、**次の再 seed で誤りが復活する**。これは followup **`csv-edit-vs-golden-divergence`** が追跡していた問題そのものであり、**本サブがその最初の実例になる。**
