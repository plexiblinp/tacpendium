## 4. ★★危険（**先に読むこと**）

### 4.1 ★★最大の危険＝ファミリーの衝突

**★「`code` のどこかにある強度語」で探すと、強度語が偶然含まれる技を誤って割りうる。**

**★★実測では衝突 0・誤検出 0 だった。⇒ しかしそれは `M30-01` の申告である。★段 1 で自分で測ること。**

**★★試験で固定すること。⇒ 「いま 0 件」ではなく「0 件であること」を主張する形にする。**

### 4.2 ★★2 番目＝最初に見つかった強度語を採ってしまうこと

**★`flame_od_kachousen` のような形では、`od` と強度語が両方在りうる。⇒ どちらを強度として採るかで結果が変わる。**

**★★`M30-01` の実測が「誤検出 0」なら、既に妥当な優先順位が在るはずである。⇒ その順位を明示的に書き、試験で固定すること。**

### 4.3 ★3 番目＝未分類タブの件数を直し忘れること

**★`M30-01` が固定した件数が動く。⇒ 動くこと自体が正しいので、テストを直すこと。★ただし「テストを緑にするために直す」のではなく、「新しい実測に書き換える」こと。**

### 4.4 ★★4 番目＝実測を信じ切ること

**★★`M30-01` は同じサブで母集団を取り違え、それを回帰テストで固定した**（`M-145`）**。⇒ その反省が本サブ §2.1 の理由である。★段 1 を省かないこと。**
