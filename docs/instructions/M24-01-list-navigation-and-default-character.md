### 1.2 目的

完了時に次の状態が成立する。

1. **既定キャラの解決順が 1 か所に定義され、A 群の 4 面がすべてそこを通る**（§4.1）。**★段 3a（`users.main_character_id`）は本サブでは実装しないが、後から 1 行足せば差し込める形になっている**（§4.1-2a）。
2. **`INITIAL_CHARACTER_ID` の直接参照が、解決関数の内部 1 か所を除いてゼロになる**（§4.1-5。**★本数は着手時に数え直す**＝§3.3-1）。
3. **マイコンボ画面のタブと件数が視覚的に分離され、ソート操作が一覧と同じ部品で提供される**（§4.2 / §4.3）。
4. **新規登録の保存後の遷移先が一覧になり、そのとき A 群の解決順が保たれる**（§4.4）。
5. **一覧に「紐づくセットプレイ数」が出る**（§4.5。**★分岐 A / B は §3.3-8 の実査で決まる**）。
