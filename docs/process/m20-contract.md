| 種別 | 置き場 | 命名 |
|---|---|---|
| 指示書 | `docs/instructions/` | `M20-<NN>-<slug>.md` ／ 調査は `M20-RESEARCH-<NN>-<slug>.md` |
| レビューチェックリスト | `docs/instructions/reviews/` | `M20-<NN>-review-checklist.md` |
| 完了報告 ／ レビュー報告 | `docs/progress/` | `m20-<NN>-completion-report.md` ／ `m20-<NN>-review.md` |
| 設計伝達レポート（**例外だけ**） | `docs/handover/design-reports/` | `<date>-m20-<NN>-design-exceptions.md` |
| CHANGE 通知書 ／ 反映レポート | `docs/change-notes/` | `CHANGE-<num>-<slug>.md` ／ `change-report-<num>.md` |
| overview | `docs/instructions/M20-overview.md` | 本契約と対で読む |

- **★設計卓へ返すのは「例外だけ」である**（`parallel-ops` §07）。**完了報告は repo に置き、設計卓は読まない。** 設計卓への入力は**ボードと設計伝達レポート**のみ。
- **★`progress-log.md` への索引行は製造が追記する**（`CLAUDE.md` §8。CLI 側に手順がある）。**指示書が明示的に求めていなくても追記する。**
- **★完了報告に「■ 併せて更新が要るもの」を常設で置く**（**E-114**。該当が無くても「なし」と書く）。
- **ボードを編集してよいのは設計卓だけ。** レーン側は編集しない（`parallel-ops` §05 V2.1）。
