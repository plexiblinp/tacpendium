ストリートファイター6向けアプリ ネーミング候補（有力案）
更新日: 2026-06-18

==================================================
【有力候補】
==================================================

1. Combosophy（コンボソフィー）
   - 意味 : combo + -sophy（知・哲学）＝「コンボの知を探求する」
   - 核 : 自問自答／上達の主役は利用者自身、知識の蓄積
   - 検索性 : 同名製品なし（検証済み・クリーン）

2. Combonomicon（コンボノミコン）
   - 意味 : combo + -nomicon（Necronomicon もじり＝秘伝の書）
   - 核 : 発掘／永続記録／知識管理 を一語で包含
   - 検索性 : 同名製品なし（検証済み）
   - 留意 : 魔導書のビジュアルを想起させ、UIの装飾過多・視認性低下・
            動作の重さにつながる懸念。格ゲーの軽快さと相性に注意。

3. FightMemoir（ファイトメモワール）
   - 意味 : fight + memoir（個人的な記録）
   - 核 : 気づき・攻略メモを書き残す／自問自答の記録（最も合致）
   - 検索性 : 完全一致なし。ただし格闘家の自伝本ジャンルと一部かぶる。
              1語連結 "FightMemoir" 推奨。

4. ComboAtlas（コンボアトラス）
   - 意味 : combo + atlas（地図帳）＝全コンボ／ルートを地図化
   - 核 : 総合的な上達環境／網羅的リファレンス
   - 検索性 : 同名アプリなし。ただし MLBB のヒーロー "Atlas" の
              "combo atlas" 動画と一部かぶる。

5. Combolexicon（コンボレキシコン）／略 Combolex
   - 意味 : combo + lexicon（語源「言葉の書」）＝コンボ表記=言語の辞書
   - 核 : 知識管理。Combonomicon の「…icon」語感を継ぎつつ装丁は自由
   - 検索性 : 同名アプリなし（検証済み）。クリーン＆モダンなUIに合う。

6. Combofolio（コンボフォリオ）
   - 意味 : combo + folio／portfolio＝自分で組み上げて育てるコンボ集
   - 核 : 蓄積・整理。occult感ゼロで親しみやすい
   - 検索性 : 同名アプリなし（検証済み）。

7. Combo Almanac（コンボアルマナック）
   - 意味 : combo + almanac（実用データ年鑑）
   - 核 : フレームデータ・統計のリファレンス／総合環境
   - 検索性 : 同名アプリなし。ただし "combo almanac" 検索は
              NCI ALMANAC（がん薬剤併用DB）と一部かぶる点に留意。

8. Comburako（コンブラコ）  ※オノマトペ路線
   - 由来 : 「どんぶらこ」（桃太郎で桃が川を流れ着き、割ると中から
            宝＝桃太郎が出る）＝「深く調べて隠れた技を見つける」発掘の核。
            Combraco の検索安全な綴り（k表記）。
   - 語感 : 弾むオノマトペで記憶に残り、所有性が高い。
   - 検索性 : 同名の製品・企業・サービスなし（検証済み・完全クリーン）。
              ※c表記 "Comburaco" はポルトガル語 "com buraco(穴あり)" と
                読まれ自動車部品リスト等のノイズが出るため、k表記が正解。
   - 留意 : 格ゲー信号は弱め＝マスコット前提。「川を流れてくる桃／殻が
            割れて中身が出る」マスコットと好相性。

  不利のため要検討。
