# バトルログ取り込みの出所・法務スタンス — 決定記録

> **種別**: 決定記録（DR）／法務　**ステータス**: 決定（取り込み方式）／一部要確認
> **注意**: 本書は法的助言ではない（作成者は弁護士ではない）。一次整理。
> **関連**: `combmgr-framedata-legal-decision.html`（フレームデータ側の決定）。バトルスナップショット機能のメモから本書を参照。

## 1. 結論（一言で）

バトルログは「**自分のブラウザで手動保存したマイページHTMLをローカルでパース**」または「**スクショOCR／手入力**」で取り込む。**自動ログイン／スクレイピングはしない。ゲームの通信・メモリ解析もしない。** データは配布せず、各ユーザーが自分の分だけ取り込む（プログラムは配布、データは配布しない）。

## 2. 背景

- バトルログはインゲーム、およびカプコンのマイページ（**CAPCOM ID ログイン配下**。SF6 は Buckler's Boot Camp / CFN 等）から参照できる。
- 当初はスクショOCR／手入力を検討。これに加えて「マイページからのパース」も検討対象に上がった。
- 方針の前提：プログラムは作るが**データは配布しない**。

## 3. なぜ著作権・配布が主問題ではないか

- バトルログは**自分自身の対戦記録（事実）**であり、カプコンが創作したデータセットではない。事実の記録に対する著作権は薄い。
- **データを配布しない**ため、フレームデータで問題だった「他社データセットの配布」がほぼ消える。
- 自分用の自分のデータの複製は、**私的使用目的の複製（著作権法30条）**の射程に入りやすい。

→ よって主問題は著作権ではなく、**アクセス方法と規約・業務妨害**に移る。

## 4. 確認結果（自動アクセス可否）

- **CAPCOM ID サイト（cid.capcom.com）は robots.txt レベルで自動アクセスを拒否**（実際に自動取得を試みてブロックされた）。運営側が技術的に「bot お断り」を明示している＝自動アクセス可否への最も直接的な回答。
- **ゲームEULA**：本プログラムの通信プロトコル／データの解析と他用途への使用、複製・改変・解析・リバースエンジニアリング・コード抽出、サービスの妨害を禁止。→ **ゲーム本体から通信・メモリを解析して取得するルートは明確に不可**。
- **CAPCOM ID 系の規約**：規約違反や「手段のいかんを問わずサービス運営を妨害した場合」、事前通知なく利用を停止できる。自動巡回は「運営妨害」と評価されやすい。
- **第21条の判明（訂正）**：CAPCOM ID 規約 第21条は「**権利義務の譲渡**」（カプコンが自社の権利・義務を第三者に譲渡・承継できる条項）であり、自動アクセス／禁止事項とは無関係と判明。当初「第21条＝禁止事項」としたのは、別規約（e-capcom 利用規約）の条番号からの誤推測。→ **禁止事項にあたる条項は別の条番号**にあり、未読（下記「要確認」）。

## 5. 法的軸の整理（私的利用でも残る論点）

- **規約（契約）違反** → 主に**アカウント停止・損害賠償（民事）**。認証配下サービスではこれが主軸。
- **業務妨害**（高頻度・大量アクセスでサーバ／運営を妨害）→ **刑事**になり得る（偽計業務妨害／電子計算機損壊等業務妨害）。規約に書いていなくても成立し得る。
- **私的使用**は著作権法の抗弁であり、上記2つ（契約・業務妨害）には**効かない**。
- 自分のIDで自分のアカウントに入ること自体は、**不正アクセス禁止法の対象外**（同法は他人のID・認証回避が対象）。

## 6. 採用する取り込み方式（安全度順）

1. **手入力** — 自分の画面。最も安全。
2. **スクショOCR** — 自分の画面のピクセル読み取り（写真に近い）。
3. **マイページHTMLの手動保存 → ローカルパース** — アクセスは**自分が人として手動**で行い、ツールは**ローカルファイルを読むだけ**。「自動アクセス」の土俵に乗らない。フレームデータのインポーターと同じ設計思想（自動クロールしない・手動保存物を入力にする）。

**採用しない（×）**：ツールによる自動ログイン＋スクレイプ／ゲームの通信・メモリ解析。

## 7. 付随ルール

- 取り込むのは**事実（数値）**のみ。カプコンの**表現（レイアウト・画像・ラベル文言）は持ち込まない**。
- バトルログには**対戦相手のID等（第三者の個人情報）**が含まれる。ローカル保管・自分用に限定し、**共有・エクスポート経路では相手の識別子を出さない／削る**。
- **撤退ライン**：問題があれば即停止・修正（フレームデータと同じ姿勢）。

## 8. 要確認（公開前に一次情報で固める）

- **CAPCOM ID 利用規約の「禁止事項」条項**（第21条ではない＝別条）を自分のブラウザで特定・確認。第21条は「権利義務の譲渡」であり該当しない。探すキーワード：自動／ロボット／クローラー／スクレイピング／多重・大量アクセス／解析／運営妨害。※ただし実務的な決定（自動スクレイプしない／手動保存パースに寄せる）は robots拒否＋EULA＋運営妨害条項で既に成立しており、この条文確認は補強であって決定の前提ではない。
- **SF6 オンラインサービス（Buckler's Boot Camp 等）の個別規約**に同種条項がないか。
- 可能なら**公式エクスポート（CSV／公式DL）の有無**を先に確認。あればパース不要で最もきれい。
