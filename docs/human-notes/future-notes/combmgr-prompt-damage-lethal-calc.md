では仕様を説明する:
コンボは技を順番に当てる連続技で、各技には基礎ダメージがある。ストリートファイターではコンボが続くほど後続ヒットのダメージが減る「補正（コンボスケーリング）」がかかる。始動技で初期補正が決まり、ヒットごとに補正が下がり、下限で止まる。総ダメージはこの補正を順に適用して算出する。
削りきりとは、ガードされた必殺技やスーパーアーツが与える削りダメージで、体力の少ない相手を倒し切ること。

このツールは、技の列（順序つき・各技の基礎ダメージと補正属性）、補正ルール（または既定モデル）、相手の残り体力を受け取り、補正適用後の総ダメージと、倒し切れるか（致死判定・残り体力）を返す。削りモードでは、ガードされた技の削りダメージ列と残り体力から致死判定を返す。

これは「順序つきの列に対して補正関数を畳み込み（fold）し、最後にしきい値（体力）と比較する問題」に言い換えられる。

算出アルゴリズムは後から改善しようはいくらでもあるので、まずは動くものを作る。

私のイメージは以下だが、シニアエンジニアとしてすでに改善ポイントがあれば直してよい。

1. 補正を始動値（または 100%）で初期化
2. 技を順に処理：適用ダメージ = round(基礎ダメージ × 現在の補正)、総和に加算、補正を所定の減衰で下限まで下げる
3. 総ダメージを残り体力と比較して致死判定（倒せるか／残り体力）
4. 削りモード：ガードされた技列の削りダメージを合算し、残り体力と比較
5. 結果（総ダメージ・致死可否・残り体力・必要ならゲージ消費）を返す

ここで詰めておきたい論点がいくつかある。格ゲーの慣習・SF6 の実値に照らして提案・質問してほしい:
- 始動補正の値、ヒットごとの減衰ステップ、補正の下限
- 端数処理（切り捨て／四捨五入のどちら）
- 削りダメージに補正がかかるか
- ドライブラッシュ等の追加補正を v1 で扱うか

補正モデルは正確さがそのまま価値になるので、v1 では補正ロジックを差し替え可能（パラメータ化／ストラテジ）にして、後から実値を調整できる構造にしてほしい。

なお、このツールは渡しているドキュメントのプロジェクト(本体)に組み込む他、需要の高い機能であり、ストリートファイター以外にも使えるようなモジュール（基礎ダメージ＋補正モデル＋体力という数値だけで成立する汎用ロジック）である必要があります。
