# html-reports(気に入った要約レポートの保管庫)

`/docs_to_html` が生成した HTML のうち、**開発者が残す価値ありと判断したものを手動で移してくる**フォルダ。

- **生成先はここではない**。`/docs_to_html` は常に `work_html/`(`.gitignore` 済み・使い捨て)へ書き出す
- 気に入ったものだけを開発者が手で `work_html/` からここへ移動する。コマンドは本フォルダへ書き込まない
- ここに置いたものは commit 対象(= リポジトリの資産として残る)

生成物はあくまで **md/HTML 原本の要約** であり、正は原本側。齟齬があれば原本を信じること。
