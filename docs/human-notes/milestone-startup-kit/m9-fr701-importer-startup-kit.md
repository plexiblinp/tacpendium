# M9 FR701 公式フレームデータ取込ツール 設計委任チャット 起動キット

> 本ファイルは **FR701「公式フレームデータ取込ツール」(仮称 `combomgr-importer`) の設計を専任する
> 並列チャット**(Claude Web 版「設計・指示書作成担当」)を立ち上げるためのプロンプト本文 +
> 投入ファイル一覧。流用方法は同フォルダの `README.md` を参照。
>
> **本キットは標準の連番マイルストーンキット(`m4`〜`m7-startup-kit.md`)とは性格が異なる特殊キットです。**
> 連番キットが本体アプリの単一マイルストーン指示書作成を目的とするのに対し、本キットは
> **本体とは別バイナリの外部ツール(FR701)設計を、別チャットの専任設計担当 Claude に委任する**
> ことを目的とします。本体フェーズ2 のメイン設計チャット(`phase2-kickoff` 系、M8 / M10 / M11… 担当)
> とは**別に並列で走る**チャットを起動します。
>
> **一次資料は委任ブリーフ `docs/instructions/phase2-tool-delegation-brief-fr701-importer.md` です。**
> 本キットはそのブリーフを Web チャットへ投入して専任設計担当を立ち上げるためのラッパーです。

## 0. 本キットの位置づけ(必読)

- 時系列は **フェーズ1(M0〜M7)完了 → 整理工程(CHANGE-020 / 021)→ フェーズ2 着手 → M8(moves スキーマ
  見直し、CHANGE-022 / 023 反映済み)→ M9(FR701 取込ツール)**。本キットは M9 の専任設計委任。
- **委任先の役割は FR701 ツール専任の設計担当**。一次資料 = 委任ブリーフ(設計担当 Claude がフェーズ2
  キックオフで作成、v1.0.0、自己完結)。ブリーフを入力として、ツールの**設計仕様**・**技術スタック選定
  (M9-RESEARCH)**・**製造指示書ドラフト**・**開発者確認事項リスト**を作成する(ブリーフ §6)。
- **本キットの特殊スコープ(特殊指示)**: FR701 は外部ツールのため、単なる指示書作成だけでなく
  **技術スタック等の設計(M9-RESEARCH)も作業に含まれる**。本体は Go だが、ツールは別バイナリのため
  独立選定が可能(Go で揃える / HTML パース資産の豊富な言語にする、等のトレードオフを提示して開発者承認)。
- **CHANGE 管理の扱い(最重要)**: FR701 ツールは本体の設計書本体(REQ-001 / DES-001〜006)**ではない**ため、
  本体の CHANGE 通知書プロセスの**対象外**。ツールは独自の設計文書として管理する。ただしツールの仕様変更が
  本体の CSV 契約(DES-002 §7.5)に波及する場合は、**本体側へ申し送りが必要**(ブリーフ §0 / §9)。
- **委任先は本会話の文脈を持たない**。ブリーフは自己完結を意図している。不足は「開発者への確認事項」として
  明示し、推測で埋めない。
- **実施環境と分担**: 本工程は Claude Web 版の設計担当チャットで実施。設計書本体を含む資料はそのまま投入し、
  Web 版が成果物(ツール設計文書・製造指示書ドラフト)を提示、開発者がコミットする。

## 3. 補足(進め方)

- 流れ: 委任ブリーフ + §1 のファイル投入 → 専任設計担当の読み込み・確認事項提示 → **技術スタック選定
  (M9-RESEARCH)を先に固める**(別バイナリ・配布形態・HTML パース資産の比較、開発者承認)→ ツール設計仕様
  → 製造指示書ドラフト、という流れ。
- **技術スタックを最初に固める**こと。パース方式・CLI・配布形態がスタック選定に依存するため、後で言語を
  変えると手戻りが大きい。本体 Go との統一 / パース容易な言語のトレードオフを提示して開発者承認を得る。
- **本体 CSV 契約(DES-002 §7.5)への波及に注意**。ツール側で CSV 列・採番規則・正規化規約を変更する必要が
  生じた場合、本体取込(FR704)との契約が崩れるため、本体側のメイン設計チャットへ**申し送り**する
  (本キットの委任先は本体設計書本体を直接改訂しない)。
- 「要確認報告」(投げ並び順の例外・接頭辞なし空中技・過剰除去候補・日英対応崩れ)の受け渡し形式は
  ブリーフ §9-4 の確認事項。本体 FR703 取込プレビューとの接続を踏まえて設計する。
