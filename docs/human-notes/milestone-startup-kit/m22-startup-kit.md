### 投入手順

1. **`git status` をクリーンにする。** 武装は「排除対象(`docs` / `.claude` / `scripts` 以外)に未コミットの変更がある」と `exit 1` で失敗します。
2. **Claude Code を開く**(PC なら devContainer、外出先なら `claude.ai/code`)。
3. **ブランチを `claude/desk-YYYYMMDD-N` にする**(1 セッション 1 ブランチ。`remote-ops` §6.1)。**設計卓ブランチから製造を分岐させないこと。**
4. **§2 のプロンプト 1 本を貼る**(先頭に武装コマンドが入っています)。
5. **設計卓が `bash scripts/design-desk-arm.sh` を実行して報告するのを確認する。** 報告に「作業ツリーに残した領域: docs .claude scripts」と出ていれば OK。**続けて `bash scripts/check-derived-docs.sh` の結果も報告されます。** **`code-facts` の再生成が要る**と報告されたら、それは**武装中には実行できない**ので開発者側か製造セッションで回してください。
6. **セッションを終えたあと(PC の場合)**、解除は開発者の端末で行います(設計卓からは解除できません):
   ```
   git sparse-checkout disable
   rm tmp/.design-desk-armed
   ```
   **クラウド(`claude.ai/code`)ではセッションごとに新しい環境が用意されるので解除は不要です。**

> **★V-6(クラウドでの `git sparse-checkout`)は M20 起動時に判明しているはずです。** ボード §1 か `remote-ops` §8 を見て、未記録なら本セッションで改めて観察してください。

>
> **鮮度は HEAD です**(Sync now は不要)。**ただし派生資料は HEAD と同期しているとは限りません**——起動時に `bash scripts/check-derived-docs.sh` を回して実際の鮮度と変化量を確認してください(§2 の 2 手目)。

### ★読む単位の指定について(2026-08-12 新設・規則 20)

**`Read` は既定でファイル全体を読みます。** 下表の「読む単位」列が **節限定**のものは、**必ず 2 手で読んでください。**

```
grep -n '^## ' <path>          # 節の開始行を得る
Read(<path>, offset=<当該節の行>, limit=<次節の行 − 当該節の行>)
```

**★行番号を直書きしません。** 資料が伸びた瞬間に失効し、この指定が防ごうとしている陳腐化そのものを持ち込むためです。

### 3.2 製造への引き渡し

- **設計卓と製造はどちらも main から分岐し、どちらも main へマージします。** 設計卓ブランチから製造を分岐させないでください(`remote-ops` §6.1)。
  ```
  main ──┬─→ claude/desk-YYYYMMDD-N   (設計卓・docs のみ)      ──→ main
         │
         └─→ claude/m21-07            (製造・code + progress)  ──→ main
  ```
- 理由は 3 つ: ①マージが 2 段になり開発者の作業が倍になる ②ボード・registry・backlog の正本が分岐上に載って「main と分岐のどちらが正か」が曖昧になる ③設計卓は `fetch` が deny なので長命ブランチほど分岐点が古くなる。
- **★`followup-backlog.md` のコンフリクト面は消えました**(**D-382**・2026-08-14)。**同ファイルを書くのは親だけ**になったため、並列時の唯一のコンフリクト面だった §J も親が畳みます。**⇒ 製造は完了報告 §4 へ候補を並べるだけです。**

### 3.3 個別設計チャットへの外注

起動プロンプトに必ず入れる 3 点: **①凍結事項とスコープ ②設計変更権限を持たないことの明示 ③読むべき文書名の明示**。
返却様式は固定 8 節: 目的 / **読んだ資料**(鮮度ズレの検出) / 検討した選択肢と却下理由 / **確定事項** / 開発者判断が要る未決 / **DES 差分案** / 指示書に入れるべき制約 / 教訓(親は読まなくてよいと明記)。
**★委任時は返却物の文書番号まで指定する**(番号を割り当てないと委任先が次番を取り二重発番する)。
