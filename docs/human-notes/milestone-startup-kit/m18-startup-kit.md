### 0.4 M18 起点の要約(handover §7・正本 = phase3-overview §M18)

- **機能**: ガード/ジャストパリィ後の有利フレーム中に始動する確定反撃を記録。**確定反撃版はオンデマンドで別コンボとして
  materialize**(出自 = 基底コンボ参照を記録・全自動生成しない・生成後は独立フォーク)。REQ 正典化は **CHANGE-077 で完了済み**。
- **承認ゲート(各個別承認・スキーマ変更)**: **G-c** `combo_punishes` 中間テーブル / **G-b** ジャストパリィ有利フレーム
  (`moves.is_projectile` 追加・算出式は実装前に詰める)/ **G-d** 距離除外の 2 層フラグ(pruning/curation)/
  **G-e** materialize 出自参照。**物理設計 CHANGE は G-b 算出式設計後に起票**(CHANGE-077 と二段分離)。
- **ダメージ(開発者確定 2026-07-02)**: 生成元ノーマルヒット → **始動技ダメージにのみ 1.2 倍**(合計に「始動技×0.2」加算)+
  ヒット区分パニッシュカウンター。生成元カウンターヒット → ダメージ不変・区分のみ変更。生成後編集可。ジャストパリィ始動 = 手入力。
- **重複防止**: 「同一レシピ+ヒット区分=パニッシュカウンター」の既存探索(**既存 FR301 dup キーの判定キーを実コードで
  先に引く** = E-19・VAL-S04 の轍を踏まない)。
- **注意**: `recovery` は nullable で NULL の技あり(走査時の扱いを実装時に決める)。距離依存技は自動走査対象外 = 手動確認。
