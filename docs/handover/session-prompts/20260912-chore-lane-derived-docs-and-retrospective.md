## 1. ★★★段 1 — `retrospective-log` への教訓バッチ反映（**先にやること**）

### 1.1 なぜ先か

**`retrospective-digest` は `retrospective-log`（源泉）から蒸留する派生資料である。⇒ 源泉を更新せずに `/retrospective-digest-update` を回しても、中身は 2026-09-01 のままである。**

**★`check-derived-docs.sh` が `retrospective-digest` を「✅ 最新」と出すのは、源泉が止まっているからにすぎない。⇒ 「最新」を信じないこと。**

### 1.2 対象（**28 サブ**・すべて `docs/handover/design-reports/` に在る）

**★各レポートの §7（または「§7 教訓」相当の節）が源泉である。** どのレポートも冒頭に「**宛先は `retrospective-log` へのバッチ反映であり、実施者は設計担当**」と書いてある。

```

2026-09-07  M28-02c / M28-05 / M29-02
```
