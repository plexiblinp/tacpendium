## 1. ★★そのまま貼るブロック

---- ここから ----

shadcn/ui のコンポーネントを自分のリポジトリへコピーして取り込み、そのリポジトリを AGPL-3.0-or-later で公開・配布する場合について調べてください。

**一次情報（公式リポジトリの LICENSE ファイル、公式ドキュメント）の URL と、あなたが参照した日付を明示したうえで**、次の 5 点に答えてください。

1. shadcn/ui 本体のライセンスは何ですか。LICENSE ファイルの所在（リポジトリとパス）と、著作権表示の逐語を示してください。

2. コンポーネントをコピーして再配布する場合、そのライセンスが求める帰属表示の「内容」と「置き場所」は何ですか。ファイルの先頭に書く必要があるのか、NOTICE のような別ファイルでよいのかを含めて答えてください。

3. shadcn/ui の公式が「コピーしたコードはあなたのものである」という趣旨を述べている箇所があれば、その逐語と所在を示してください。そのうえで、その記述は 2 の要求を免除するものなのか、しないのかを答えてください。

4. MIT のコードを AGPL-3.0-or-later のプロジェクトへ取り込むことは、ライセンス上両立しますか。両立する場合、NOTICE ファイルや REUSE.toml（REUSE 仕様）ではどう表現するのが一般的ですか。

5. shadcn/ui のコンポーネントが内部で依存する Radix UI 等は、package.json 経由で依存一覧に載ります。コピーしたコンポーネント自体の帰属とは別に、それらを重ねて書く必要がありますか。

**推測で答えた部分は「推測」と明記してください。確認できなかった点は「確認できなかった」と書いてください。**「おそらく」「一般的には」で済ませず、根拠にした文書を必ず示してください。
