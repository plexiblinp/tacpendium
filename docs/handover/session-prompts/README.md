## 1. ここは何か

**別のチャット・別のツールへ「そのまま貼る」プロンプトを、1 件 1 ファイルで置く場所。**

このセッションで決めたことを、**別セッションで実行できる形にして残す**ためにある。
会話の中にしか無いプロンプトは、セッションが終わると失われる——**それを防ぐのが本ディレクトリの役割。**

## 1.1 書き方の規約（★★「そのまま貼る」ブロックは自己完結させる）

**★★★「そのまま貼る」と銘打ったブロックは、ブロックの外を指す参照を持たない。**

**⇒ 貼られた先には、ブロックの中身しか届かない。★外を指した瞬間、受け手はその参照を解決できず、往復が 1 回増える。**

| # | 規約 |
|---|---|
| **(i)** | **ブロックの中で「上記ファイル」「前述の」「先ほどの」と書かない。⇒ ブロックの外に在るものを、位置関係の言葉で指さない** |
| **(ii)** | **外の節を指すなら、ファイルパスと*実際の見出し文字列*を書く。★見出しは記憶で書かず `grep` で確かめる**〔`grep -n '^## ' <file>` の形〕 |
| **(iii)** | **書き終えたら、ブロックだけを読み直して「これだけで始められるか」を確かめる。⇒ 前後の説明を読んでいる自分の目で判定しない** |

> **★★由来＝計測点 `M-165`**（2026-09-12）**。交代プロンプトの貼るブロックが自己完結しておらず、3 つの誤りが重なった。**
>
> **(1) 案内をブロックの外**（チャット本文）**に書き、ブロック内に 1 行も入れなかった ／ (2) 「上記ファイル」がブロック内から解決できなかった**（ファイルパスが外に在った）**／ (3) 節名を「§補足」と書いたが、実際の見出しは `## 補足:` であった。**
>
> **⇒ 受け手が `§補足` で `grep` して 0 件になり、照会の往復が 1 回発生した。★(iii) を通していれば、貼る前に気づけた形である。**

## 3. 使い方

1. §6 の一覧から該当ファイルを開く
2. **「投入プロンプト」節をそのままコピーして貼る**（前後の説明は貼らなくてよい）
3. 作業が終わったら **`docs/handover/followup-backlog.md` §J の該当項目を更新する**
4. **プロンプトが役目を終えたらファイルを削除する**（§5）

## 4. 書くときの決まり

新しく追加するときは次を守る。**既存ファイルが手本になる。**

- **ファイル名は `YYYYMMDD-<slug>.md`。** 起票日を先頭に置く（古さが一目で分かる）
- **冒頭にメタ表**を置く——`宛先` ／ `実施時期` ／ `追跡`（§J のスラッグ）／ `起票`
- **「## 投入プロンプト」節にコードブロックで本文を書く。** ここだけをコピーすれば動く形にする
- **判断が要る点は本文に明記する。** 例＝「`--board-through` の上限は毎回判断すること」
- **背景・根拠は「## 補足」へ分け、「プロンプトには含めない」と書く。** 貼る側が迷わないため
- **★宛先を明記する。** Claude Code／Web 版設計卓／Codex／開発者（PowerShell）で書き方が変わる
- **★実測値・根拠は数字で書く。** 「大きい」ではなく「517 KB のうち 62%」
- **★★貼るブロックは自己完結させる。** 規約の本体は §1.1（**ブロックの外を指す参照を持たない**）

## 5. 寿命の規則

**役目を終えたプロンプトは削除する。** 残すと「まだやることがある」と誤読される。

| 状態 | 扱い |
|---|---|
| 実行して完了した | **ファイルを削除**し、結果と学びは §J の該当項目へ書く |
| 実行したが追加作業が出た | ファイルを削除し、**新しい項目を §J へ起票**する |
| 前提が変わって不要になった | ファイルを削除し、§J へ「不要になった理由」を書く |
| まだ実行していない | 残す |

> **削除してよい理由**: 本ディレクトリは**作業の受け皿**であって記録ではない。
> **記録は `followup-backlog.md` §J と `docs/progress/` が持つ**（§J は「完了した項目も削除しない」を規則にしている）。
> 実例＝`20260811-codex-storage-probe.md` は 2026-08-11 に実行して完了したため削除し、
> 結果（**補償は機能する。ただし命名規約に沿ったキーに限る**）を §J の
> `web-claude-md-codex-invisibility` と `browser-storage-key-naming-blindspot` へ書いた。
