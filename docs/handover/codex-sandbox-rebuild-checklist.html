Codex Sandbox 再ビルド後チェックリスト

CombMgr Dev Containerで、Codexのworkspace sandboxと承認境界が正常になったことを確認する。

現在: 再ビルド済み・検証手順を更新

1. 再ビルド前

このHTMLを作成したCodexセッションでは再ビルドを実行していません。

2. 再ビルド直後の手動確認

この節はCodexへのプロンプトではなく、VS Codeの統合端末から直接実行する。Codexセッション内からcodex sandboxを再実行しない。

  1. VS Codeで Dev Containers: Rebuild Container を実行する。
  2. 再接続後、リポジトリルートで次を実行する。
bash .devcontainer/verify-env.sh

stat -c '%U:%G:%a %n' /usr/bin/bwrap

codex sandbox \
  -P :workspace \
  --include-managed-config \
  -C "$(git rev-parse --show-toplevel)" \
  /bin/pwd

3. 期待する権限境界

操作期待結果確認
pwd、rg、sed、git status承認なしで成功
workspace内の通常ファイル編集承認なしで成功
.git、.codex、.agentsへの書き込み拒否または承認要求
workspace外への書き込み拒否または承認要求
shellからの外部ネットワーク接続拒否または承認要求
禁止Git操作.codex/rulesにより禁止
PostToolUse / Stop hooks追加承認なしで完了

4. Codexへ渡す検証プロンプト

第2節の端末側検証が成功した後、新しいCodexセッションを開いて下記を貼り付ける。このプロンプトではnested sandboxを起動しない。

5. 完了判定

全項目を満たせば、sandbox是正は完了です。
