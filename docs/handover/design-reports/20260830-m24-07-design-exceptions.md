### ★§1-4 詳細: `ComboResponse` の応答変更（`DES-002` §4.2）

**変更した経路**: `ComboResponse` を返す経路すべて（`internal/api/combo/handler.go` の `toComboResponse` 経由＝作成 `:448` / 更新 `:399` / 取得 `:194` / 一覧 `:325-327` / ゴミ箱系 `:135` `:497` / `:77`）。**新設した経路は無い。**

**足したフィールド 1 つ**（`internal/api/combo/dto.go:226-229`）:

```go
StarterMoveCode   string  `json:"starterMoveCode"`
// StarterMoveNameJa は始動技の表示名(公式日本語)。未登録なら省略される(M24-07)。
// ★画面はこちらを出し、引けないときだけ starterMoveCode へ落ちる。
StarterMoveNameJa *string `json:"starterMoveNameJa,omitempty"`
```

**母集団の述語** — `starterMoveNameJa` は **`official_ja_move` プリセットの `preset_aliases.alias_text`** を `LEFT JOIN` で解決した値である（`internal/repository/combo/repository.go` の `findMoveLabelsByIDs`・**`internal/repository/punish` と同じ経路を使い、名前解決を二重実装していない**）。

**★返らない場合が実在する（`omitempty` で省略される）** — `alias_text` は `moves` の列ではなく `preset_aliases` 由来であり、**ラッシュ版（`rush_variant`）は `preset_aliases` へ書かない**（`internal/repository/move/rush.go:46-47`）。**⇒ 「必ず入る」と読まないこと。**

**★持たせなかった分岐** — **エラー契約は 1 行も増えていない。** 名前が引けないことはエラーではなく、**`starterMoveNameJa` が省略されるだけ**である。新しいステータス・エラーコードは無い。**404 も増えていない**（存在しない始動技という状態は、既存の `starterMoveId` が nil という形で既に表現されている）。
