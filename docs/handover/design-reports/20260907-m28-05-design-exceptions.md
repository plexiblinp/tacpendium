## 1. 独自確定仕様（設計書に無い／設計書より細かい決めごと）

### ★★§1-1 単一強度の必殺技はクイック入力パネルのファミリー UI に載らない（as-built・明文が無い）

**何が起きるか**: `parseSpecialCode`（`web/src/features/combo/inputResolution.ts:107-116`）は **`_light` / `_medium` / `_heavy` / `_od` で終わる `move_code` だけ**をファミリーと強度に分解し、**接尾辞を持たない code には `null` を返す**。`null` を返された code は**必殺技クイック入力パネル**（`web/src/features/combo/components/VirtualController/SpecialMovePanel.tsx`）の**ファミリー UI に載らず**、「▶ 全技一覧から選ぶ」プルダウン（`web/src/features/combo/components/RecipeBuilder.tsx`）からの入力になる。

**★これは意図された設計である**——同ファイル `:106` のコメントが逐語で書いている:

> 強度接尾辞を持たない code(単一強度の必殺技等)は null(ファミリー UI 非対象 → プルダウンで網羅入力)。

**本サブで実際に変わること**（DB から算出・実測）:

```
terry/quick_burn:  ファミリーで活性=[('quick_burn_od', 'od')] / ファミリー非対象=['quick_burn']
guile/sonic_break: ファミリーで活性=[('sonic_break_od', 'od')] / ファミリー非対象=['sonic_break']
```

| | 改名前（誤ったデータ） | 改名後（正しいデータ） |
|---|---|---|
| ファミリー「クイックバーン」の中身 | `quick_burn_light` が **弱** ／ `quick_burn_od` が **OD** | **`quick_burn` は非対象。`quick_burn_od` だけが OD を埋める** |
| 強度ボタン | **［弱］活性** ／［OD］活性 | **★［弱］非活性** ／［OD］活性 |
| ファミリー名 | 「クイックバーン」 | 「クイックバーン」のまま（`stripStrengthLabel`（同 `:154-156`）が `^(弱|中|強|OD)` を落とす） |

**★退行ではない。** `guile` の `sonic_break`（`M19-04c` で**同じ改名**を行った先例。`character_data/guile.csv:64-65` に `sonic_break` ＋ `sonic_break_od` の 2 行のみ）が**まったく同じ形**であり、これが本アプリの「単一強度の必殺技」の正しい姿である。
