## 2. ★★★他の機能で表現できるものが混ざっていないか

### 2.1 ★★★重複の疑いが 1 件ある——**ジャンプ状態の flag と、移動 system move**

**★事実 A＝`DES-004` §2.1 は、技を出さないジャンプを *move* として持つ。**

| code | 意味 |
|---|---|
| `jump_neutral` | 垂直ジャンプ |
| `jump_forward` | 前ジャンプ |
| **`jump_back`** | **後ろジャンプ** |

**★事実 B＝`DES-004` §2.3 は、同じことを *flag* でも持つ。**

| code | 意味 |
|---|---|
| `neutral_jump` | 垂直ジャンプ中 |
| `forward_jump` | 前ジャンプ中 |
| **★★（`back_jump` は無い）** | — |

**★事実 C＝`DES-004` §2 は「ジャンプ→攻撃は空中技 ＋ `{neutral_jump}` / `{forward_jump}` flag」と書いている。⇒ flag のほうが想定された表現である。**

**★★★したがって同じコンボが 2 通りに書ける。**

```
(a) jump_forward〔move〕 > jumping_heavy_punch
(b) jumping_heavy_punch {前ジャンプ中}
```

**★★★これは `DES-004` §2.1 が*移動については明示的に禁じた*形である。⇒ 同節の逐語＝「『前入力を `forward` + `modifiers.flags=[\"micro_walk\"]` で表現』という案も検討したが、同じ意味の状態が 2 通り…」。**

**⇒ 微歩きには当てた規律を、ジャンプには当てていない。**

**★★★しかも非対称である＝`jump_back` に対応する flag が無い。⇒ 後ろジャンプからの空中技は flag では書けず、move を使うしかない。★同じ操作が、方向によって書き方が変わる。**

**★★判断していただきたいこと**〔§5-1〕**＝どちらを正とするか。⇒ 設計卓は「決めるべきである」とだけ言い、どちらかは推さない。両方に理があるためである**〔flag は行数が減る ／ move は「何をしたか」が並びに出る〕**。**

### 2.2 ★重複していないもの（**確認済み**）

| コード | 隣接して見えるもの | 判定 |
|---|---|---|
| `just` | `hit_type` の `just_parry_punish_counter` | **★別物である**。⇒ 前者は*入力のタイミング*、後者は*ジャストパリィからの確定反撃*。**★★語が似ているだけである。⇒ 混同しないよう、要否の検討でも分けて扱うこと** |
| `low_jump` | `jump_*` の move ／ `neutral_jump` / `forward_jump` flag | **★直交する**。⇒ 「最低空で出したか」は方向と独立であり、`{低ジャンプ}{前ジャンプ中}` は同時に成り立つ |
| `first_hit_cancel` | `moves` の多段技そのもの | **★別物である**。⇒ 技が多段であることは move の性質、「初段でキャンセルした」は出し方 |
| `parry_drive_rush` | `dash_forward` / `dash_back`（move） | **★別物である**。⇒ ラッシュは中P＋中K からの前進であり、ダッシュとは別動作。**★`DES-004` は単値 `dash` の type を「幽霊仕様」として削除済み**（`CHANGE-062`） |
| `od_lm` / `od_mh` / `od_lh` | move の `<family>_od` | **★直交する**。⇒ *OD であること*は move が持ち、*どの 2 ボタンで出したか*を flag が持つ |

### 2.3 ★★`od_*` 3 値だけは「値打ち」の問いが立つ

**★SF6 では OD は「同じ強度でなくてもよい 2 ボタン同時押し」であり、どの組で出しても*技の出力は同じ*である。⇒ 記録しても技の性能は変わらない。**

**★★したがって `od_*` は「出し方メモ」としてのみ意味を持つ。⇒ 「この場面は弱中のほうが押しやすい」といった*運指*の記録である。**

**★★★これは modifier の趣旨に合っている。⇒ 消すべきとは言わない。★ただし要否を問うなら第一候補である**〔3 値で 10 枠のうち 3 枠を占め、UI のボタン上限に効く〕**。**

## 5.3 ★★★残論点の決着（**2026-09-13・`D-873`**）
